# An exposition body in the shape a jmx_exporter serves in httpserver mode in front of a Kafka broker,
# with the lowercaseOutputName rule set. The line shapes are the format's; the numbers are chosen rather
# than measured, and nothing in this repository claims otherwise.
#
# It holds one family of each kind this parser has to survive: the three broker-wide rates it reads, the
# per-topic slices of the same MBeans it must not double-count, the replication family whose name contains
# one of the names it reads, the request percentiles, the two idle ratios beside the two decoy pools whose
# names contain one of them, the purgatory queues, four of the several hundred families it knows nothing
# about, a NaN and a +Inf.
#
# The slices are written BEFORE the aggregate they belong to, deliberately. Nothing in the exposition
# format orders a family's lines, and a parser that took the first line matching a name would read
# `98000.0` here — which is a real number, from a real topic, and not the cluster's throughput. Put the
# aggregate first and the skip-the-slices rule cannot be made to fail.
# HELP jmx_exporter_build_info JMX Exporter build information
