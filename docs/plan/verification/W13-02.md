## 3. The row this packet filed, and the class under it — TD-053

**The defect, reproduced before anything was changed.** `connect-seed.sh`'s `RUNNING` wait loop
assigned `running="$(printf … | grep -o '"state":"RUNNING"' | wc -l | tr -d ' ')"` under
`set -euo pipefail`. `grep` exits 1 when the status document holds no `RUNNING` state — the normal
first poll — `pipefail` carries that out of the command substitution and `set -e` kills the script
before its own `die()`.

Driven against a fake worker (`python3 -m http.server` subclass) whose **first** status poll answers
an `UNASSIGNED` connector with no tasks and every later one answers connector + task `RUNNING`,
compact JSON like a real worker:

```
$ KUI_CONNECT_URL=http://127.0.0.1:18087 bash <HEAD's connect-seed.sh>
the Connect worker at http://127.0.0.1:18087 is answering
registered quickstart-file-source reading /opt/kafka/LICENSE into connect.file.lines
exit=1                                     # and nothing else printed

$ KUI_CONNECT_URL=http://127.0.0.1:18086 bash deployment/quickstart/seed/connect-seed.sh
the Connect worker at http://127.0.0.1:18086 is answering
registered quickstart-file-source reading /opt/kafka/LICENSE into connect.file.lines
waiting for quickstart-file-source: connector UNASSIGNED, 0 RUNNING state(s)
quickstart-file-source and its task are RUNNING:
{"name":"quickstart-file-source","connector":{"state":"RUNNING",…},"tasks":[{"id":0,"state":"RUNNING",…}]}
exit=0
```

**It is a class of three, not one line.** `deployment/compose/smoke.sh:637` and `:649` carried the
identical shape around the two broker byte counters — two lines above the `fail` written for
exactly the "the exporter published no such series" case. Confirmed as fatal rather than
theoretical:

```

> bytes_in="$(grep -E "^kafka_x " <<<"$exposition" | awk "{print \$2}")"; echo "ALIVE"'
$ echo $?
```

All three now wrap the filter as `{ grep … || true; }`, and `connect-seed.sh` says what it is
waiting for once per change of state.

**On a real stack**, the bring-up in §1 line 5 printed *waiting for quickstart-file-source:
connector RUNNING, 1 RUNNING state(s)* — the connector up and its task not yet — before reaching
