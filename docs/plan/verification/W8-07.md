`ECOSYSTEM`'s third row has a destination. All of it is the **shell's** half — the feature's screen,
its registration and its stylesheet are W8-05's, and a feature edits no routing file.

| Where | What |
| --- | --- |

| `shell/src/shell.test.tsx` | the reading and the crumb, the two halves that fail silently in opposite directions |

It could not be written until `FeatureId` carried `"ksql"`: the union is the kernel's, W8-06 ships
the widening, and `gate("ksql")` is a type error without it. This packet waited for it rather than
editing the kernel, and landed the route within minutes of its arrival.

**The crumb's spelling is asserted**, which is not decoration: the id is `ksql` because an id is a
path segment and the product's word is `ksqlDB` (§4.15). A crumb built from the id reads `Ksql`,
which is a word this product uses nowhere a person can see.

**A fourth case says no object name may enter the address.** §3.16's two panes are one workspace; a
`/ksql/:stream` sibling would make the left pane a navigation and would throw away the editor's
contents on every click.
