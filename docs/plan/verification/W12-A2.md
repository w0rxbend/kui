## 4. Rows 5–9, and the second edge

**Row 6 first, because it is the rule the other two depend on.** `readDeclared`'s own scaladoc
claimed the hole "cannot be reopened one `Files.readString` at a time" and nothing enforced it. The
case reads this suite's own source — through `scala.io.Source`, deliberately, so that it does not
count itself — and requires **exactly one** `Files.readString(` in the file, positioned between
`private def readDeclared` and `private lazy val buildFile`. The call shape is counted **with its
open parenthesis** so that the comment and the clues can name the method without changing the number.
A second `Source.fromFile(` is refused too, because a reader that closed one API and opened another
would be the same hole.

## 5. Rows 10–13, and what the frontend sweep cannot see by construction

Row 11 is the one worth stating as a general fact rather than as a defect. W12-04's address sweep
mounts a **fresh frame per press**, deliberately and for a good reason — a sweep that pressed its way
down one inventory would be pressing a frame its own previous press had changed. The cost is exact and
total: **every control is pressed exactly once from a clean frame, so no toggle's second press is
asserted anywhere in this frontend.** Closing the bell closes one instance; the class is still open
for the theme glyph, the appearance popover and every disclosure control added later.

Rows 12 and 13 close with one case because they are the two ends of one link. The sweep's link half
is `href !== ""`, which one character of punctuation satisfies. `#` is a valid `href` and an invalid
selector, so it is refused **by name** rather than handed to `querySelector`, which would throw
instead of failing.

```
# href="#kui-content" -> href="#"          × resolves every fragment link `/ui` draws …
# id="kui-content"    -> id="kui-conten"   × resolves every fragment link `/ui` draws …
# bell toggle         -> setNoticesOpen(true)
#                                          × closes the notification panel on the bell's second press
# Toast onClick       -> () => {}          × dismisses the toast the button belongs to when pressed
```
