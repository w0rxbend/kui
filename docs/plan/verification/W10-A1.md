## 3. Equivalent mutants, argued down rather than counted

**G10 — the CSRF fail-open default, unreachable under the current route table.** `CsrfCheck.verdict`
is called with `session.fold(PrincipalKind.Anonymous)(_.principal.kind)`, and `PrincipalKind.Bearer`
is exempt from CSRF outright. Replacing the default therefore turns *every mutation arriving without a
session* from denied into allowed, and the whole gateway module stayed green. The algebra: a request
reaches the CSRF interceptor only after an endpoint matched, and `ensureSession` attaches a session to
**every** request under `/api/v1` except `/api/v1/health/*`. The endpoints outside that set are the
health probes, the static routes and the SPA shell, and a grep finds no `.post`, `.put`, `.delete` or
`.patch` among them — so today the branch is unreachable and the mutation is equivalent. It is listed
because it is equivalent *by accident of the route table*, not by construction: the day any endpoint
outside `/api/v1` (or under `/api/v1/health`) accepts a mutation, this default silently inverts from
fail-closed to fail-open. A gate for it is a route-table invariant — "every endpoint the gateway
serves whose method is not safe sits inside the session-minting set" — and building the real route
list needs `GatewayTestServer`'s private `configView`, which is not this packet's file.

**`LatencyWindow.empty`'s `math.max(1, size)`** was read and **not** mutated: the only production
caller is `ReadinessPoller`'s `LatencyWindow.empty()`, which passes the default of 50, and no
configuration key reaches it. A size of 0 would make `takeRight(0)` permanently empty and `p95`
permanently `None`, but nothing can produce one, so it is not counted in the denominator.

## 4. Filed and not closed — rule 22, with the seam named

**K9 — the OAuth refresh margin.** `parseToken` stamps `usableUntil` at
`now + max(lifetime - RefreshMargin, MinimumLifetime / 2)`. Removing the margin left
`services.ksql.infrastructure.test` green, because the two suites there observe only *whether* a token
is fetched, never *when* it stops being used. The closing case is a two-fetch assertion on a virtual
clock — take a token with `expires_in: 61`, advance 31 seconds, request again, and assert a second
fetch happened. **The seam is one `mvnDeps` line:**
`mvn"org.typelevel::cats-effect-testkit::${Versions.catsEffect}"` on
`services.ksql.infrastructure.test`, which `services.gateway.application.test` already has and which
`ReadinessPollerSuite` uses for exactly this. `build.mill` is **W10-05's** file.

**G10 — the route-table invariant** described in §3. The case needs a route list, which means
`GatewayTestServer.configView` (currently `private`) or an equivalent fixture;
`GatewayTestServer.scala` sits at `services/gateway/api/test/src/kui/gateway/api/`, outside this
packet's `auth/**` and `routing/**`. **The seam is one word:** `private def configView` becomes
`private[api] def configView`.

**Two seams were landed by this packet**, because it owns the files and rule 22 says the owner lands
them before it freezes. Both are behaviour-preserving and both are in the diff:

* `SessionMiddleware.alreadyCarriesSessionCookie`: `private` becomes `private[auth]`.
* `AuthRoutes.replaceSession`: the delete-then-create pair lifted out of `signIn` into a
  `private[auth]` function of `(store, previous, principal)`. `signIn` now reads the session and calls
  it. Without this, G16's rule is unreachable from any test: every suite in the tree builds a gateway
  with `identity = None`, so `/auth/login` answers `KUI-UNSUPPORTED` before `signIn` runs.

## 5. Structural gates the compiler enforces, which nobody has published

Wave 9 found two (an unused pattern binding and an unused parameter). This packet hit **three more
sub-kinds**, each of which refused a mutation outright and forced a second, visible edit:

1. **`-Wunused:privates`.** Deleting `.orElse(errorIn(json))` from `KsqlHttp.frameOf` left `errorIn`
   unreferenced: `unused private member`, then `No warnings can be incurred under -Werror`. Deleting
   the method as well was a second edit, twelve lines wide.
2. **`-Wunused:explicits`.** Replacing `SessionMiddleware.setCookie`'s `path` with a constant left
   `basePath` unused: `unused explicit parameter`. Completing the attack means changing the signature
   and both call sites — including `AuthRoutes.cookieOf`.
3. **`-Wunused:imports`.** Deleting the `ErrorCode.Unsupported` arm from `ReadinessPoller.reasonOf`
   left `kui.kernel.error.ErrorCode` imported and unused: `unused import`. A second edit to the import
   list was required.

**This is a real defence and it is worth stating plainly.** It does not stop a determined attacker,
but it converts every *deletion* of a guard whose only reader is that guard into a diff that touches a
second place — an import list, a signature, a whole method — which is exactly the shape a reviewer
notices. It is also why "delete the guard and see if the build is green" is not one edit in this
repository; three of twenty-five attempts here needed two.

## 6. The clue, carried forward

*A rule ungated in a file that already has a suite is ungated because the fixture could not express
the failing input, or because no assertion ever read that field.* **It fired again, and this time in
both halves at once.**

* **The fixture could not express the input.** `StubServiceClient` answers the readiness probe and the
  capability probe from **one** `ServiceHealth`, so no case among the twelve could have a service
  whose readiness succeeds while its capabilities fail — which is precisely P2's rule, and the reason
  the `.orElse(inputs.serviceReport)` that a paragraph of comment argues for had no reader. Closing it
  needed a second `ServiceClient` written by hand.
* **No assertion ever read the field.** `ContractRoutingSuite` asserted `CapabilityState.Unavailable`
  by shape — `case Unavailable(_, _, _) => true` — in both directions, in two tests, with a comment
  explaining why each matters. The **first field of that pattern is the reason code**, and permuting
  the whole mapping changed nothing. The underscore is where the rule went.
* And a third, which the clue does not yet name: **the fixture never left the default.** `basePath`
  defaults to `"/"` in `GatewayTestServer` and every cookie assertion in `SessionMiddlewareSuite` took
  it. Two independent rules (G5, G22) lived entirely in the non-default branch.

## 7. What was read and left alone

`CapabilityRegistry` (419 lines) and `CapabilityFold` were read and screened: the debounce, the
per-subscriber queue, the precedence table and the stickiness of `since` each have a case that names
the failure it prevents, and `CapabilityFoldSuite.aBusinessErrorHasNoWayToReachTheFold` is asserted
*structurally*, over `CapabilityInputs.productElementNames`, which is the strongest shape in this
tree. `PolicyRbacPreCheck`'s fail-closed arms (`anEndpointThatDeclaresNoPermissionIsRefused...`,
`anEndpointWhoseResourceIsNotInTheRequestPathIsRefused...`) are both gated and logged at error level.
`ClusterScope` has eight cases including the two traps its own comment names. `ServiceContracts` is
covered by seven, one of which proves no two services declare the same path. **`CapabilityFold`'s
`PollIntervalFactor` is the one loose thread:** the case asserts `suggestedPollIntervalMs >= p95`, so
a factor of `0` is red and a factor of `1` is green — the direction that matters is gated and the
factor itself is not, which is a judgement the suite has already made in words.

The one thing this packet would **not** declare finished is `AuthRoutes`' sign-in surface. A grep for
`login` and `oidc` over `services/gateway/**/test` finds no behavioural case for `login`,
`changePassword`, `oidcStart` or `oidcCallback`. G16 is one rule out of that file closed by a unit
seam; the OIDC callback's refusal of `PasswordChangeRequired`, the password-change path's deliberate
*absence* of a new cookie, and `withIdentity`'s "this deployment has no identity service" sentence are
all still unasserted, and closing them needs an identity `ServiceClient` stub reachable from
`GatewayTestServer` — the same seam G10 needs.
