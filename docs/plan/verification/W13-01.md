That is **the exact sentence the whole of wave 12 and wave 13 exist to refuse**, attributed to the
exact file that no longer contains it, inside a `<!-- checked: -->` region, with the run green — the
verbatim shape of the reproduction at the top of `WAVE-13.md`, reproduced on the bytes W13-01 shipped
to close it.

**Why.** The packet delivered the plan's *"excluded by name in one place"* for the derivation:

* `quotation_handled_kind=quotations` (`:3368`) strikes `quotations` blocks out of
  `marked_blocks_on_disk`, so the sweep never opens them **and `reconcile_swept_roster` never sees
  them** — they are absent from `derived` and absent from `quotation_marked_roster` alike, so both
  `comm` halves are silent about them by construction.
* The other side of that exclusion — the list of files whose `quotations` blocks **are** read
  directly — is a **hand-written two-item roster reconciled against nothing**, at `:3764`:

```bash
for file in README.md "$matrix"; do
  check_marked_file quotations "$file" check_quotation_region
done
reconcile_swept_roster      # <- the fix, on the very next line
```

House rule 26 says *a hand-written list of the places a gate looks must be reconciled against the
repository, in the same run, by the same script*. This is the one list in section 9 that still is not,
and it is one line above the function that enforces the rule.

**It is one-directional, which is why it was not caught.** Deleting `"$matrix"` from that loop **is**
RED (`section quotations compared 8 claims and published 12`, 2 disagreements, exit 1) — the claim
count defends the *shrinking* direction. The *growing* direction — a third document acquiring a
`quotations` block — is defended by nothing, and growing is the direction wave 13 exists for: *"a
document that grows a marked block is swept on the day it grows one"* is the sentence the packet
shipped in the refusal text, and it is not true of this kind.

**Consequence for the report.** §3 of the packet summary says of line 3399: *"'every block in this
repository is read for attributions' was false of 12 of 13. **It is now true by construction**"*. It
is not. The shipped refusal text is narrower and honest — *"every block of every **other** kind"* —
so the script does not lie; **the report does**, and the hedge in the shipped sentence is exactly
where the remaining hole is.

**The case that would close it.** Derive the `quotations`-kind file list the same way: emit the
`quotations` pairs from `marked_blocks_on_disk` into a second set, drive `check_marked_file` from it
instead of from the two-name loop, and let `reconcile_swept_roster` claim it in both directions — or,
minimally, add a third comparison group to the existing `quotation-roster` claim asserting that the
`quotations` pairs on disk are exactly `{README.md, $matrix}`. **This is one claim in a section the
closer already has to touch, and it is the same claim W13-01 just wrote.**

## D-bis. The fixture seam W13-A2 is handed does not work

```bash

  local -A quotation_marked_roster=([a.md]="rows")
```

**Driven verbatim, it does not work, and it fails silently.** `marked_markdown_files` strips the root
prefix (`sed "s|^$marked_markdown_root/||"`, `:3360`), so it emits `a.md`; `marked_blocks_on_disk`
then `sed`s that **bare** path (`:3375`) while the process cwd is the repository root, because the
script `cd "$root"`s unconditionally at startup. Measured, driving the shipped function bodies over a
two-page fixture root:

```
--- marked_markdown_files() with root=$fixtures ---
a.md
b.md
--- marked_blocks_on_disk() with root=$fixtures ---
sed: can't read a.md: No such file or directory
sed: can't read b.md: No such file or directory
--- exit 0 ---
```

`sed` writes to stderr, the inner `while` reads nothing, and the function **returns 0 with an empty
derived set**. So both of the packet's documented cases invert:

* **case 1a** (fixture declared, require silence) → `unpresent` fires: *"names blocks this repository
  does not carry: a.md (checked: rows)"*. **Fails.**
* **case 1b** (fixture undeclared, require *"carries marked blocks the sweep's roster does not
  name"*) → `derived` is empty, `undeclared` is empty, **no refusal at all. Fails — and this is the
  case the packet designates as the one that closes its own disclosed ungated rule (F-4).**

**The case that would close it** — and the repair is one token, twice: read
`"$marked_markdown_root/$file"` in `marked_blocks_on_disk:3375` and in `quotation_census:3397`
(`tr '\n' ' ' < "$file"`, same bug, same silent-empty failure). Verified in a scratch harness: with
