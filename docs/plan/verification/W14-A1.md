```bash
check_repository_layout_region() {

```

`residue_text=$text` reads the **caller's** `text` and not the parameter beside it — bash applies the

hold a `text` local and hand it over, which is what the shipped caller does. Filed, not repaired:
`residue_text=$2` is a one-token change in W14-01's file with no behaviour to gain today.

had gated: the tree moved, six *sentences* went false, and the one *listing* that had a gate went red.
Those sentences are wave 11's class, and the reason they are silent is not that the mechanism is
missing — it is that `research/`, `docs/plan/` and half of `ARCHITECTURE.md` carry no marked region at
all. That is a **scope** result, not a mechanism one, and it is the first time in six waves the answer
to *what is left* has been "point the readers we have at more of the tree" rather than "build another
reader".

blocked on prose or a marker in a document this packet does not own — the same partition result wave
13 reported (11 of 22). The rate at which a builder discloses its own holes has still not moved; the
rate at which a closer can close what verifiers file is still bounded by who owns the document, not
by who can write the case.
