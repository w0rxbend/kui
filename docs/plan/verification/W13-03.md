## The decision this packet took, stated before the evidence

The brief offered two repairs for a stale figure: re-take it, or replace it with the command that
prints it. Its own bolded rule settles which — *"a figure about the tree lives inside a checked
region or is written as a command; there is no third option left after five waves of this"* — and
the wave-12 pass had already taken the other road and lost: it converted three moving figures to
commands, left six dated, and **the dated ones are the ones that were wrong**.

So `docs/overview/README.md` §5's gate table now has **no figure in its right-hand column at all**.
Each row says what running that command prints. This is not an omission and the page says so: every
one of those commands ends by printing its own size, so a reader who wants a number is one command
away from one nobody had to remember to re-take. The only figures left on the page are the four
inside the `gate-table` block, which `./scripts/feature-matrix-check.sh` re-reads on every run, and
a handful of structural counts each written beside the one-second command that answers it
(`ls services`, `ls frontend/packages`, `git ls-files '*openapi*.json'`, `./mill resolve …`).
