# SVC-002 — `services/cluster/contract`: endpoints and DTOs

- **ID:** SVC-002
- **Title:** `services/cluster/contract`: endpoints and DTOs
- **Milestone / Feature:** M0 / KU-006
- **Owner role:** Domain Architect (Cluster Registry context)
- **Size:** M
- **Dependencies / blocked by:** KERN-005, SVC-001

## Goal (user value)

The first cross-compiled contract module: one description of an endpoint that produces the
server route, the gateway's client, the browser's client and the OpenAPI document. No hand-
written path lists anywhere (ADR-003).

## Scope

1. The cross-compiled module `services/cluster/contract` (JVM + JS).
2. Endpoints:
   - `GET /internal/v1/ping?message=<string>` → `PingResponse`, requiring `X-Kui-Principal`.
   - The health and capability endpoints come from `libs/http` (HTTP-002) and are **not**
     redeclared here.
3. `PingResponse` DTO with an explicit Circe codec and Tapir `Schema`, plus its golden file.
4. An `endpoints: List[AnyEndpoint]` value — the list the gateway derives its routes from and
   the OpenAPI generator consumes. Nothing may be served that is not in this list.

## Non-goals

No M1 endpoints (`/clusters`, `/clusters/{id}/brokers`, …). No `/api/v1` paths — the public
prefix belongs to the gateway (`ARCHITECTURE.md` §5: services use `/internal/v1`). No server
logic (SVC-003).

## Design references

ADR-003 (one contract module per service, endpoint groups, no hand-written routes),
ADR-007 (explicit codecs), ADR-020 (`securityIn(header("X-Kui-Principal"))` on every
`/internal/v1` endpoint), `ARCHITECTURE.md` §5, PLAN §18 (`contract` must not depend on
`domain`).

## Public Scala signatures to implement

```scala
package kui.cluster.contract.dto

final case class PingResponse(message: String, at: Instant, service: String)
object PingResponse:
  given io.circe.Codec[PingResponse]
  given sttp.tapir.Schema[PingResponse]
```

```scala
package kui.cluster.contract

object ClusterEndpoints:
  val ping: Endpoint[SignedPrincipal, String, ErrorEnvelope, PingResponse, Any] =
    KuiEndpoint.internal
      .get
      .in("internal" / "v1" / "ping")
      .in(query[String]("message").description("Echoed back, 1..128 characters"))
      .out(jsonBody[PingResponse])
      .name("cluster.ping")
      .summary("Echo endpoint used to prove the contract → client → gateway → browser chain")
      .tag("cluster")

  /** Every endpoint this service serves. The gateway and the OpenAPI generator read this. */
  val all: List[AnyEndpoint] = List(ping)
```

`.name(...)` is the operation id OBS-002 requires; the suite below fails if any endpoint in
`all` lacks one.

## Library coordinates

Same as `libs/contracts-core` (tapir-core, tapir-json-circe, tapir-iron, circe, iron-circe,
`scala-java-time` on JS). Plus `moduleDeps` on `libs.contractsCore` and `libs.securityCore`.
**No** dependency on `services.cluster.domain` — `checkArchitecture` rule A2 enforces it.

## Tests required

- `PingDtosSuite` (unit + golden, cross-compiled):
  - `pingResponseMatchesTheGoldenDocument` (encode and decode).
  - `everyEndpointHasAnOperationIdAndASummary` — iterate `ClusterEndpoints.all`.
  - `everyInternalEndpointRequiresThePrincipalHeader` — iterate `all`, assert the security
    input is present. This is the test that stops a future endpoint from being added
    unauthenticated.
  - `endpointPathsStartWithInternalV1`.
