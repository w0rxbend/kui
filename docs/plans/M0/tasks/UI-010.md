# UI-010 — Capability-driven navigation, `FeatureGate` and fallback panel

- **ID:** UI-010
- **Title:** Capability-driven navigation, `FeatureGate` and fallback panel
- **Milestone / Feature:** M0 / KU-002, KU-003
- **Owner role:** Frontend Architect
- **Size:** L
- **Dependencies / blocked by:** UI-008, UI-009, GW-005

## Goal (user value)

The milestone's visible promise: when a service dies, its sidebar entry dims within seconds,
clicking it explains what is wrong and when it started, offers a retry, and says what still
works — while the rest of KUI keeps working normally.

## Scope

1. **Sidebar rendering rules** (ADR-032, exactly):
   - `NotConfigured` → the entry is **hidden**.
   - `Forbidden` → shown, **disabled**, tooltip "You do not have permission to view X";
     hidden instead when `kui.ui.hideForbidden` is set.
   - `Unavailable` → shown **dimmed and clickable**; the route renders the fallback panel.
   - `Degraded` → shown normally with an **amber dot** and a tooltip carrying the reason.
   - `Ready` → shown normally.
2. `FeatureGate` — wraps a feature route: given the `FeatureState`, it renders the feature
   (loading it lazily first, UI-007) or the fallback panel, and it never renders a blank frame
   between states (a spinner with the feature's name).
3. `FeatureFallbackPanel` — the ADR-032 panel: the reason code rendered as human text, the
   message, `since` as both absolute and relative time, a **Retry now** button calling
   `POST /api/v1/capabilities/{service}/probe`, and a "what still works" list built from the
   other features' current states.
4. `CapabilityBanner` — a top-of-content banner when the capability stream is disconnected or
   when any feature is degraded, with the connection state from UI-006.
5. `ActionPermissionWrapper` (ADR-032): one wrapper that disables a write action for either
   an RBAC or a capability reason and shows **one merged tooltip**. In M0 only the capability
   half is live; the RBAC parameter exists.
6. Wiring the toast rule from UI-008 into the shell's toast host.

## Non-goals

No per-cluster navigation (M1). No RBAC (M6). No real feature content (UI-012).

## Design references

ADR-032 (this task is the ADR's implementation; every rendering rule above is quoted from it),
ADR-012 (loading is triggered when the capability is anything but `NotConfigured`),
feature matrix KU-002, KU-003, KU-009; PLAN §16.5 as amended by ADR-032.

## Public Scala signatures to implement

```scala
package kui.ui.shell.nav

object Navigation:
  /** Renders one item per registered feature, ordered by NavEntry.order, applying the
    * ADR-032 rules. Takes states as a Signal so a capability change re-renders exactly the
    * affected item. */
  def apply(
      features: List[(NavEntry, Signal[FeatureState])],
      current: Signal[Page],
      hideForbidden: Boolean
  ): HtmlElement

package kui.ui.shell.feature

object FeatureGate:
  def apply(
      feature: LazyFeature,
      state: Signal[FeatureState],
      page: Signal[Page],
      probe: Observer[Unit]
  ): Signal[HtmlElement]

object FeatureFallbackPanel:
  def apply(
      featureLabel: String,
      reason: DegradedReason,
      since: Option[Instant],
      retry: Observer[Unit],
      whatStillWorks: Signal[List[String]]
  ): HtmlElement

package kui.ui.kernel.component

object ActionPermissionWrapper:
  /** One merged tooltip for the two independent reasons an action can be unavailable. */
  def apply(
      action: HtmlElement,
      capability: Signal[FeatureState],
      permitted: Signal[Boolean] = Val(true),
      capabilityMessage: FeatureState => Option[String] = default
  ): HtmlElement
```

**Reason-code display text** is a `Messages` object (ADR-024: strings centralized per module,
no i18n runtime). Each `ReasonCode` gets one sentence written for an operator, e.g.
`UpstreamUnavailable` → "The cluster service is not responding." Add the table to
`docs/frontend/README.md`.

```
# with the compose stack up
$ docker stop kui-cluster
# within ~10 s: the "Clusters" entry dims; a toast appears once

```

## Tests required

- `NavigationSuite` (DOM, exhaustive over `FeatureState`):
  - one assertion per ADR-032 rendering rule (hidden / disabled+tooltip / dimmed+clickable /
    amber dot / normal) — five rows, mirroring UI-008's derivation table.
  - `hideForbiddenHidesForbiddenEntries`.
  - `orderFollowsNavEntryOrderAndIsStableAcrossStateChanges` — an entry must not jump around
    when its state changes.
  - `aStateChangeRerendersOnlyTheAffectedItem`.
- `FeatureGateSuite` (DOM):
  - `loadsTheFeatureWhenTheStateBecomesAnythingButNotConfigured` — and **does not** load it
    while `NotConfigured` (the ADR-012 promise).
  - `rendersTheFallbackPanelWhenUnavailableWithoutLoadingTheFeature` — clicking a dimmed
    entry must not download the module.
  - `showsANamedSpinnerWhileLoadingAndNeverABlankFrame`.
  - `aFailedImportRendersTheFallbackWithARetryThatWorks`.
- `FallbackPanelSuite` (DOM):
  - `showsTheReasonTheMessageAndBothTimeFormats`.
  - `retryCallsProbeAndShowsProgress`; a failed probe shows an inline error, not a toast storm.
  - `whatStillWorksListsOnlyReadyFeatures`.

## Observability

Not applicable (browser).

## Degraded behavior

This task *is* the degraded behaviour. Its own edge case: when the capability stream is
disconnected, entries keep their last known state, the banner says so, and nothing is
silently marked available — an unknown state must never be rendered as `Ready`.
