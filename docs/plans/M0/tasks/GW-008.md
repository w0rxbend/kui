# GW-008 — Static asset serving, base path and SPA fallback

- **ID:** GW-008
- **Title:** Static asset serving, base path and SPA fallback
- **Milestone / Feature:** M0 / NX-005, KU-004
- **Owner role:** Chief Architect
- **Size:** M
- **Dependencies / blocked by:** GW-001

## Goal (user value)

The browser gets the shell from the same origin as the API — no CORS, no second server, no
separate deployment — and it works when KUI is mounted at `https://example.com/kui/` behind a
reverse proxy.

## Scope

1. `GET /ui/**` serves the linked frontend from the classpath (`tapir-files`), with:
   - `index.html` returned for any path that does not match a file (SPA deep links, required
     by Waypoint — `research/scala/frontend-research.md` §3.4).
   - correct MIME types, in particular `text/javascript` for `.js` **modules** and
     `application/json` for the import map.
   - `Cache-Control: public, max-age=31536000, immutable` for hashed asset names and
     `no-cache` for `index.html`, so a deploy is picked up immediately but assets are not
     re-fetched.
2. `GET /` redirects to `<basePath>/ui/`.
3. Base path support (NX-005): every served URL, the injected `<base href>` and the API base
   the shell reads are derived from `server.basePath`. The shell must not hard-code `/api/v1`.
4. Runtime configuration injection: `index.html` is served with a small
   `<script id="kui-bootstrap" type="application/json">` block containing
   `{ "basePath": "...", "apiBase": "...", "buildVersion": "..." }` so the frontend needs no
   build-time knowledge of the deployment.
5. The ES module import map for the npm packages ADR-025 will need (empty in M0, but the
   mechanism and its `Content-Type` are proven now).

## Non-goals

No bundling step (ADR-012: `fastLinkJS` output is served as static ES modules). No CDN, no
compression tuning beyond enabling gzip for text assets. No service worker.

## Design references

ADR-012 (served as static ES modules; no Vite in M0), ADR-011 (`the gateway serves index.html
for /ui/**`), feature matrix NX-005, `ARCHITECTURE.md` §12, PLAN §20.7.

## Acceptance criteria

```
$ curl -s -o /dev/null -w '%{http_code} %{content_type}\n' localhost:8080/ui/
200 text/html
$ curl -s -o /dev/null -w '%{http_code} %{content_type}\n' localhost:8080/ui/main.js
200 text/javascript
$ curl -s -o /dev/null -w '%{http_code}\n' localhost:8080/ui/clusters/some/deep/link
200                       # index.html, not 404
$ curl -s localhost:8080/ui/ | grep kui-bootstrap
<script id="kui-bootstrap" type="application/json">{"basePath":"","apiBase":"/api/v1",...}</script>
$ curl -s -o /dev/null -w '%{http_code} %{redirect_url}\n' localhost:8080/
302 http://localhost:8080/ui/
```

With `KUI_SERVER_BASEPATH=/kui`, every URL above works under `/kui` and the bare paths 404.

## Tests required

- `StaticRoutesSuite` (unit + integration on a bound port):
  - `servesIndexForAnUnknownUiPath` — the SPA deep-link rule.
  - `servesARealAssetWithTheRightContentType` — table over `.js`, `.css`, `.json`, `.svg`,
    `.woff2`.
  - `doesNotServeIndexForAnUnknownApiPath` — `/api/v1/nope` is a 404 envelope, not HTML.
    (Getting this wrong makes every API typo look like a working request that returns HTML.)
  - `indexIsNoCacheAndHashedAssetsAreImmutable`.
  - `bootstrapJsonMatchesTheConfiguredBasePath` — property over generated base paths.
  - `pathTraversalIsRefused` — `/ui/../../etc/passwd` and its encoded variants return 400 or
    404, never a file.
  - `basePathIsAppliedToEveryServedUrlAndTheRedirect`.

## Observability

Static asset requests are excluded from `kui.http.server.duration` (they would dominate) but
counted separately as `kui.http.server.duration {route="static"}` with a single label value,
so an operator can still see traffic without cardinality explosion.

## Degraded behavior

If the frontend assets are missing from the classpath (a backend-only build), `/ui/**` returns
a plain 503 HTML page saying the UI is not bundled, rather than a stack trace or an empty
200 — a developer running the gateway alone must get a comprehensible message.
