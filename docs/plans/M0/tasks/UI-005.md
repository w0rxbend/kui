# UI-005 — Kernel `ApiClient` over sttp `FetchBackend`

- **ID:** UI-005
- **Title:** Kernel `ApiClient` over sttp `FetchBackend`
- **Milestone / Feature:** M0 / KU-009, OT-005
- **Owner role:** Frontend Architect
- **Size:** M
- **Dependencies / blocked by:** UI-001, KERN-005

## Goal (user value)

The browser calls the gateway through typed clients derived from the same contracts the server
implements — so a renamed field is a compile error, not a runtime surprise — and every call
carries the CSRF token and correlation id without a single feature remembering to add them.

## Scope

1. `ApiClient` wrapping sttp 4's `FetchBackend` and Tapir's `SttpClientInterpreter`:
   - base URL from the `kui-bootstrap` JSON block GW-008 injects (never hard-coded);
   - `credentials: include` so the session cookie travels;
   - `X-Kui-Csrf` added to every non-GET request from the token in `AuthState`;
   - a client-generated request id echoed as `X-Kui-Request-Id` for support correlation
     (the gateway still generates the authoritative correlation id — GW-001);
   - `ErrorEnvelope` decoded into a typed `ApiError`, including the transport cases.
2. `AuthState` — one of the five kernel-owned `Var`s: the current `Principal`, the CSRF token
   and the auth type, populated from `GET /api/v1/auth/me` at startup and after a 401.
3. Interception rules: `401` sets `AuthState.expired` (M6 shows a login screen; M0 retries
   `auth/me` once); `403` is surfaced as `ApiError.Forbidden` for the caller to render;
   a network failure or a 5xx becomes `ApiError.Unreachable`/`ApiError.Upstream`, which
   UI-011 turns into the full-screen "cannot reach gateway" state when it affects the shell's
   own calls.

## Non-goals

No caching (UI-006). No SSE (UI-006). No retry policy in the browser — retrying is the user's
decision through explicit UI (ADR-032's "Retry now"), because silent browser retries hide
outages.

## Design references

ADR-011 §3.6 ("a kernel `ApiClient` adds the CSRF header, correlation id and 401/403
interception"), ADR-019 (the CSRF token comes from `/auth/me`), ADR-003 (`tapir-sttp-client4`
with `FetchBackend`), ADR-034 (render by `code`), `research/scala/frontend-research.md` §3.6.

## Public Scala signatures to implement

```scala
package kui.ui.kernel.api

/** Read once from the <script id="kui-bootstrap"> block GW-008 injects. */
final case class Bootstrap(basePath: String, apiBase: String, buildVersion: String)
object Bootstrap:
  def read(): Bootstrap        // falls back to ("", "/api/v1", "dev") when absent

enum ApiError:
  case Envelope(code: String, message: String, details: List[ErrorDetail], correlationId: String, retryable: Boolean)
  case Unreachable(cause: String)          // network failure, DNS, offline
  case Timeout
  case Decoding(cause: String)             // a response the contract could not parse
  def isAuth: Boolean
  def isForbidden: Boolean

trait ApiClient:
  /** Runs a Tapir endpoint. `EventStream` rather than `Future` so callers stay in Airstream. */
  def call[I, O](endpoint: PublicEndpoint[I, ErrorEnvelope, O, Any], input: I)
      : EventStream[Either[ApiError, O]]
  def callSecure[I, O](endpoint: Endpoint[?, I, ErrorEnvelope, O, Any], input: I)
      : EventStream[Either[ApiError, O]]

object ApiClient:
  def make(bootstrap: Bootstrap, auth: AuthState): ApiClient

package kui.ui.kernel.state

object AuthState:
  val principal: Var[Option[Principal]]
  val csrfToken: Var[Option[String]]
  val authType: Var[String]
  val expired: EventBus[Unit]
  def refresh(client: ApiClient): EventStream[Unit]     // calls GET /api/v1/auth/me
```

## Observability

Browser-side telemetry is out of scope for M0. The `X-Kui-Request-Id` header is the hook a
future support-bundle feature uses; document it, do not build on it yet.

## Degraded behavior

Every call returns `Either`, never a failed `EventStream` — an unhandled Airstream error would
blank a page (ADR-011 §3.6). Assert this: a stub that throws still yields a `Left`.

## Docs to update

`docs/frontend/README.md`: how a feature makes an API call, and the rule that features never
construct a backend themselves.

## Deviations

Recorded during implementation. None of them changes what the task delivers; each records a place
where the specification could not be implemented exactly as written.

1. **`callSecure` takes the security input explicitly.** The spec's signature is
   `callSecure[I, O](endpoint: Endpoint[?, I, ErrorEnvelope, O, Any], input: I)`. A wildcard for the
   security type makes the method uncallable: the caller has no way to supply a value of a type the
   signature refuses to name. The implemented signature is
   `callSecure[A, I, O](endpoint: Endpoint[A, I, ErrorEnvelope, O, Any], security: A, input: I)`.
   For every KUI endpoint today `A` is `Unit`, because the session travels in a cookie the browser
   attaches by itself; the parameter is there so M6's token-based flows have somewhere to put a
   token without changing the interface.

2. **`AuthState.refresh` takes a fetch function, not an `ApiClient`.** The spec has
   `def refresh(client: ApiClient): EventStream[Unit]`, which requires the kernel to name the
   `GET /api/v1/auth/me` endpoint. That endpoint is defined in `services/gateway/contract`, a module
   that sits *above* the kernel — the kernel is the bottom of the frontend and may not depend on any
   one service's wire shapes (the same rule the previous lane-F task applied to `UnavailableReason`).
   `refresh` therefore takes `() => EventStream[Either[ApiError, AuthInfo]]`, and the shell supplies
   it during start-up. `AuthInfo` is a kernel-owned record of `(principal, csrfToken, authType)`.

3. **`refresh` answers with the outcome, not with `Unit`.** `EventStream[Unit]` gives the caller no
   way to tell a refresh that failed from one that succeeded, which the shell needs in order to
   decide whether to show the sign-in state. It returns `EventStream[Either[ApiError, AuthInfo]]`.

4. **`ApiError` has no `Upstream` case.** The scope section mentions `ApiError.Upstream` for a 5xx,
   but the enum it specifies does not list one, and it does not need one: a 5xx from KUI carries an
   `ErrorEnvelope` (ADR-034), so it decodes to `ApiError.Envelope` with the server's own code and
   `retryable` flag. A 5xx that is *not* a KUI response — a proxy's HTML error page — becomes
   `ApiError.Decoding`, which the spec already defines as "a response the contract could not parse".
   Two further predicates were added to make the distinction usable without a `match` at every call
   site: `isTransport` (what UI-011 counts towards the full-screen state) and `isRetryable`.

5. **The `sendsCredentialsSoTheSessionCookieTravels` test asserts the option, not a request.**
   `credentials` is an argument to the browser's `fetch`, not a header, so it never appears on a
   request object and `BackendStub` cannot observe it. The suite pins
   `ApiClient.BrowserFetchOptions` instead, which is the line that would be deleted by accident.

6. **The base-path property is over `Bootstrap.absoluteApiBase`, with a separate example test for
   the request.** An `EventStream` cannot be awaited inside a synchronous ScalaCheck property on
   Scala.js. The URL-composition rule — the part with the off-by-one-slash failure modes a property
   is worth writing for — is tested as a property; that the composed URL is what the request
   actually goes to is an ordinary asynchronous test
   (`aDeploymentUnderAPathPrefixSendsTheRequestToThatPrefix`).
