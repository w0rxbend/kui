# CFG-001 — `libs/config`: Ciris model, loaders and precedence

- **ID:** CFG-001
- **Title:** `libs/config`: Ciris model, loaders and precedence
- **Milestone / Feature:** M0 / KU-007
- **Owner role:** Principal Scala Engineer
- **Context / service:** `libs/config`
- **Size:** L
- **Dependencies / blocked by:** KERN-002

## Goal (user value)

An operator who mistypes a key, forgets a secret or writes an invalid URL is told **all** of
it at once, at startup, with the key names — instead of discovering it at 3 a.m. through a
`NullPointerException`.

## Scope

The M0 slice of the configuration model from PLAN §24 and `ARCHITECTURE.md` §10:

```yaml
kui:
  server:    { host, port, basePath }
  gateway:   { services: { <name>: { url, timeout, maxConcurrent } },
               readinessIntervalMs, principalKeys[], cors: { enabled, origins[] } }
  auth:      { type: disabled }                 # only `disabled` is legal in M0
  telemetry: { otlpEndpoint?, prometheusPort?, logFormat: json|text, hashUserIds }
```

`kui.clusters[]` and `kui.rbac` are **declared as empty-by-default sections with a TODO
pointing at M1/M6** so the shape exists, but no cluster field is modelled here.

1. Explicit `ConfigValue` definitions per field (ADR-013: hand-written, no derivation), each
   naming its `KUI_*` environment key and its YAML path.
2. Precedence CLI flags → environment → YAML file(s) → defaults, implemented once in
   `KuiConfigSource` and property-tested.
3. Accumulated validation: a load failure lists every problem, one line per key, with the key
   name, the offending value (redacted when the field is a `Secret`) and the expectation.
4. Unknown-key detection: a YAML key under `kui.` that maps to nothing is an error, not a
   silent ignore (this is the "configuration with an unknown key fails at startup" exit
   criterion, stated in M1 but implemented here).
5. `Secret[A]` fields resolve from literal values, `env:NAME` and `file:/path` references.

## Non-goals

No Kafbat legacy env-key mapping (`KAFKA_CLUSTERS_0_*`) — that is the migration tool in M8;
this task only leaves a documented extension point. No `ConfigStore[F]` port or its file /
Kubernetes adapters (ADR-036, M1 with the cluster registry). No hot reload. No wizard.

## Design references

ADR-013 (Ciris, precedence, hand-written loaders, `Secret`), PLAN §24, `ARCHITECTURE.md` §10
and §14 (URL policy: `http`/`https` only, no link-local, no metadata ranges), ADR-019
(`cors` off by default), ADR-020 (`principalKeys[]` shape).

## Public Scala signatures to implement

```scala
package kui.config

final case class ServerConfig(host: Host, port: Port, basePath: String)
final case class UpstreamServiceConfig(url: SafeUrl, timeout: FiniteDuration, maxConcurrent: PositiveInt)
final case class CorsConfig(enabled: Boolean, origins: List[String])
final case class PrincipalKeyConfig(kid: String, key: Secret[String], notBefore: Instant)
final case class GatewayConfig(
    services: Map[ServiceId, UpstreamServiceConfig],
    readinessInterval: FiniteDuration,
    principalKeys: List[PrincipalKeyConfig],
    cors: CorsConfig
)
enum LogFormat { case Json, Text }
final case class TelemetryConfig(
    otlpEndpoint: Option[SafeUrl],
    prometheusPort: Option[Port],
    logFormat: LogFormat,
    hashUserIds: Boolean
)
final case class KuiConfig(
    server: ServerConfig,
    gateway: GatewayConfig,
    telemetry: TelemetryConfig
)

object KuiConfigSource:
  /** Loads with the documented precedence. Returns every error, not the first one. */
  def load[F[_]: Async](args: List[String], files: List[Path]): F[Either[ConfigErrors, KuiConfig]]

final case class ConfigProblem(key: String, problem: String, source: ConfigSourceName)
final case class ConfigErrors(problems: NonEmptyList[ConfigProblem]):
  def render: String        // one problem per line, ready to print to stderr and exit(1)

/** A URL that passed ARCHITECTURE.md §14: http/https only, no userinfo, host is not a
  * loopback/link-local/metadata address unless explicitly allow-listed. */
opaque type SafeUrl = String
object SafeUrl:
  def from(raw: String, policy: UrlPolicy): Either[ValidationError, SafeUrl]
  extension (u: SafeUrl) def value: String

final case class UrlPolicy(allowLoopback: Boolean, allowPrivate: Boolean, allowedSchemes: Set[String])
object UrlPolicy:
  val Strict: UrlPolicy        // production default
  val Dev: UrlPolicy           // allows loopback and private ranges; used by compose and tests
```

**Defaults, decided here:** `server.host = 0.0.0.0`, `server.port = 8080`,
`server.basePath = "/"`, `gateway.readinessInterval = 10s`, per-service `timeout = 10s`,
`maxConcurrent = 32`, `cors.enabled = false`, `telemetry.logFormat = Json`,
`telemetry.hashUserIds = true`.

## Acceptance criteria


Behavioural acceptance, asserted by tests and reproducible by hand once SVC-004 exists:

```
$ ./mill services.cluster.app.run -- --config libs/config/test/resources/config/multiple-errors.yaml
kui.server.port: expected 1..65535, got 0            (file: multiple-errors.yaml)
kui.gateway.services.cluster.url: expected http or https, got ftp://x   (file: ...)
kui.telemetry.logFormat: expected json|text, got yaml (file: ...)
# exit code 1, three lines, no stack trace
```

## Tests required

- `PrecedenceSuite` (unit + property): CLI beats env beats file beats default, for a
  representative field; a value present only in the file is used; a value present nowhere
  falls back to the documented default (table over every field with a default).
- `ValidationSuite` (unit):
  - `reportsEveryProblemNotJustTheFirst` — the three-error fixture yields three problems.
  - `rejectsUnknownKeys` — `kui.server.prot: 8080` names the key and suggests nothing (a
    typo-suggestion feature is explicitly out of scope).
  - `secretValuesAreRedactedInProblemMessages` — a bad `file:` reference to a secret does not
    print the file's contents.
  - `authTypeOtherThanDisabledIsRejectedInM0` — with a message pointing at M6.
- `UrlPolicySuite` (unit + property): rejects `ftp://`, `http://user:pass@host`,
  `http://169.254.169.254/` (metadata), `http://[::1]/` and `http://10.0.0.1/` under
  `Strict`; accepts them under `Dev`; a property asserting no accepted URL contains userinfo.

## Observability

At startup the loaded configuration is logged once at INFO as a single structured entry with
every `Secret` rendered as `***` — CFG-002 asserts this.

## Degraded behavior

There is none: an invalid configuration is a startup failure. A service must never start with
a partially valid configuration, because a "mostly working" gateway is harder to diagnose than
one that refused to boot.
