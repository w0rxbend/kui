# CFG-002 — Secret redaction proof across log, trace and JSON

- **ID:** CFG-002
- **Title:** Secret redaction proof across log, trace and JSON
- **Milestone / Feature:** M0 / KU-007 (exit criterion)
- **Owner role:** Security Engineer
- **Context / service:** `libs/config`, `libs/observability`, `libs/contracts-core`
- **Size:** S
- **Dependencies / blocked by:** CFG-001, OBS-001, KERN-004

## Goal (user value)

The milestone exit criterion "a `Secret[String]` field logged, traced, or returned from any
endpoint renders as `***`" is proven by one test that covers all four sinks at once, so a
future change that adds a fifth sink has an obvious place to be covered.

## Scope

One suite that takes a single fixture value — the string `hunter2-DO-NOT-LEAK` wrapped in
`Secret` inside a realistic config object — and asserts it never appears in:

1. **A log line.** Log the config through the real `StructuredLogger` with the JSON encoder;
   capture the encoded output; assert the raw string is absent and `***` is present.
2. **A span attribute.** Record a span with the config rendered into an attribute using the
   documented helper; assert via `otel4s-oteljava-testkit` that no attribute value contains it.
3. **An error envelope.** Construct a `KuiError` whose construction site had access to the
   secret; assert `ErrorEnvelope.of(...)` output does not contain it.
4. **An HTTP response body.** Serve a stub endpoint returning the config DTO through the real
   Tapir/Circe stack; assert the response body contains `***`.

Plus the negative control: the same fixture *without* the `Secret` wrapper does appear, which
proves the test can fail.

## Non-goals

No `/api/v1/config` endpoint (M8's config wizard). No masking of message payloads (ADR-023,
M3). No log scrubbing filter — redaction is a property of the type, not of the encoder
(ADR-008 "Secret redaction is enforced by `Secret[A]`'s `toString`, not by the log encoder").

object RedactionAssertions:
  /** Fails with the location of the leak when `haystack` contains `needle`. Truncates the

  def assertNoLeak(haystack: String, needle: String)(using munit.Location): Unit

## Deviations

1. **`SecretRedactionSuite` lives in `libs/http/test`, not `libs/config/test`.** The four sinks span
   four modules — the configuration model, the log encoder, the tracer and the Tapir/Circe HTTP
   stack — and `libs/config` is the lowest of them: it can see none of the other three, so a suite
   there could only test the sink it already owns. `libs/http` is the only module that depends on
   all four, so it is the only place the exit criterion can actually be proved. The suite's Scaladoc
   says so, and says where to add a fifth sink.

2. **`RedactionAssertions.assertRedactedAndNoLeak` was added** beside the two the spec names. Every
   case wants both halves — the secret is absent *and* something says a value was withheld — and an
   absent field is a different bug from a redacted one: a reader has to be able to tell "there is a
   value and you may not see it" from "there is no value".

3. **The negative control is doubled.** As well as asserting that an unwrapped value does appear, the
   suite asserts that the leak report itself never prints the needle, and that it says where the
   leak was. A leak test whose failure message copies the secret into a CI log has recreated the
   problem it was written to prevent.

4. **Two extra sinks are covered:** an error envelope served through the real Tapir stack (as
   distinct from an envelope built in memory), and the "logged once at INFO" requirement from
   CFG-001's own observability section, which had no other home.
