# GW-002 — Gateway `ServiceClient[F]` and its sttp implementation

- **ID:** GW-002
- **Title:** Gateway `ServiceClient[F]` and its sttp implementation
- **Milestone / Feature:** M0 / KU-005, KU-001
- **Owner role:** Chief Architect
- **Context / service:** `services/gateway/application`
- **Size:** M
- **Dependencies / blocked by:** GW-001, HTTP-003

## Goal (user value)

The abstraction that makes all-in-one honest: the gateway's routing, capability tracking and
aggregation code is byte-for-byte the same whether the service is across the network or in the
same JVM (ADR-005), so a bug cannot hide in the shape nobody tests.

## Scope

1. `ServiceClient[F]` — the port: "call this Tapir endpoint of this service and give me
   `Either[KuiError, Out]`", plus a streaming variant returning `Stream[F, SseEvent]`.
2. `SttpServiceClient` — the distributed implementation: a `tapir-sttp-client4` interpreter on
   top of HTTP-003's resilient backend, one `UpstreamClient` per configured service (so
   bulkheads and breakers are per service, PLAN §16.4), signing the principal per call
   (KERN-006) and injecting the standard headers of `ARCHITECTURE.md` §5.
3. `ServiceClients[F]` — the registry keyed by `ServiceId`, built from
   `GatewayConfig.services`, exposing `circuitStates: Stream[F, CircuitEvent]` merged across
   all upstreams (GW-004 consumes it).

## Non-goals

`InProcessServiceClient` is AIO-001's job (it needs the services' server logic, which the
gateway must not depend on). No routing (GW-006). No caching.

## Design references

ADR-005 (the two implementations, in-process interprets the same endpoints), ADR-037
(one resilience implementation), ADR-020 (per-call signing with the request digest),
`ARCHITECTURE.md` §5 (the header table), §11.

## Public Scala signatures to implement

```scala
package kui.gateway.application.client

final case class CallContext(
    principal: Principal,
    correlationId: CorrelationId,
    cluster: Option[ClusterId]

trait ServiceClient[F[_]]:
  def service: ServiceId
  def call[I, O](endpoint: Endpoint[SignedPrincipal, I, ErrorEnvelope, O, Any], input: I)
                (ctx: CallContext): F[Either[KuiError, O]]
  def stream[I](endpoint: Endpoint[SignedPrincipal, I, ErrorEnvelope, ?, Fs2Streams[F]], input: I)
               (ctx: CallContext): Stream[F, SseEvent]

trait ServiceClients[F[_]]:
  def get(id: ServiceId): Option[ServiceClient[F]]
  def all: List[ServiceClient[F]]
  def circuitStates: Stream[F, CircuitEvent]
```

```scala
package kui.gateway.api.client

object SttpServiceClient:
  def resource[F[_]: Async: Tracer](
      service: ServiceId,
      config: UpstreamServiceConfig,
      principals: PrincipalCodec[F],
      telemetry: Telemetry[F]
  ): Resource[F, ServiceClient[F]]
```

Headers set on every call, asserted by the test suite:
`X-Kui-Principal` (signed, `aud` = the target service, `req` = digest of method + path + body),
`X-Kui-Correlation-Id`, `traceparent`, and `X-Kui-Cluster-Id` when `ctx.cluster` is present.

## Tests required

- `SttpServiceClientSuite` (unit + failure, against `StubUpstream` from `libs/testkit`):
  - `sendsTheFourStandardHeaders` — asserts each one's presence and shape.
  - `signsWithTheTargetServiceAsAudience` — decode the token and check `aud`.
  - `requestDigestCoversMethodPathAndBody` — a changed body yields a different token.
  - `mapsAnErrorEnvelopeResponseBackToTheOriginalKuiError` — a 404 `KUI-TOPIC-NOT-FOUND` from
    the upstream becomes `ApplicationError.NotFound`, not a generic `Upstream`.
  - `mapsATransportFailureToInfrastructureError` — table over refused, timeout, breaker open.
  - `doesNotForwardTheBrowsersHeaders` — a `Cookie` or `Authorization` on the inbound request
    never reaches the upstream.
  - `oneSlowServiceDoesNotDelayAnother` — two clients, independent bulkheads.

## Observability

Each call is a child span named `kui.gateway.call.<service>.<operation>`;
`kui.upstream.duration` carries `upstream = <serviceId>`; the correlation id is on both the
span and the outbound header, which is what makes a cross-process trace readable.

## Degraded behavior

Every failure is a typed `KuiError`, never an exception escaping into the route layer. A
service with no configured URL yields `ApplicationError.Unsupported("service not configured")`,
which the registry (GW-003) turns into `CapabilityState.NotConfigured` rather than
`Unavailable` — the distinction users care about (ADR-032).
