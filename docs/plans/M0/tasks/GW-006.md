# GW-006 — Contract-derived proxy route to the sample service

- **ID:** GW-006
- **Title:** Contract-derived proxy route to the sample service
- **Milestone / Feature:** M0 / KU-005, KU-006
- **Owner role:** Chief Architect
- **Size:** M
- **Dependencies / blocked by:** GW-002, SVC-002

## Goal (user value)

The browser reaches a service through `/api/v1/...` without the gateway containing a single
hand-written path — proving ADR-003's rule ("routes are derived from contract endpoint
metadata; hand-written path lists are forbidden") on real code before eleven services exist.

## Scope

1. `ContractRouting.derive(service, endpoints)` — turns a service's `contract` endpoint list
   into gateway routes by rewriting the path prefix `/internal/v1` → `/api/v1`, keeping every
   input and output type, and delegating to the service's `ServiceClient`.
2. The M0 route: `GET /api/v1/ping?message=` proxies to the cluster service's
   `/internal/v1/ping`.
3. Failure translation: an upstream `KuiError` reaches the browser as the same envelope with
   the gateway's correlation id; a transport failure becomes `KUI-UPSTREAM-UNAVAILABLE` (503)
   and **also** reports to the capability registry, so a user-visible failure and the sidebar
   state can never disagree.
4. Streaming passthrough: the same derivation handles an SSE endpoint by re-streaming without
   buffering (no such service endpoint exists in M0, so this path is covered by a stub
   endpoint in the test suite — writing it now means M3 does not have to).

## Non-goals

No RBAC pre-check (M6 — leave the named seam `RbacPreCheck.allowAll` so M6 replaces one
function). No aggregation endpoints (M1+). No caching. No request-body transformation.

## Design references

ADR-003 (contract-derived routing), ADR-004 §3, `ARCHITECTURE.md` §5 (`/api/v1` public,
`/internal/v1` internal), PLAN §20.3, ADR-037 (transport failures).

## Public Scala signatures to implement

```scala
package kui.gateway.api.routing

trait RbacPreCheck[F[_]]:
  /** M0: always allowed. M6 replaces this implementation with Rbac.decide. */
  def check(principal: Principal, endpoint: AnyEndpoint, cluster: Option[ClusterId]): F[Either[KuiError, Unit]]
object RbacPreCheck:
  def allowAll[F[_]: Applicative]: RbacPreCheck[F]

object ContractRouting:
  /** Public path = internal path with the `/internal/v1` prefix replaced by `/api/v1`.
    * Fails at construction (not at request time) if any endpoint's path does not start with
    * `/internal/v1`, so a malformed contract cannot ship. */
  def derive[F[_]: Async](
      service: ServiceId,
      endpoints: List[AnyEndpoint],
      client: ServiceClient[F],
      registry: CapabilityRegistry[F],
      rbac: RbacPreCheck[F]
  ): Either[String, List[ServerEndpoint[Fs2Streams[F], F]]]
```

## Tests required

- `ContractRoutingSuite` (contract + failure, with a stub `ServiceClient`):
  - `derivesOneRouteForEveryContractEndpoint` — count and paths.
  - `rewritesInternalV1ToApiV1AndNothingElse` — a path containing the string `internal`
    elsewhere is untouched.
  - `rejectsAContractWhosePathIsNotUnderInternalV1` — at construction, with a clear message.
  - `passesQueryAndPathParametersThrough`.
  - `upstreamApplicationErrorsKeepTheirCodeAndStatus`.
  - `transportFailureBecomesUpstreamUnavailableAndReportsToTheRegistry` — asserts both the
    response and the registry report, because "the UI shows an error but the sidebar still
    looks green" is exactly the inconsistency this test prevents.
  - `sseEndpointsAreReStreamedWithoutBuffering` — a stub streaming endpoint emitting 1000
    events with a slow consumer; assert memory stays bounded and events arrive in order.
  - `rbacPreCheckIsConsultedBeforeTheUpstreamCall` — with a denying stub, no upstream request
    is made (the M6 seam is proven now).

## Observability

The gateway span wraps the upstream span, so one trace shows `browser → gateway → cluster`.
The route label in `kui.http.server.duration` is the **public** path template
(`/api/v1/ping`), never the interpolated path — high-cardinality labels are a metrics
outage waiting to happen.

## Degraded behavior

A proxied call that fails never leaves the capability registry ignorant: every
`InfrastructureError` is reported. Conversely, an `ApplicationError` (a 404 for a missing
resource) is **not** reported — a user asking for a topic that does not exist does not mean
the topic service is down. Assert both directions.
