# UI-003 — Kernel primitives A: button, input, select, tag, card, tabs

- **ID:** UI-003
- **Title:** Kernel primitives A: button, input, select, tag, card, tabs
- **Milestone / Feature:** M0 / NX-007
- **Owner role:** Frontend Architect
- **Size:** L
- **Dependencies / blocked by:** UI-002

## Goal (user value)

The first half of the design system: the controls every screen in every later milestone is
built from, keyboard-accessible and themeable, so no feature ever hand-rolls a button.

## Scope

Six hand-written Laminar components (ADR-024 rejects a third-party widget library for M0),
each with: a typed API, a CSS file using only tokens, ARIA roles and keyboard behaviour, a
disabled state, and a DOM test.

| Component | API highlights | Keyboard / ARIA |
| --- | --- | --- |
| `Button` | `variant: Primary/Secondary/Danger/Ghost`, `size`, `loading`, `disabled`, `icon` | native `<button>`, `aria-busy` while loading, focus-visible ring |
| `TextInput` | `value: Var[String]`, `label`, `placeholder`, `error: Signal[Option[String]]`, `hint` | `<label for>`, `aria-invalid`, `aria-describedby` for hint and error |
| `Select` | `options: Signal[List[(A, String)]]`, `selected: Var[Option[A]]` | native `<select>` in M0 (a custom combobox is M2 with the topic filters) |
| `Tag` | `tone: Neutral/Info/Success/Warning/Danger`, `dot`, `onRemove` | `role="status"` when it conveys state |
| `Card` | `header`, `body`, `footer` slots, `elevated` | landmark-free, headings supplied by the caller |
| `Tabs` | `tabs: List[Tab]`, `selected: Var[TabId]`, lazy body rendering | `role="tablist"`, arrow-key navigation, `aria-selected`, roving tabindex |

Plus `Icon` — an inline-SVG set (no icon font, no sprite request) with the ~15 icons M0 needs
(chevrons, close, check, warning, info, refresh, external, search, menu, sun, moon, plus,
copy, dot, spinner).

## Non-goals

`Dialog`, `Drawer`, `Toast`, `Tooltip`, `Breadcrumbs`, `EmptyState`, `DataTable` are UI-004.
No virtualized table (M2). No date picker (M3). No code editor (M3). No Shoelace.

## Public Scala signatures to implement

```scala
package kui.ui.kernel.component

enum ButtonVariant { case Primary, Secondary, Danger, Ghost }
enum Size { case Sm, Md, Lg }

object Button:
  def apply(
      label: Signal[String],
      onClick: Observer[Unit],
      variant: ButtonVariant = ButtonVariant.Secondary,
      size: Size = Size.Md,
      disabled: Signal[Boolean] = Val(false),
      loading: Signal[Boolean] = Val(false),
      icon: Option[SvgElement] = None,
      testId: Option[String] = None            // data-testid, used by E2E-001
  ): HtmlElement

object TextInput:
  def apply(
      value: Var[String],
      label: String,
      placeholder: String = "",
      hint: Option[String] = None,
      error: Signal[Option[String]] = Val(None),
      disabled: Signal[Boolean] = Val(false),
      testId: Option[String] = None
  ): HtmlElement

final case class Tab(id: String, label: String, body: () => HtmlElement)
object Tabs:
  def apply(tabs: Signal[List[Tab]], selected: Var[String], testId: Option[String] = None): HtmlElement
```

**Cross-cutting rules for every primitive**, worth stating once:

- Every component accepts an optional `testId` rendered as `data-testid`; E2E selectors use
  it and never a CSS class, so restyling never breaks a test.
- A disabled control is `disabled` in the DOM (not merely styled), and never fires its
  observer.
- No component owns application state: it takes `Var`/`Signal` from the caller.
- No component reads a colour except through a token.

## Tests required

- `ButtonSuite` (DOM, jsdom + `scala-dom-testutils`): renders the variant class; a disabled
  button does not fire; `loading` sets `aria-busy` and blocks clicks; `testId` reaches the DOM.
- `TextInputSuite` (DOM): two-way binding with the `Var`; `aria-invalid` and
  `aria-describedby` appear exactly when there is an error; the label is associated with the
  input by `for`/`id` (property over generated labels, since ids must be unique per instance).
- `TabsSuite` (DOM): arrow keys move focus and selection; `Home`/`End` jump; only the selected
  panel is in the DOM (lazy bodies); `aria-selected` matches.
- `A11ySuite` (DOM, shared): for every primitive, assert the documented role/attribute set —
  a table with one row per component, so adding a component without its ARIA row fails.

## Degraded behavior

Every primitive must render something usable with CSS missing (see UI-002's rule) and must not
throw when given an empty options list, an empty tab list or a `None` selection.
