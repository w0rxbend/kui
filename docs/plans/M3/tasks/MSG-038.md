# MSG-038 — The produce and resend drawers, with bulk placeholders

- **ID:** MSG-038
- **Title:** The produce and resend drawers
- **Milestone / Feature:** M3 / MP-001, MP-002, MP-003, MP-004, MS-008
- **Owner role:** Frontend Architect
- **Context / service:** `frontend/ui-messages`
- **Size:** L
- **Dependencies / blocked by:** MSG-036

## Goal (user value)

Publish a record without leaving the screen — with the topic's schema validating the payload as it is
typed — and copy a range of records into another topic. Plus the purge action, on the one screen
where it belongs today.

## Scope

1. The produce drawer (MSG-033's `Drawer`): key, value, headers, partition, key and value serdes with
   their parameters, `count`, and "keep contents" on success.
2. Client-side validation against the JSON Schema from `GET .../messages/schema` (SD-004, MSG-013),
   with every error listed at once.
3. Bulk placeholders (MP-002): `{{count}}`, `{{timestamp}}`, `{{uuid}}` expanded **in the browser**,
   producing `count` distinct records, with a preview of the first and last before sending.
4. The resend drawer (MP-003): source topic, partition, offset range, destination topic and optional
   partition, and a "strip headers" toggle, with the range validated against the partition bounds
   shown beside the fields.
5. The purge action with a typed confirmation, on the messages screen only (DEVPLAN §10 D11).

## Non-goals

- No topic-page entry points (M5, with audit).
- No CodeMirror-based editor in M3 unless ADR-025's kernel editor already exists from M2; if it does,
  use it, and if it does not, a plain textarea with the validation list is enough and the upgrade is
  a `TECH_DEBT.md` row. Building an editor here is not this task.
- No server-side templating: the server takes `count` and a record (MSG-022).

## Public Scala signatures to implement

```scala
package kui.ui.messages.produce

/** Expanded in the browser so the user can see exactly what will be sent.
  *
  * `{{count}}` is the 1-based index within this batch, `{{timestamp}}` the epoch millisecond at
  * expansion time (one per record, not one per batch — otherwise a thousand records share a
  * timestamp and are indistinguishable), `{{uuid}}` a fresh v4 per record.
  * An unknown `{{...}}` is left verbatim rather than removed: silently deleting text the user typed
  * is worse than sending it.
  */
object Placeholders:
  def expand(template: String, index: Int, now: Instant, uuid: () => UUID): String
  def preview(template: String, count: Int): (String, String)      // first and last
```

```scala
package kui.ui.messages.produce

object ProduceDrawer:
  def open(cluster: ClusterId, topic: TopicName, prefill: Option[MessageDto]): Unit

object ResendDrawer:
  /** Bounds are fetched and shown before the user types, so an out-of-range value is prevented
    * rather than rejected. */
  def open(cluster: ClusterId, source: (TopicName, PartitionId), range: Option[(Long, Long)]): Unit
```

## ADRs this task must obey

ADR-024 (the design system), ADR-032, ADR-021 (the action is gated by the declared permission, which
always allows while auth is disabled — one wrapper for capability and permission, DC-H5),
ADR-023 (a prefilled "produce like this" carries the **masked** value the browser received, and the
drawer says so: reproducing a masked record would write the mask into the topic, so the value field
is marked and the user must edit it).

## Tests required

- `PlaceholdersSuite`
  - `expandsEachPlaceholder` and `leavesUnknownOnesVerbatim` (property).
  - `timestampAndUuidDifferPerRecord` (property).
  - `countIsOneBased`.
  - `aTemplateWithNoPlaceholderProducesIdenticalRecords` — which is the MP-002 default and must not
    silently become distinct.
- `ProduceDrawerSuite` (jsdom)
  - `validatesAgainstTheSchemaAndListsEveryError`.
  - `keepContentsRetainsTheFormOnSuccessAndClearsWhenOff`.
  - `serdeParametersAppearWhenTheSelectedSerdeDeclaresThem`.
  - `aPrefillFromAMaskedRecordIsMarkedAndTheValueFieldIsFlagged` — the ADR-023 rule above.
  - `emptyValueProducesATombstoneOnlyWhenExplicitlyChosen` — an empty textarea is `""`, and the
    tombstone is a checkbox; conflating them corrupts compacted topics.
  - `focusIsTrappedAndRestored` (inherited from `Drawer`, asserted here for this usage).
  - `submitIsDisabledWhileTheCapabilityIsNotAvailableWithAReason`.
- `ResendDrawerSuite` (jsdom)
  - `showsTheSourcePartitionBoundsBeforeTheUserTypes`.
  - `rejectsAnInvertedOrOutOfRangeRangeInTheForm`.
  - `reportsAPartialCopyWithTheOffsetToResumeFrom` — MSG-022's `ResendResult`, rendered so the
    operator can act on it.
  - `stripHeadersTogglesTheRequestFlag`.
- `PurgeActionSuite`
  - `requiresTypingTheTopicNameToConfirm` — the only destructive action in M3 and there is no audit
    trail yet; a one-click purge is not acceptable.
  - `isHiddenWhenTheClusterIsReadOnlyOrTheOperationIsUnsupported`.

## Degraded behaviour

- Schema endpoint unavailable (registry down): the form falls back to free JSON with a banner saying
  validation is unavailable, and the send is still attempted — the server validates anyway
  (MSG-013), so the worst case is a rejected send with a clear message.
- Produce refused because the cluster is read-only: the action is disabled with the reason in the
  tooltip, one merged tooltip for capability and permission (DC-H5).
- A partial resend: reported as counts plus the resume offset, never as a bare failure.

## Cancellation and shutdown

Closing a drawer aborts any in-flight request it owns. `ProduceDrawerSuite.closingAbortsTheSend`
asserts it — and the scaladoc records that aborting the request does not un-produce a record the
broker already accepted, which is the same honesty MSG-007 requires of the port.
