# MSG-009 — `libs/serde`: the module, the SPI, `DeserializeResult` and the mandatory `Fallback`

- **ID:** MSG-009
- **Title:** `libs/serde`: the module, the SPI, `DeserializeResult` and the mandatory `Fallback`
- **Milestone / Feature:** M3 / SD-001
- **Owner role:** Principal Scala Engineer
- **Context / service:** `libs/serde`
- **Size:** M
- **Dependencies / blocked by:** none

## Goal (user value)

Bytes become readable text, and **a payload nobody can decode is still shown**: the raw bytes as a
string, marked with the reason the intended decoder failed, in a row that renders like every other
row. A message browser that shows an error where a record should be is a message browser that hides
the one record the user was looking for.

## Scope

1. The `libs/serde` Mill module and the `Serde[F]` / `Deserializer[F]` / `Serializer[F]` SPI of
   `ARCHITECTURE.md` §4.4, unchanged in shape.
2. `DeserializeResult(text, kind, properties)` and `DeserializeFailure(serde, cause)`.
3. `FallbackSerde`: the String serde that always succeeds. It is not one serde among many — it is the
   terminal case of resolution and the reason a stream can never fail on a decode.
4. `SerdeName`, `SerdeDescription`, `SerdeParameter`, `SerdeSuggestion`, `SerdeUse`, `Target`,
   `PayloadKind` — the vocabulary the picker in the browser and the registry both use.
5. `Deserializers.attempt`: the one function that runs a deserializer and turns any failure —
   returned or thrown — into a `DeserializeFailure`. Every caller goes through it.

## Non-goals

- No concrete serdes beyond `Fallback` (MSG-010).
- No registry, no resolution order, no configuration (MSG-011).
- No Schema Registry, no Confluent classes. Rule A11 (MSG-047) makes that a build failure here.
- No Java SPI bridge (`libs/serde-kafbat-bridge` is M6+, ADR-028).

## Design references

`ARCHITECTURE.md` §4.4 (the signatures, which this task implements rather than redesigns), ADR-028
(lifecycle and resolution semantics kept from Kafbat: built-ins auto-configured, mandatory `Fallback`,
per-record fallback on failure), ADR-035 ("a failed decode falls back to the String serde and never
aborts the stream"; `DeserializeResult.kind` reaches the client so the table view can flatten JSON).

## Public Scala signatures to implement

```scala
package kui.serde

opaque type SerdeName = String
object SerdeName:
  val Fallback: SerdeName            // "Fallback" — the name Kafbat uses, kept so a migrating user recognises it
  val String: SerdeName
  def fromString(s: String): Either[String, SerdeName]

enum Target  { case Key, Value }
enum SerdeUse { case Deserialize, Serialize }

/** What the browser needs to know to render a payload. `Json` is what makes the table view's
  * flattener applicable; `Text` is everything else. */
enum PayloadKind { case Text, Json }

final case class DeserializeResult(text: String, kind: PayloadKind, properties: Map[String, Json])
final case class DeserializeFailure(serde: SerdeName, cause: String)
final case class SerializeFailure(serde: SerdeName, cause: String)
```

```scala
package kui.serde

trait Serde[F[_]]:
  def name: SerdeName
  def describe: SerdeDescription
  def canDeserialize(topic: TopicName, target: Target): F[Boolean]
  def canSerialize(topic: TopicName, target: Target): F[Boolean]
  def preferable(topic: TopicName, target: Target): F[Boolean]
  def schema(topic: TopicName, target: Target): F[Option[SchemaDescription]]
  def parameters(topic: TopicName, target: Target): F[List[SerdeParameter]]
  def deserializer(topic: TopicName, target: Target): F[Deserializer[F]]
  def serializer(topic: TopicName, target: Target, params: Map[String, String]): F[Serializer[F]]

trait Deserializer[F[_]]:
  def deserialize(headers: List[RawHeader], bytes: Array[Byte])
    : F[Either[DeserializeFailure, DeserializeResult]]

trait Serializer[F[_]]:
  def serialize(input: String, headers: List[RawHeader]): F[Either[SerializeFailure, Array[Byte]]]
```

```scala
package kui.serde

/** Always succeeds. Interprets the bytes as UTF-8 with replacement characters for anything invalid,
  * so a protobuf payload renders as mojibake rather than as an empty cell.
  *
  * This serde is why no browse can fail on a decode. Everything else in `libs/serde` is optional. */
object FallbackSerde:
  def apply[F[_]: Applicative]: Serde[F]

object Deserializers:
  /** Runs a deserializer and converts **both** a returned `Left` and a thrown exception into a
    * `DeserializeFailure`. Nothing else in KUI calls `deserialize` directly.
    *
    * A third-party serde that throws is not a hypothetical: it is the normal failure mode of a
    * decoder handed bytes of the wrong shape, and a stream that propagated it would end a page
    * because one record was odd.
    */
  def attempt[F[_]: Sync](
    d: Deserializer[F], headers: List[RawHeader], bytes: Option[Array[Byte]]
  ): F[Either[DeserializeFailure, DeserializeResult]]

  /** `attempt`, then the fallback on failure. Returns the failure alongside the fallback result so
    * the caller can put it in `deserializeErrors[]` (ADR-035). */
  def withFallback[F[_]: Sync](
    primary: Deserializer[F], fallback: Deserializer[F],
    headers: List[RawHeader], bytes: Option[Array[Byte]]
  ): F[(DeserializeResult, Option[DeserializeFailure])]
```

## ADRs this task must obey

ADR-028 (the SPI shape and the mandatory fallback), ADR-035 (a decode failure is an annotation on a
record, never a stream failure), ADR-007 (explicit codecs — but not here: `libs/serde` has circe for
`properties`, and the *wire* codecs live in `services/message/contract`), ADR-041 A11.

```scala
// The property the whole milestone leans on
forAll { (bytes: Array[Byte]) =>
  val r = FallbackSerde[IO].deserializer(t, Target.Value)
            .flatMap(_.deserialize(Nil, bytes)).unsafeRunSync()
  assert(r.isRight)
}

// A serde that throws does not escape
val boom = new Deserializer[IO] { def deserialize(h, b) = IO.raiseError(new RuntimeException("x")) }
assert(Deserializers.attempt[IO](boom, Nil, Some(Array(1))).unsafeRunSync().isLeft)

// A null payload is not a failure
assertEquals(Deserializers.attempt[IO](boom, Nil, None).unsafeRunSync().map(_.text), Right(""))
```

## Tests required

- `FallbackSerdeSuite`
  - `neverFails` (property over arbitrary byte arrays, including empty and invalid UTF-8).
  - `kindIsAlwaysText` — even for bytes that happen to be JSON. Detecting JSON is the JSON serde's
    job (MSG-010); a fallback that guessed would make "the fallback was used" invisible in the UI.
  - `isIdempotentOverValidUtf8` (property).
- `DeserializersSuite`
  - `attemptCatchesThrownExceptions`.
  - `attemptCatchesReturnedFailures`.
  - `nullBytesDeserializeToTheEmptyStringNotAFailure` — a tombstone is a record, and the seeded topic
    has two of them.
  - `withFallbackReturnsBothTheTextAndTheFailure`.
  - `withFallbackNeverFails` (property over a deserializer generator that fails in every way).

## Observability

- `kui.serde.deserialize.failures` — counter, attributes `serde`, `target`, `topic`. It is the metric
  that tells an operator their default serde is wrong for a topic, which is otherwise only visible as
  a screen full of mojibake.
- No log line per failure: a topic of undecodable records would produce one line per record. The
  failure travels on the record instead.

## Degraded behaviour

This module **is** the degraded behaviour for the whole serde layer, and its contract is:
`deserialize` may return `Left`; `Deserializers.withFallback` may not fail at all. Anything that can
fail is above this line, and everything below it renders.

## Cancellation and shutdown

`Serde[F]` has no lifetime. Serdes that do — the Confluent ones with their HTTP client — are
`Resource`s in MSG-012, acquired by the registry in MSG-011, and this module's types deliberately
carry none so that a pure serde stays pure.
