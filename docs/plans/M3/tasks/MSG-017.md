# MSG-017 — Message domain: the model and its ports

- **ID:** MSG-017
- **Title:** Message domain: the model and its ports
- **Milestone / Feature:** M3 / MS-001, MS-003, MP-001, MP-003, ET-001
- **Owner role:** Domain Architect (message)
- **Context / service:** `services/message/domain`
- **Size:** M
- **Dependencies / blocked by:** MSG-001

## Goal (user value)

Nothing directly. This is the vocabulary every use case, every DTO and every adapter in the milestone
is written in, and the point at which the milestone's rules stop being prose in a plan and become
types that a wrong program will not compile against.

## Scope

1. `services/message/domain`: the request types (`BrowseRequest`, `PageRequest`, `TrackQuery`,
   `ProduceRequest`, `ResendRequest`, `PurgeRequest`) with their invariants enforced in smart
   constructors.
2. `DecodedRecord` — the domain's record: decoded key and value, rendered headers, sizes, serde
   names and the decode failures, which is what every response is mapped from.
3. The ports the application states its needs in: `MessageBrowsePort` (the domain's own view of it),
   `SerdeSource`, `FilterSource`, `ClusterProfileSource`, `MaskingRules`.
4. `docs/domain/message.md`, including the two invariants inherited from
   `libs/kafka/PORT-INVARIANTS.md`.

## Non-goals

- No use cases (MSG-019 onward), no DTOs (MSG-027), no adapters (MSG-025).
- No dependency on `libs/kafka`, `libs/serde` or circe. Rule A1 allows this module `libs/kernel` and
  cats-core, and that is the whole of it — which is why `DecodedRecord` carries `String` and not
  `Json`, and why the ports are declared here in domain terms and *satisfied* by adapters over the
  library types.
- No empty ports "for later". Every trait declared here has a caller inside M3.

## Design references

`ARCHITECTURE.md` §4.3 and §4.4 (the shapes the adapters will satisfy), ADR-041 A1, ADR-029
(the track query and the resend request), `libs/kafka/PORT-INVARIANTS.md`,
`research/kafbat/api-analysis.md` Finding 5.2 (the limit rules, which are invariants of
`BrowseRequest` rather than checks scattered in the API layer).

## Public Scala signatures to implement

```scala
package kui.message.domain

import kui.kernel.browse.*

/** A browse, validated. The limit rules live here rather than in the API layer because the page
  * endpoint and the stream endpoint must agree about them, and two validations of one rule is how
  * they stop agreeing. */
final case class BrowseRequest private (
  cluster: ClusterId, topic: TopicName,
  seek: SeekMode, direction: Direction,
  partitions: Option[NonEmptySet[PartitionId]],
  limit: Int, isolation: IsolationLevel,
  keySerde: Option[SerdeName], valueSerde: Option[SerdeName],
  stringFilter: Option[String], filter: Option[FilterRef],
  live: Boolean
)

object BrowseRequest:
  /** `limit`: absent, zero, negative or above `maxPageSize` becomes `defaultPageSize`. Kafbat's
    * rule, kept, because a user who asks for a million records means "as many as you allow" and an
    * error there would be a worse answer than a page. */
  def of(...): Either[KuiError, BrowseRequest]

/** `filterId` and `filterSource` travel together: the id addresses the cache, the source lets a
  * replica that has never seen it compile on demand (ADR-017). */
final case class FilterRef(id: FilterId, source: Option[String])
```

```scala
package kui.message.domain

/** What the domain has after decoding and masking, and the only record shape above the adapters.
  *
  * `key` and `value` are `Decoded`, not `String`, because the browser needs to know whether a
  * payload is JSON in order to flatten it (ADR-035) and needs to know which serde produced it in
  * order to render the fallback marker.
  */
final case class DecodedRecord(
  partition: PartitionId, offset: Offset, timestamp: Instant, timestampType: TimestampType,
  key: Decoded, value: Decoded, headers: List[RenderedHeader],
  keySize: Int, valueSize: Int, headersSize: Int,
  decodeErrors: List[DecodeError]
)

final case class Decoded(text: String, kind: PayloadKind, serde: SerdeName,
                         properties: Map[String, String])
final case class DecodeError(target: Target, serde: SerdeName, cause: String)
final case class RenderedHeader(key: String, value: String)
```

```scala
package kui.message.domain

/** ADR-029's track, with DEVPLAN §10 D12's rule: the match source is explicit and mandatory. */
final case class TrackQuery private (
  cluster: ClusterId, topics: NonEmptyList[TopicName],
  from: Instant, until: Instant,
  matcher: TrackMatch, limit: Int, isolation: IsolationLevel,
  correlationKey: Option[CorrelationKey]
)

enum MatchSource:
  case Value, Key
  case Header(name: String)

enum MatchOperator:
  case Contains, NotContains, Equals, NotEquals, Regex

final case class TrackMatch(source: MatchSource, operator: MatchOperator, value: String)

/** A header name or a JSON path; adds a `group` to each event so the UI can group one business
  * event across topics. No server-side join (ADR-029). */
enum CorrelationKey:
  case Header(name: String)
  case JsonPath(path: String)

object TrackQuery:
  /** `until` must be after `from`; the window is mandatory; the window's width is bounded by
    * `kui.message.track.maxWindow` (default 7 days). An unbounded scan is what PLAN §22 forbids. */
  def of(...): Either[KuiError, TrackQuery]
```

## ADRs this task must obey

ADR-041 A1 (this module sees `libs/kernel` and cats-core, nothing else — no circe, no Tapir, no
`libs/serde`; `SerdeName` and `PayloadKind` are therefore **re-declared in `libs/kernel`** by this
task if MSG-009 left them in `libs/serde`, and the deviation is recorded), ADR-029, ADR-026,
ADR-034.

**Resolve this before writing code, and record the answer in the Implementation Report:** either
`SerdeName` / `PayloadKind` move to `kui.kernel.browse` (one definition, visible to domain, contract
and browser), or the domain declares its own and the adapters map. The first is the M1 D1 precedent
and is almost certainly right; the second is two names for one thing, which is exactly the drift the
M0 review recorded. Coordinate with lane B in the same day: it is a one-file move for them and a
compile error for everyone if it is done twice.

## Tests required

- `BrowseRequestSuite`
  - `limitClampingTable` — absent, 0, negative, 1, 500, 501, `Int.MaxValue`.
  - `liveModeRejectsAnOffsetSeek` — tailing has no start position; accepting one would silently
    ignore it.
  - `partitionSubsetMustBeNonEmptyWhenPresent`.
  - `everyRejectionNamesTheField` (property) — because these become 400 responses with field names.
- `TrackQuerySuite`
  - `windowIsMandatoryAndOrdered`.
  - `windowWidthIsBounded`.
  - `matchSourceIsExplicit` — there is no constructor that defaults it (DEVPLAN §10 D12).
  - `regexIsValidatedAtConstruction` — an invalid regex is a 400, not a per-record failure.
- `MessageGenerators` — generators for every type here, used by lanes D, E and F.

## Observability

None: the domain has no effects. Every metric in this milestone is emitted by an adapter or a use
case.

## Degraded behaviour

Every smart constructor returns `Either[KuiError, A]` with a field-named validation error, which is
what makes a malformed query a 400 rather than a 500 three layers down.

## Cancellation and shutdown

Nothing here has a lifetime.
