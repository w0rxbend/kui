# MSG-014 — Spring DLT and retry numeric header decoding

- **ID:** MSG-014
- **Title:** Spring DLT and retry numeric header decoding
- **Milestone / Feature:** M3 / MS-012
- **Owner role:** Principal Scala Engineer
- **Context / service:** `libs/serde`
- **Size:** S
- **Dependencies / blocked by:** MSG-010

## Goal (user value)

A dead-letter record's `kafka_original-offset` header reads `41892` instead of four bytes of
mojibake. Every Spring Kafka user's DLT screen becomes legible, which is the one place they most
need it.

## Scope

1. `HeaderDecoding`: a fixed table of header names whose values are binary numbers rather than text,
   and the decoding for each.
2. Application to every record-bearing response — browse, page, track, detail — through the single
   record-mapping function of MSG-019, so that no path is missed.
3. The rule that an unknown header is decoded as UTF-8 text, or as hex when that produces control
   characters; never as an error and never as an empty cell.

## Non-goals

- No Spring-specific *behaviour*: KUI does not group DLT records, does not offer "replay to original
  topic" as a distinct action (MP-003's resend covers it), and does not read Spring's retry state.
- No configuration. The header set is fixed and documented; a configurable list would be four
  configuration keys for a table that changes once a year.

## Design references

`research/kouncil/ui-analysis.md` (Kouncil decodes these numeric headers; feature-matrix row MS-012 is
sourced from it), Spring Kafka's `KafkaHeaders` constants as the source of the names.

## Public Scala signatures to implement

```scala
package kui.serde.headers

/** How one header's bytes become the string a user reads. */
enum HeaderRendering:
  case Text(value: String)
  case Number(value: Long, raw: String)   // `raw` is the hex, kept for the detail view
  case Binary(hex: String)

object HeaderDecoding:
  /** The fixed table: Spring Kafka's numeric DLT and retry headers, by exact name. */
  val NumericHeaders: Set[String]

  /** Never fails. An absent value is `Text("")`, matching a Kafka header whose value is null. */
  def render(name: String, value: Option[Array[Byte]]): HeaderRendering
```

## The header table

| Header | Encoding | Rendered |
| --- | --- | --- |
| `kafka_original-offset` | 8-byte big-endian long | decimal |
| `kafka_original-partition` | 4-byte big-endian int | decimal |
| `kafka_original-timestamp` | 8-byte big-endian long | decimal (the UI formats it as a date) |
| `kafka_dlt-original-offset` | 8-byte long | decimal |
| `kafka_dlt-original-partition` | 4-byte int | decimal |
| `kafka_dlt-original-timestamp` | 8-byte long | decimal |
| `kafka_delivery-attempt` | 4-byte int | decimal |
| `retry_topic-attempts` | 4-byte int | decimal |
| `retry_topic-original-timestamp` | 8-byte long | decimal |
| anything else | UTF-8, or hex when the result contains control characters | as decoded |

A header in the table whose value is **not** the expected length falls through to the general rule.
Producers do get this wrong, and rendering the wrong number confidently is worse than rendering hex.

## ADRs this task must obey

ADR-035 (headers travel as a map of strings on the wire, so the rendering happens server-side and the
browser receives text), ADR-023 (masking applies to header values too, and runs **after** this
rendering: a masked numeric header is a masked string).

## Acceptance criteria

```
$ ./mill libs.serde.test
```

```scala
assertEquals(HeaderDecoding.render("kafka_original-offset", Some(longBytes(41892L))),
             HeaderRendering.Number(41892L, "000000000000a3a4"))
assertEquals(HeaderDecoding.render("kafka_original-offset", Some(Array[Byte](1,2))),
             HeaderRendering.Binary("0102"))          // wrong length: hex, not a wrong number
assertEquals(HeaderDecoding.render("trace-id", Some("abc".getBytes)), HeaderRendering.Text("abc"))
```

## Tests required

- `HeaderDecodingSuite`
  - `theTable` — one case per row.
  - `wrongLengthFallsThrough` — for every numeric header.
  - `neverThrows` (property over arbitrary names and byte arrays, including empty and absent).
  - `controlCharactersBecomeHex` (property).
  - `renderingIsDeterministic` (property).

## Observability

None. This is a pure function called per header; a metric here would be one instrument update per
header per record.

## Degraded behaviour

There is no failure path: every input has a rendering. That is the whole design, and it is why the
function returns `HeaderRendering` rather than `Either`.
