# MSG-027 — Message contract: DTOs, the SSE event payload types, golden files

- **ID:** MSG-027
- **Title:** Message contract: DTOs and SSE event payloads
- **Milestone / Feature:** M3 / MS-001, MS-003, MS-010, KU-014
- **Owner role:** Chief Architect
- **Context / service:** `services/message/contract` (cross-compiled)
- **Size:** L
- **Dependencies / blocked by:** MSG-017

## Goal (user value)

One definition of every document that crosses the process boundary, compiled by both the service and
the browser. The M1 dashboard defect — a browser decoding a document nobody sends, with both suites
green — cannot happen here because there is only one type.

## Scope

1. The `services/message/contract` cross-compiled module.
2. The DTOs: `MessageDto`, `DecodedPayloadDto`, `HeaderDto`, `DecodeErrorDto`, `MessagePageDto`,
   `SerdeSuggestionDto`, `ProduceRequestDto`, `ResendRequestDto`, `ResendResultDto`,
   `PurgeResultDto`, `TrackQueryDto`, `FilterRegistrationDto`, `FilterTestDto`.
3. The **SSE event payload types**, one per named event of ADR-035: `PhaseDto`, `MessageDto`,
   `ConsumedDto`, `DoneDto`, `ErrorDto` (the last from `libs/contracts-core`, unchanged).
4. Explicit circe codecs (ADR-007) and Tapir schemas, with golden files for every DTO.
5. The query-parameter codecs for `SeekMode` (including `seekTo[]` as `p::offset` pairs),
   `Direction`, `IsolationLevel` and partition lists, shared by the stream and page endpoints.

## Non-goals

- No endpoints (MSG-028). Types first, so that the endpoint declarations read as one page.
- No server logic, no browser code.
- **No permanently-null fields.** A field that M3 cannot fill does not exist on the wire; M1's
  CLAPI-001 decision, restated, because a `null` that never becomes a value teaches every client to
  ignore it.

## Design references

ADR-035 (`ARCHITECTURE.md` §7's envelope is normative, byte for byte, including field order),
ADR-007 (explicit codecs, no automatic derivation across the wire), ADR-003, `ARCHITECTURE.md` §5
(a service serves `/internal/v1`; `/api/v1` belongs to the gateway),
`research/kafbat/api-analysis.md` Finding 5.1 (`TopicMessage`'s fields, which KUI keeps where they
earn their place and drops where Kafbat itself deprecated them — `keyFormat`, `valueFormat`,
`keySchemaId`, `valueSchemaId` are **not** carried).

## ADRs this task must obey

ADR-007 (explicit codecs; every DTO has a golden file, and a field added without updating it fails
the build), ADR-035, ADR-026 (the cursor is an **opaque string** on the wire — the contract must not
expose its structure, or a client will parse it), ADR-034, ADR-041 A2 (a contract module has no edge
to `domain` or `application`).

## Library coordinates

None new: tapir-core, tapir-json-circe, tapir-iron, circe-core, and `scala-java-time` on the JS side.

## Tests required

- `MessageDtosSuite` (runs on **both** platforms — `KuiCrossTests`)
  - `goldenFilePerDto` — every DTO, encoded and compared byte for byte.
  - `decodesItsOwnGoldenFile` — round-trip, on both platforms; the JS run is what makes the seam
    real rather than intended.
  - `unknownFieldsAreIgnoredAndMissingRequiredFieldsFail` — the M1 defect in miniature: a decoder
    that defaults a missing list to empty turns a wrong document into an empty screen. Every list
    field on a record-bearing DTO is **required**, and this asserts it.
  - `timestampsAreIso8601WithMillis` (property).
  - `noFieldIsPermanentlyNull` — enumerated over the DTOs.
- `BrowseParamsSuite` (both platforms)
  - `seekModeRoundTripsForEveryCase` (property), including `seekTo[]` with 0, 1 and 200 pairs.
  - `malformedSeekIsADecodeFailureNamingTheParameter` — one case per malformed shape.
  - `partitionListRejectsNegativesAndDuplicates`.

## Observability

None: a contract module has no runtime.

## Degraded behaviour

The contract's contribution to degradation is that every response type can express partial truth: a
record carries `deserializeErrors[]` rather than failing, and `DoneDto.reason` always says why a
stream ended. A DTO that could only express success would force the server to fail where it should
report.
