# MSG-025 — `services/message/infrastructure`: the module and the browse / produce adapters

- **ID:** MSG-025
- **Title:** `services/message/infrastructure`: the browse and produce adapters
- **Milestone / Feature:** M3 / MS-001, MP-001
- **Owner role:** Domain Architect (message)
- **Context / service:** `services/message/infrastructure`
- **Size:** M
- **Dependencies / blocked by:** MSG-017, MSG-004, MSG-007

## Goal (user value)

The point at which the milestone's domain ports meet the real Kafka client — the only module in the
message tree with a Kafka class on its classpath, and the place where every port method is proved to
behave against a live broker the same way the fakes behave in the application suites.

## Scope

1. The `services/message/infrastructure` Mill module.
2. `KafkaMessageBrowseAdapter`: the domain's `MessageBrowsePort` implemented over `libs/kafka`'s
   `MessageBrowsePort` — a thin mapping, since the domain port was written to match, plus the
   `ClusterProfile` lookup and error mapping.
3. `KafkaProduceAdapter` over `ProducerFactory`.
4. The **shared port contract suite**: one abstract MUnit suite that both the fake used by lane D and
   this adapter must pass, so that a fake which drifts from reality fails a test rather than passing
   one.

## Non-goals

- No serde registry adapter, no profile source (MSG-026).
- No use-case logic. This module maps and adapts; anything that decides something belongs above it
  (rule A9's spirit as well as its letter).
- No caching. `ARCHITECTURE.md` §9 says payloads are never cached, and this is the module that would
  be tempted.

## Design references

`ARCHITECTURE.md` §3 (the layer's job), §4.3; ADR-041 A9 and A10; DEVPLAN §6.6 (the seam this suite
tests: the fake and the adapter).

## Public Scala signatures to implement

```scala
package kui.message.infrastructure

/** The domain port over the library port. The mapping is deliberately dull: where the two shapes
  * differ, the difference is a `ClusterProfile` lookup or a `KuiError`, never a decision. */
final class KafkaMessageBrowseAdapter[F[_]: Async](
  port:     kui.kafka.consume.MessageBrowsePort[F],
  profiles: ClusterProfileSource[F]
) extends kui.message.domain.ports.MessageBrowsePort[F]
```

```scala
package kui.message.infrastructure

/** The contract both implementations satisfy.
  *
  * A fake that answers differently from a broker is worse than no fake: every application suite
  * that used it was green and wrong. This abstract suite is the fix — it is written once, run twice,
  * and a divergence fails the build on the side that drifted.
  */
abstract class MessageBrowsePortContract extends CatsEffectSuite:
  def port: Resource[IO, MessageBrowsePort[IO]]
  def seed(records: List[SeedRecord]): IO[Unit]
  // ~15 shared cases, listed under "Tests required"
```

## ADRs this task must obey

ADR-041 A9 (only `app` may see this module) and A10 (Kafka lives here and in `libs/kafka*`),
ADR-006 Amendment 1, ADR-034 (errors are already mapped by `libs/kafka`; this module adds no second
mapping — a second one is how two codes appear for one condition).

## Library coordinates

None new; the module's `mvnDeps` are cats-effect, fs2, log4cats and otel4s, with `libs.kafka` on
`moduleDeps`.

## Acceptance criteria

```
$ ./mill services.message.infrastructure.compile
$ ./mill services.message.infrastructure.test
$ ./mill checkArchitecture
```

The third command fails if any other module in the message tree gains an edge to this one.

## Tests required

- `MessageBrowsePortContract` — the shared cases, each run against both the fake and the adapter:
  - `resolveExcludesEmptyAndLeaderlessPartitions`
  - `resolveClampsExplicitOffsets`
  - `pollTerminatesOnPosition`
  - `pollEmitsExhaustedPerPartition`
  - `pollRespectsEveryBudgetDimension`
  - `backwardStaysWithinTheOverFetchBound`
  - `tailSeesNewRecordsAndNeverExhausts`
  - `produceRoundTripsBytes`
  - `produceRejectsAnOutOfRangePartition`
  - `deleteRecordsMovesTheWatermark`
  - `everyMethodIsCancellableAndReleasesItsClient`
  - `errorsAreAlreadyMappedKuiErrors` (no raw Kafka exception escapes)
- `KafkaAdapterSuite extends MessageBrowsePortContract` (Testcontainers) — supplies a real port.
- `FakeBrowsePortSuite extends MessageBrowsePortContract` (in lane D's test module) — supplies the
  fake.

## Observability

None new: `libs/kafka` already instruments every call, and a second layer of spans around a thin
mapping would double the cardinality for no information.

## Degraded behaviour

- A cluster the profile source cannot resolve: `KUI-CLUSTER-NOT-FOUND` before any client is built.
- Everything else is `libs/kafka`'s behaviour, deliberately passed through unchanged.

## Cancellation and shutdown

The adapter holds no state and owns no `Resource`; every client's lifetime belongs to the call. The
contract suite's `everyMethodIsCancellableAndReleasesItsClient` case is what proves it for both
implementations, which is the point of writing the suite once.
