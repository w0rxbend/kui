# MSG-019 — `BrowseUseCase`: the envelope event stream, merge-sort, filters, masking, budgets

- **ID:** MSG-019
- **Title:** `BrowseUseCase`
- **Milestone / Feature:** M3 / MS-001, MS-002, MS-006, MS-007, MS-013, SD-001, DM-001, KU-014
- **Owner role:** Domain Architect (message)
- **Context / service:** `services/message/application`
- **Size:** L
- **Dependencies / blocked by:** MSG-017, MSG-018, MSG-011, MSG-015, MSG-016

## Goal (user value)

The centre of the milestone: a browse request becomes an ordered stream of decoded, filtered, masked
records with progress and a cursor — and the stream always ends, always says why, and never dies
silently.

## Scope

1. `BrowseUseCase.run(request): Stream[F, BrowseEvent]`, where `BrowseEvent` is ADR-035's envelope in
   domain terms: `Phase`, `Message`, `Consumed`, `Done`, `Failed`.
2. The pipeline, in this order and no other: poll → decode (key, value, headers) → **mask** → filter
   → merge-sort within a batch → limit → emit.
3. Merge-sort by timestamp across partitions with per-partition offset order preserved, exactly as
   the reference does, so a page reads chronologically without reordering a partition.
4. The record-mapping function — the **one** place a `RawRecord` becomes a `DecodedRecord` — used by
   browse, page, tail and track, which is what makes MSG-029's masking boundary test provable.
5. Cursor minting on `Done` when records remain.
6. `Consumed` events carrying cumulative bytes, records, elapsed, `filterErrors` and the remaining
   budget.

## Non-goals

- No SSE, no HTTP, no DTO. This layer emits domain events; MSG-029 renders them (ADR-041 A3).
- No tailing (MSG-020), no page mode (MSG-021), no track (MSG-023) — all three reuse the mapping
  function and the pipeline stages from here.
- No decision about *which* serde: `SerdeSource` resolves it (MSG-011).

## Design references

ADR-035 (the event names, the one-terminal-event rule, what `consumed` carries, that a decode failure
never aborts), ADR-023 (masking runs after deserialization, before anything leaves), ADR-017 (filter
errors are counted, not fatal), ADR-026 (when a cursor is minted),
`research/kafbat/api-analysis.md` Finding 5.1 and 5.2 (the observed event sequence, and the
merge-sort rule), DEVPLAN §6.6 (the seams) and §10 D13 (an `error` is terminal and what precedes it
stands).

## Public Scala signatures to implement

```scala
package kui.message.application.browse

/** ADR-035's envelope, in domain terms. `api` maps one-to-one onto the named SSE events; the names
  * here are the names there, so a reader can hold one vocabulary. */
enum BrowseEvent:
  case Phase(name: String)
  case Message(record: DecodedRecord)
  case Consumed(records: Long, bytes: Long, elapsed: FiniteDuration,
                filterErrors: Long, budgetLeft: PollBudget)
  case Done(reason: DoneReason, cursor: Option[BrowseCursor])
  case Failed(error: KuiError)

enum DoneReason { case Limit, Exhausted, Budget, Filter, Cancelled }
```

```scala
package kui.message.application.browse

trait BrowseUseCase[F[_]]:
  /** Exactly one terminal event — `Done` or `Failed` — unless the caller cancels.
    *
    * A failure inside the stream becomes `Failed` and terminates; it never escapes as an exception,
    * because an exception here reaches the client as a dropped connection, which is precisely the
    * reference product's behaviour this milestone exists to replace
    * (`research/kafbat/api-analysis.md` Finding 5.1: "there is no ERROR event type").
    */
  def run(request: BrowseRequest): Stream[F, BrowseEvent]

  /** Continue from a cursor. Everything except the filter source comes from the cursor (ADR-026). */
  def continue(cursor: BrowseCursor, filterSource: Option[String]): Stream[F, BrowseEvent]
```

```scala
package kui.message.application.browse

/** `RawRecord` to `DecodedRecord`: resolve serdes, decode with fallback, render headers
  * (MSG-014), then mask (MSG-016).
  *
  * **This is the only function in KUI that produces a `DecodedRecord`.** Browse, page, tail and
  * track all call it. That is what makes "nothing unmasked leaves the service" a property of one
  * function rather than a rule four call sites have to remember — and it is what
  * `MaskingBoundarySuite` verifies by enumerating the endpoints.
  */
object RecordMapping:
  def decode[F[_]: Sync](
    serdes: ClusterSerdes[F], rules: List[MaskingRule],
    topic: TopicName, keySerde: Option[SerdeName], valueSerde: Option[SerdeName],
    record: RawRecord
  ): F[DecodedRecord]

object RecordOrdering:
  /** Timestamp ascending across partitions, offset ascending within one. Stable, and the same
    * function for both directions — a backward browse reverses the *pages*, not the records inside
    * one. */
  def merge(batches: List[Chunk[DecodedRecord]]): Chunk[DecodedRecord]
```

## The event sequence, stated exactly

For a forward or backward browse:

1. `Phase("Consumer created")`
2. `Phase("Reading partitions [0, 2, 5]; 1 empty, 1 offline")` — from `ResolvedRanges.excluded`, so
   the user learns why a partition is missing instead of wondering.
3. per round: zero or more `Message`, then one `Consumed`
4. exactly one `Done(reason, cursor)`; `cursor` is present only when records remain.

For a failure at any point after (1): the events already emitted stand, then exactly one `Failed`.
No `Done` follows a `Failed` and no `Failed` follows a `Done`.

## Observability

- `kui.message.browse.duration` — histogram, attributes `cluster`, `topic`, `mode`, `outcome`.
- `kui.message.browse.records`, `.bytes`, `.filter_errors`, `.decode_errors` — counters.
- `kui.message.browse.active` — up-down counter of in-flight browses.
- One INFO line per browse at completion: cluster, topic, mode, records, bytes, elapsed, reason.
  One line per browse, not per record, and never any payload (ADR-023).

## Degraded behaviour

- Serde unavailable: records fall back with an error annotation; the browse succeeds.
- Filter port unavailable (CEL failed to initialise): a `filterId` request is `KUI-UNSUPPORTED`
  before the stream starts; a `stringFilter` request is unaffected.
- Masking rules unloadable: **the browse fails**. This is the one place where degrading is not
  allowed: rendering unmasked payloads because the rules would not load is a data leak dressed up as
  resilience. The error is `KUI-INTERNAL` and it is logged at ERROR.
- Broker failure mid-stream: `Failed(KUI-UPSTREAM-*)`, after which what was sent stands.

## Cancellation and shutdown

- The stream is a `Stream[F, BrowseEvent]` over the port's stream over the consumer `Resource`;
  cancelling anywhere releases everything. There is no `Ref` of running browses to clean up.
- `BrowseUseCaseSuite.cancellationReleasesEverything` — cancel mid-stream and assert the fake port's
  release flag and that no further event is emitted.
- `Done(Cancelled)` is **not** emitted on cancellation: the client is gone, and ADR-035 says the
  one-terminal-event rule is suspended when the client cancels. The reason exists in the enum for the
  server-side case where a supervisor stops a browse.
