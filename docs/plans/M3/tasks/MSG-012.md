# MSG-012 — `libs/serde-confluent`: the registry client, the Avro / Protobuf / JSON Schema deserializers, the caches

- **ID:** MSG-012
- **Title:** `libs/serde-confluent`: Schema-Registry-backed deserializers
- **Milestone / Feature:** M3 / SD-001
- **Owner role:** Principal Scala Engineer
- **Context / service:** `libs/serde-confluent`
- **Size:** L
- **Dependencies / blocked by:** MSG-011

## Goal (user value)

Avro, Protobuf and JSON-Schema topics read as JSON, with the subject and schema id shown beside each
record — and a deployment with no Schema Registry still runs, because this whole module is optional.

## Scope

1. The `libs/serde-confluent` Mill module: the **only** module with Confluent, Jackson or Guava on
   its classpath (rule A11, MSG-047).
2. `SchemaRegistrySerde`: one `Serde[F]` wrapping `kafka-avro-serializer`,
   `kafka-protobuf-serializer` and `kafka-json-schema-serializer` 8.3.1, selected by the schema type
   the registry reports for the id in the payload's magic-byte header.
3. The registry client configuration from `ClusterProfile`: URL list, basic auth **or** OAuth2 client
   credentials (never both), mTLS, failover.
4. Two caches on `BoundedCache` (MSG-015 builds it): schema by id (size-bounded) and subjects
   (TTL 60 s), exactly the `message` row of `ARCHITECTURE.md` §9.
5. `properties` on the `DeserializeResult`: `{type, id, subjects[]}`, which is what lets the browser
   link a record to its subject (`research/kafbat/ui-analysis.md`, `Serde.tsx`).
6. `SchemaRegistryHealth`: a probe the capability fold reads, so "SR unavailable" is a chip and not a
   stack trace.

## Non-goals

- No subject, version or compatibility **management**. That is `services/schema` in M7. This module
  reads schemas to decode records and does nothing else with the registry.
- No serializers here (MSG-013).
- No `AvroEmbedded`, no `ProtobufFile`, no `ProtobufRaw` — M5, KU-023.

## Design references

ADR-014 (this exact split: own REST client for management in M7, Confluent serializers for the wire
format here, in one isolated module, optional at runtime, Community License documented),
`research/kafka/admin-capabilities.md` §6, ADR-016 (both caches and their bounds), ADR-039 (SR down
is `Degraded`, SR unconfigured is `NotConfigured`).

## Public Scala signatures to implement

```scala
package kui.serde.confluent

/** The registry-backed serde. One serde, three wire formats, chosen by what the registry says the
  * id is — not by configuration, because a topic can carry more than one and the payload already
  * says which. */
object SchemaRegistrySerde:
  /** A `Resource` because it owns an HTTP client and two caches. */
  def make[F[_]: Async](config: SchemaRegistryConfig, caches: SchemaCache[F]): Resource[F, Serde[F]]

  /** Confluent's wire header: one zero byte, then a four-byte big-endian schema id.
    * `None` when the payload is too short or does not start with zero — which is the ordinary case
    * for a topic that is not registry-encoded and must not be an error. */
  def readSchemaId(bytes: Array[Byte]): Option[Int]

final case class SchemaRegistryConfig(
  urls: NonEmptyList[Uri],
  auth: Option[RegistryAuth],          // Basic | OAuth2ClientCredentials, never both
  tls:  Option[TlsSettings],
  requestTimeout: FiniteDuration,
  schemaCacheSize: Int, subjectsTtl: FiniteDuration
)

trait SchemaRegistryHealth[F[_]]:
  /** Cheap, cached, and never blocking a record: the browse path uses the last known value. */
  def status: F[RegistryStatus]
enum RegistryStatus:
  case Ok(at: Instant)
  case Unreachable(reason: String, since: Instant)
  case NotConfigured
```

## ADRs this task must obey

ADR-014, ADR-016 (bounds and TTLs are configuration, not literals in a file), ADR-035 (a decode
failure is an annotation), ADR-039 (which state the registry's failure produces), ADR-041 A11 —
**no type from `io.confluent`, Jackson or Guava appears in any signature this module exports**. The
module's public surface is `Serde[F]`, `SchemaRegistryConfig` and `SchemaRegistryHealth`, all KUI
types, which is what makes the classpath rule enforceable.

## Degraded behaviour

This module is the milestone's second fault-injection scenario. Contract:

- **Registry unconfigured**: the serde is not registered at all; `suggest` does not list it;
  `resolve` never picks it; the `message` capability is `Available`. Nothing is broken, so nothing
  is dimmed (ADR-039).
- **Registry unreachable**: the serde stays listed, marked unavailable with the reason; records fall
  back to `String` with a `deserializeErrors[]` entry; the capability is `Degraded`; the picker chip
  reads `SR unavailable`. **Browsing never stops**, which is exit criterion 8.
- **Registry slow**: bounded by `requestTimeout`, per record, and the failure is cached for a short
  interval so one slow registry does not multiply into one timeout per record.

## Cancellation and shutdown

The client and the caches are one `Resource`, owned by the cluster's `ClusterSerdes` (MSG-011), so a
profile change or a shutdown closes them. `SchemaRegistrySerdeSuite.cancellationClosesTheClient`
asserts the finaliser ran; an HTTP client left open per profile version is a slow leak that only
shows up after a few days of configuration edits.
