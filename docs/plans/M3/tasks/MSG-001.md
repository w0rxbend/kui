# MSG-001 — `libs/kernel`: the browse vocabulary (`SeekMode`, `Direction`, `PollBudget`, `OffsetRange`)

- **ID:** MSG-001
- **Title:** `libs/kernel`: the browse vocabulary
- **Milestone / Feature:** M3 / MS-001, MS-002, KU-015
- **Owner role:** Principal Scala Engineer, reviewed by the Chief Architect
- **Context / service:** `libs/kernel` (cross-compiled)
- **Size:** M
- **Dependencies / blocked by:** none. One of the five first-movers (DEVPLAN §6.4).

## Goal (user value)

Nothing a user sees. This is the task that makes it possible for the browser to build a seek
position, the contract to put it on the wire, the domain to state a port in terms of it and
`libs/kafka` to execute it — from **one** definition, so that the four never disagree about what
"from offset 42, backwards" means.

## Why this is a first-mover

`ARCHITECTURE.md` §4.3 declares `SeekMode`, `Direction`, `IsolationLevel`, `PollBudget` and
`OffsetRange` inside `kui.kafka.consume`. That cannot be implemented: rule A1 forbids
`services/message/domain` from seeing `libs/kafka`, rule A5 forbids `libs/kafka` from seeing a
service, and a Scala.js module cannot see a JVM module at all — yet the filter bar in the browser
constructs exactly these values. DEVPLAN §10 D1 decides the ADT lives in `libs/kernel`; this task
executes it. Getting it wrong is a rewrite of the port, the domain, the contract and the browser.

## Scope

1. A new pure package `kui.kernel.browse` in the cross-compiled `libs/kernel`.
2. The seek and direction vocabulary, including the per-partition `seekTo[]` form (DEVPLAN §10 D10).
3. `OffsetRange` with its invariant, and the arithmetic every window walker and page calculator
   needs, so that neither writes its own.
4. `PollBudget`, with subtraction that saturates at zero rather than going negative.
5. `PartitionId` and `Offset` as opaque types, in the same package, because a browse API that takes
   two `Long`s in a row will eventually be called with them the wrong way round.

## Non-goals

- No `RawRecord`, no `PollEvent`, no `RawHeader`. Those are adapter types that only `libs/kafka` and
  its callers inside `infrastructure` name; putting them in the kernel would drag record shapes into
  the browser build for nothing.
- No codecs. Circe and Tapir codecs for these types belong to `services/message/contract` (MSG-027);
  `libs/kernel` has no JSON dependency and gains none.
- No consumer, no Kafka import of any kind. Rule A10 makes this a build failure, not a review
  comment.

## Design references

`ARCHITECTURE.md` §4.3 (the shapes, which this task relocates rather than redesigns),
`research/kafka/admin-capabilities.md` §4 (what each seek mode actually resolves to, and the
`offsetsForTimes` semantics that make `Timestamp` different in the two directions), ADR-026 (the
cursor payload, whose `perPartitionNextOffset` is a `Map[PartitionId, Offset]` of these types),
DEVPLAN §10 D1 and D10.

## Public Scala signatures to implement

```scala
package kui.kernel.browse

/** A partition number. Opaque because `browse(topic, 3, 42)` is a bug this type makes impossible. */
opaque type PartitionId = Int
object PartitionId:
  def fromInt(value: Int): Either[String, PartitionId]   // rejects negatives
  def unsafe(value: Int): PartitionId                    // for decoders that have already validated
  extension (id: PartitionId) def value: Int
  given Ordering[PartitionId]

/** A record offset. Non-negative; `-1` from a Kafka API means "absent" and is decoded as `None`
  * by the adapter, never carried as a negative `Offset`. */
opaque type Offset = Long
object Offset:
  val Zero: Offset
  def fromLong(value: Long): Either[String, Offset]
  def unsafe(value: Long): Offset
  extension (o: Offset)
    def value: Long
    def +(n: Long): Offset      // saturates at zero, never wraps
    def -(n: Long): Offset
  given Ordering[Offset]
```

```scala
package kui.kernel.browse

/** A half-open window `[from, until)` of one partition.
  *
  * Half-open, and said so in the type's name, because every off-by-one in this milestone is a
  * disagreement about whether `until` is included. It is not, anywhere, ever.
  */
final case class OffsetRange private (from: Offset, until: Offset):
  def size: Long                       // `until - from`, never negative
  def isEmpty: Boolean
  def contains(o: Offset): Boolean
  /** The last `n` offsets of this range, clamped to `from`. The backward walker's one primitive. */
  def tail(n: Long): OffsetRange
  /** Everything before `tail(n)`. `tail(n)` and `dropTail(n)` tile the range exactly. */
  def dropTail(n: Long): OffsetRange
  def clampTo(bounds: OffsetRange): OffsetRange

object OffsetRange:
  /** `Left` when `until < from`: a range that runs backwards is a programming error, not a value. */
  def apply(from: Offset, until: Offset): Either[String, OffsetRange]
  def unsafe(from: Offset, until: Offset): OffsetRange
  def empty(at: Offset): OffsetRange
```

```scala
package kui.kernel.browse

enum Direction:
  case Forward, Backward

enum IsolationLevel:
  case ReadUncommitted, ReadCommitted

/** Where a browse starts.
  *
  * `Offset` carries both reference shapes on purpose: Kafbat's v2 API applies one offset to every
  * selected partition, and its own cursors carry a per-partition map. KUI accepts both, which is
  * DEVPLAN §10 D10 — without the per-partition form a user cannot express what a cursor expresses.
  */
enum SeekMode:
  case Beginning
  case Latest
  case AtOffset(offset: Offset)
  case AtOffsets(perPartition: Map[PartitionId, Offset])
  case AtTimestamp(millis: Long)

object SeekMode:
  /** The direction the reference product infers from the mode, kept so that a caller that does not
    * care can stay silent: `Beginning` and `AtOffset`/`AtOffsets`/`AtTimestamp` used as a *lower*
    * bound are forward, `Latest` is backward. Callers that pass an explicit `Direction` win. */
  def defaultDirection(mode: SeekMode): Direction
```

```scala
package kui.kernel.browse

import scala.concurrent.duration.FiniteDuration

/** What a single browse may consume before it stops of its own accord (PLAN §22).
  *
  * Every field saturates at zero on subtraction. A budget that can go negative is a budget that
  * silently becomes unbounded the first time a chunk overshoots it.
  */
final case class PollBudget(
  maxRecords: Int,
  maxBytes: Long,
  deadline: FiniteDuration,
  throttleBytesPerSecond: Option[Long]
):
  def consume(records: Int, bytes: Long): PollBudget
  def isExhausted: Boolean
  def recordsLeft: Int
  def bytesLeft: Long

object PollBudget:
  /** Not the product's defaults — those are configuration (MSG-041). This is the value a test or a
    * caller with no configuration in scope uses, and it is deliberately small. */
  val Conservative: PollBudget
```

## ADRs this task must obey

ADR-041 A1 (the kernel is the one module the domain may see, so it must stay dependency-free),
ADR-026 (the cursor payload names these types), ADR-035 (the wire carries them), ADR-007 (opaque
types for domain values; codecs live with the contract, not here).

$ ./mill libs.kernel.jvm.test

```scala
// Half-open, everywhere
assertEquals(OffsetRange.unsafe(Offset.unsafe(10), Offset.unsafe(13)).size, 3L)
assert(!OffsetRange.unsafe(Offset.unsafe(10), Offset.unsafe(13)).contains(Offset.unsafe(13)))

// The backward walker's primitive tiles exactly
val r = OffsetRange.unsafe(Offset.unsafe(0), Offset.unsafe(100))
assertEquals(r.dropTail(30).until, r.tail(30).from)

// A budget never goes negative
assertEquals(PollBudget.Conservative.consume(Int.MaxValue, Long.MaxValue).recordsLeft, 0)

// A backwards range is not representable
assert(OffsetRange(Offset.unsafe(5), Offset.unsafe(4)).isLeft)
```

## Tests required

- `OffsetRangeSuite`
  - `sizeIsUntilMinusFrom` (property).
  - `tailAndDropTailTileTheRangeExactly` (property over `(range, n)`): the two are adjacent, their
    sizes sum to the original, and neither escapes the bounds. This is the property the whole
    backward walker rests on.
  - `tailClampsAtFrom` — asking for more than the range holds gives the whole range, not a negative
    `from`.
  - `clampToIsIdempotent` (property).
  - `emptyRangeContainsNothing`.
  - `constructorRejectsInvertedRanges`.
- `SeekModeSuite`
  - `defaultDirectionTable` — one assertion per case, written as a list of tuples.
  - `atOffsetsKeepsEveryPartition` (property): the map is carried unchanged, since a mode that
    silently dropped a partition would silently drop records.
- `PollBudgetSuite`
  - `consumeSaturatesAtZero` (property over `Int`/`Long` extremes, including `MaxValue`).
  - `isExhaustedWhenAnyDimensionIsSpent` — records, bytes and, separately, a zero deadline.
- `BrowseGenerators` — the ScalaCheck generators for these types, in `test/src` and **not** in
  `libs/testkit`: rule A5 is not the issue here, but a generator that lives beside the type is one
  that stays correct when the type changes. `libs/testkit` re-exports it in MSG-042 if another module
  needs it.

## Observability

None. This module has no effects, no logger and no meter, and adding one would give the domain a
telemetry dependency it does not have today.

## Degraded behaviour

Not applicable — there is nothing here that can fail at runtime. The one design rule that serves
degradation is that every partial constructor returns `Either[String, A]` rather than throwing, so a
malformed value arriving from a query parameter becomes a 400 with a field name in MSG-028 instead of
a 500.

## Cancellation and shutdown

Nothing here has a lifetime.
