# MSG-016 — The masking engine in `libs/security-core`

- **ID:** MSG-016
- **Title:** The masking engine in `libs/security-core`
- **Milestone / Feature:** M3 / DM-001
- **Owner role:** Principal Scala Engineer, reviewed by the Security Engineer
- **Context / service:** `libs/security-core`, `libs/config`
- **Size:** M
- **Dependencies / blocked by:** none

## Goal (user value)

An operator writes three lines of configuration and the `cardNumber` field is never readable in KUI,
by anyone, on any screen — including the table view's raw column, the track results and the message
detail.

## Scope

1. `MaskingRule` and `MaskingEngine` as **pure functions over `io.circe.Json` and `String`**, in
   `libs/security-core` (ADR-023 puts them there).
2. The three rule types with Kafbat's semantics: `remove`, `mask` (with Kouncil's
   `keep{prefix, suffix}` folded in), `replace`.
3. Scoping: `fields[]` **xor** `fieldsNamePattern`, plus `topicKeysPattern` / `topicValuesPattern`.
4. The application order Kafbat uses: a JSON value gets **all** matching policies in order; a
   non-JSON value gets the first policy's string form.
5. The `kui.clusters[].masking` configuration slice, validated at startup.

## Non-goals

- No group scoping, no `subjects[]`, no UI-managed policies. That is DM-002 in M6, and adding the
  field now would mean shipping an unenforced access control.
- No masking on produce. ADR-023 says so and MSG-022's suite asserts it: masking a value on the way
  in would corrupt the topic.
- No encryption, no tokenisation, no reversible masking.
- The engine does not decide **where** it runs. MSG-019 owns that, and the boundary test is
  MSG-029's.

## Design references

ADR-023 (the rule model, the application order, that masking runs after deserialization and before
any DTO leaves the service, including `originalValue`), `research/scala/security-research.md` §4,
`research/kouncil/ui-analysis.md` (`FIRST_5` / `LAST_5`, which become `keep`).

## Public Scala signatures to implement

```scala
package kui.security.masking

enum MaskingKind:
  case Remove
  case Mask(replacementChars: String, keep: KeepEnds)
  case Replace(replacement: String)

/** Kouncil's `FIRST_5` / `LAST_5`, generalised: keep this many characters at each end. */
final case class KeepEnds(prefix: Int, suffix: Int)

final case class MaskingRule(
  kind: MaskingKind,
  fields: Option[NonEmptyList[String]],          // xor
  fieldsNamePattern: Option[Regex],              // xor
  topicKeysPattern: Option[Regex],
  topicValuesPattern: Option[Regex]
)

object MaskingEngine:
  /** All matching rules, in configuration order, applied to a JSON document. */
  def maskJson(rules: List[MaskingRule], topic: TopicName, target: Target, json: Json): Json

  /** The first matching rule's string form, for a payload that is not JSON. */
  def maskText(rules: List[MaskingRule], topic: TopicName, target: Target, text: String): String

  /** Header values are masked too, by header name against the same field rules. */
  def maskHeaders(rules: List[MaskingRule], topic: TopicName,
                  headers: Map[String, String]): Map[String, String]

  /** True when any rule could apply to this topic and target. Lets the browse pipeline skip the
    * walk entirely for the common case of no rules, which is the difference between masking costing
    * nothing and costing a JSON re-parse per record. */
  def applies(rules: List[MaskingRule], topic: TopicName, target: Target): Boolean
```

## The rules, stated exactly

| Kind | On a matched field | Notes |
| --- | --- | --- |
| `Remove` | the key is deleted from the object | arrays: the element is removed |
| `Mask` | every character replaced, cycling through `replacementChars`, except `keep.prefix` leading and `keep.suffix` trailing characters | **the result is never longer than the input** |
| `Replace` | the value becomes the literal `replacement` | type becomes string |

Matching: a rule with `fields` matches those exact names at any depth; a rule with
`fieldsNamePattern` matches any name the regex matches; a rule with neither matches the **whole
value**. Nested objects and arrays are walked to any depth; cycles are impossible in `Json`.

## ADRs this task must obey

ADR-023 (the model and the placement), ADR-013 (configuration errors accumulate: a rule with both
`fields` and `fieldsNamePattern` is a startup error naming the rule's index), ADR-041 A1 (the engine
is pure, so `application` may use it directly).

## Tests required

- `MaskingEngineSuite`
  - `theRuleTable` — one case per kind, on a flat object, a nested object and an array.
  - `allMatchingRulesApplyInOrderForJson` — two rules on the same field compose; the order is the
    configured one.
  - `firstRuleOnlyForNonJson`.
  - `noRuleEverLengthensAValue` (property) — the leak this pins is a length side channel: a mask
    that pads a four-digit field to sixteen tells the reader the field was not a card number.
  - `maskingIsIdempotent` (property) — masking a masked document changes nothing, which is what makes
    it safe to apply on a path that may already have been masked.
  - `fieldsMatchAtAnyDepth` (property).
  - `patternRulesUseTheConfiguredRegexNotSubstring`.
  - `appliesIsFalseWhenNoRuleCanMatch` (property, and the fast path is asserted to produce the same
    output as the slow one).
  - `headersAreMaskedByName`.
  - `unicodeAndSurrogatePairsAreMaskedByCharacterNotByByte` — masking half of an emoji produces
    invalid text, which then fails JSON encoding two layers away.
- `MaskingConfigSuite`
  - `bothScopingFormsIsAnError`, `invalidRegexNamesTheRule`, `emptyFieldsListIsAnError`.
  - **`theSectionIsActuallyUsed`** — loaded through the real composition path and asserted to change
    what a browse returns (the M1 seam defect).

## Observability

- `kui.masking.applied` — counter, attributes `cluster`, `topic`, `target`. Deliberately **not** a
  count of fields masked: that number is a function of the payload and would leak its shape into
  metrics that are often less protected than the payload itself.

## Degraded behaviour

Masking has no failure mode by construction: every function is total and the identity is a legal
result. The one dangerous case is a rule that matches nothing because of a typo, and it is handled at
startup — an unusable regex is a configuration error, and `docs/operations/masking.md` tells the
operator to verify a rule against a record before trusting it.

## Cancellation and shutdown

Not applicable; the engine is pure.
