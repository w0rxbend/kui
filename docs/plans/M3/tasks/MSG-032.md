# MSG-032 — OpenAPI regeneration, the error-code table, the contract snapshot

- **ID:** MSG-032
- **Title:** OpenAPI regeneration and the error-code table
- **Milestone / Feature:** M3 / KU-009
- **Owner role:** Chief Architect
- **Context / service:** `services/message/api`, `services/gateway/api`, `docs/api`
- **Size:** S
- **Dependencies / blocked by:** MSG-031, MSG-029

## Goal (user value)

The published API document describes what the product actually serves, including the five new error
codes, so that a person integrating with KUI reads a file rather than the source.

## Scope

1. `services/message/api`'s `openApi` and `openApiCheck` Mill commands, following the cluster
   service's shape exactly.
2. The merged gateway document regenerated, with the message routes.
3. `docs/api/error-codes.md` regenerated from `ErrorCode`, now including `KUI-CURSOR-EXPIRED`,
   `KUI-CURSOR-INVALID`, `KUI-CURSOR-TOO-LARGE`, `KUI-FILTER-COMPILE`, `KUI-SERDE-UNAVAILABLE`.
4. A documented note on the streaming endpoints, since OpenAPI cannot express named SSE events: the
   response is `text/event-stream` and the event catalogue is a `description` generated from
   `StreamRendering.EventNames` rather than typed by hand.

## Non-goals

- No hand-editing of any generated file. A generated document that someone edited is a document that
  is wrong the next time it is generated.
- No new endpoints, no schema changes.

## Design references

## Files to change

- `build.mill` — `services.message.api.openApi()` / `openApiCheck()`.
- `docs/api/openapi.json`, `docs/api/error-codes.md` — regenerated.
- `libs/kernel/src/kui/kernel/error/ErrorCode.scala` — the five new codes. **This is the one file
  outside lane F's boundary that this task touches**, and it is deliberate: a wire code is a contract
  change and the contract lane owns it. The M1 precedent is KAFKA-005's deviation, which deferred a
  code rather than adding one in passing; this task adds them explicitly, with their statuses.

## Public Scala signatures to implement

```scala
package kui.kernel.error

enum ErrorCode:
  ...
  case CursorExpired      // KUI-CURSOR-EXPIRED,     400
  case CursorInvalid      // KUI-CURSOR-INVALID,     400
  case CursorTooLarge     // KUI-CURSOR-TOO-LARGE,   400
  case FilterCompile      // KUI-FILTER-COMPILE,     400
  case SerdeUnavailable   // KUI-SERDE-UNAVAILABLE,  503
```

`SerdeUnavailable` is a 503 and the other four are 400, because the first is a temporary condition of
the system and the rest are a property of the request. That distinction is what decides whether a
client retries.

## Tests required

- `ErrorCodeSuite` (existing, in `libs/kernel`) — extended: `statusOf` is total over the enum, every
  wire string is unique, and the five new codes have the statuses above.
- `OpenApiSnapshotSuite` — `openApiCheck` runs in CI; a contract change without a regeneration fails
  the build rather than being noticed in a review.
- `ErrorCodeDocsSuite` — `docs/api/error-codes.md` contains one row per `ErrorCode` case, generated;
  a code without a row fails.
