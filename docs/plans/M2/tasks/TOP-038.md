## What each amendment must say

### ADR-036 — Amendment 1

- **What changed.** The resolved `ClusterProfile` served at `GET /internal/v1/clusters/{id}/profile`
  carries the cluster's credentials. The shared consumer is `services/cluster/client`, a JVM module
  every Kafka-facing service depends on, admitted by rule A11.
- **Why.** The ADR already said Kafka-facing services receive the resolved profile over the
  internal contract and that keystore bytes travel inside the signed inter-service channel; M1
  shipped the endpoint redacted because it had no consumer. M2 has one. The alternative — every
  Kafka-facing service becoming a metadata-store client with the encryption key — was rejected in
  DEVPLAN §10 D1 and the amendment records the rejection with its reason.
- **What did not change.** Single writer per section; the gateway never reads the store; the store's
  encryption; the file adapter.

### ADR-038 — consequences

The measured cost of `NameIndex` at 10 000 names, from TOP-035's benchmark: build time, query p95
in both modes, and memory. This is the number the ADR says Lucene would be revisited against
("adopted only if a benchmark shows p95 > 50 ms"), so recording it either closes that question for
several milestones or opens it now.

### `ARCHITECTURE.md` §4.2

M1's definition of done item 11 established the pattern: sketch signatures are replaced by links to
the implementing files once they exist. `TopicAdmin` now exists, so §4.2's topic sketch becomes a
link to `libs/kafka/src/kui/kafka/admin/TopicAdmin.scala`, and the leaderless invariant is
referenced rather than restated — one statement of the rule, in the code.

## Decisions this task takes (no ADR covers them)

1. **KU-013 is recorded `PARTIAL`, not `DONE`.** The slot exists and is proven extensible by a
   test, but a slot with no guest has not been used in anger. Recording it as done and discovering
   in M4 that it needs a different shape would make the matrix a document nobody trusts.
2. **Criteria that were not demonstrated are recorded as not demonstrated.** M1's `STATUS.md`
   recorded nine of eleven confirmed and named the two that were not; the value of that document is
   entirely in its willingness to do that.
