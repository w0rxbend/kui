# TOP-027 — `ui-kernel`: `SearchBox`, `Pagination`, and the `Favourites` store

- **ID:** TOP-027
- **Title:** `ui-kernel`: `SearchBox`, `Pagination`, and the `Favourites` store
- **Milestone / Feature:** M2 / SF-001, TP-001, CL-010
- **Owner role:** Frontend Architect
- **Context / module:** `frontend/ui-kernel`
- **Size:** M
- **Dependencies / blocked by:** —

## Goal (user value)

Typing in a search box filters a list without hammering the server, the page controls say which
page of how many, and a starred topic stays at the top of the list on the next visit.

## Scope

1. `SearchBox`: a debounced text input that writes a URL parameter, with a clear button and an
   optional mode toggle (`plain` / `fts`).
2. `Pagination`: first / previous / next / last, a "page X of Y" label, a "go to page" input, and a
   page-size selector; hidden entirely when there is one page.
3. `Favourites`: a `localStorage`-backed set keyed by cluster id and item name, with a `Signal` so
   a list re-sorts when a star is toggled.
4. URL synchronisation: `q`, `mode`, `page`, `pageSize`, `sort` and `showInternal` live in the query
   string, so a search result is a link somebody can paste into a ticket.

## Non-goals

- No server calls. These are controls; the page wires them.
- No favourites on the server. DEVPLAN §10 D9: they are a browser preference, they never reach the
  server, and they pin **within the current page**.
- No cursor paging control. ADR-026 puts cursors on messages, which is M3.
- No topic knowledge. `Favourites` stores strings under a namespace and does not know what they
  name.

```scala
package kui.ui.kernel.prefs

/** Starred items, per cluster, in this browser.
  *
  * ==Why this never reaches the server==
  *
  * The lists it decorates are **server-paged**. If the favourite set influenced which items are on
  * which page, two tabs of the same user would disagree about what page 3 contains and a shared
  * link would not reproduce for the person it was sent to. So favourites pin within the page that
  * is on screen, change no total, and are a preference of this browser (DEVPLAN §10 D9).
  *
  * Every read and write is wrapped: a browser with site data blocked throws on access, and a
  * preference that cannot be stored must degrade to "nothing is starred", never to a broken page.
  */
final class Favourites(namespace: String) {
  def signal(cluster: String): Signal[Set[String]]
  def isFavourite(cluster: String, name: String): Boolean
  def toggle(cluster: String, name: String): Unit
  /** Favourites first, then the given order. Stable within each group. */
  def pin[A](cluster: String, items: List[A])(name: A => String): List[A]
}
```

```scala
package kui.ui.kernel.query

/** Reading and writing the query string, in one place, so a screen's state is a URL.
  *
  * A list screen's whole state — search, mode, sort, page, size, toggles — is in the address bar,
  * which is what makes "send me the link to what you are looking at" work. It also means Back
  * works, which is what a user expects from a paged list and does not get from a state variable.
  */
object UrlParams {
  def get(name: String): Option[String]
  def set(updates: Map[String, Option[String]]): Unit   // None removes
  def signal(name: String): Signal[Option[String]]
}
```

## Decisions this task takes (no ADR covers them)

1. **The debounce is 300 ms, not the reference's 500.** The list is served from an in-memory
   snapshot and costs no admin call, so the round trip is a few milliseconds; 500 ms is tuned for a
   backend that scans. Three hundred still collapses a burst of typing into one request.
2. **A new query resets `page` to 1.** Staying on page 7 of a result set that now has two pages
   shows an empty screen, and the user reads it as "no results".
3. **Page size is a control, not a preference.** It lives in the URL like everything else. A
   remembered page size would make a shared link show a different list to its recipient.
4. **`Favourites` is a class with a namespace, not a global.** PLAN §21: feature state is a class
   holding `Var`s, never a global; and a namespace keeps topics' stars from colliding with the
   consumer groups' in M4.

## Observability

None: kernel components send no metric to the server.

## Degraded behaviour

- **`localStorage` unavailable or throwing**: nothing is starred, nothing is stored, and no error
  reaches the user. Recorded in the type's doc comment because a wrapped accessor looks like
  defensive noise until you know why.
- **A query string a user hand-edited into nonsense**: each control parses its own parameter and
  falls back to its default; the server also validates, and its 400 is what the page shows if the
  value was well-formed but wrong.
