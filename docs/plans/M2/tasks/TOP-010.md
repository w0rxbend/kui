- **ID:** TOP-010
- **Rule number authority:** A11 is allocated to this rule by **ADR-041 Amendment 4**, which is the
  only place rule numbers are allocated. M3 owns A12 and A13, M4 owns A14; none of them is this rule.
- **Title:** `checkArchitecture` rule A11 and its build test
- **Milestone / Feature:** M2 / OT-005
- **Owner role:** Chief Architect
- **Context / module:** `build.mill`, `build-tests`
- **Size:** S
- **Dependencies / blocked by:** TOP-009

## Goal (user value)

The first service-to-service dependency in KUI's history is the moment to say what a service may
see of another service, so that the tenth one does not have to be argued about.

## Scope

1. Rule **A11** in the `checkArchitecture` rule table: `services.<a>.*` may depend on
   `services.<b>.contract.{jvm,js}` and `services.<b>.client`, and on no other module of
   `services.<b>`.
2. The rule's failure message: the rule id, the offending edge, and one sentence of why — the
   existing rules' format, which ADR-041 §3 requires.
3. A build test per direction: a legal edge passes, an illegal one fails.
4. ADR-041 gains **Amendment 4** recording A11, its allow-list, and why `client` is named
   explicitly.

## Non-goals

- No change to A1 … A10. In particular A4 (the gateway sees only `contract`) is **not** relaxed to
  admit `client`: the gateway holds no Kafka client and has no reason to resolve a profile, and
  widening a rule for symmetry is how allow-lists stop meaning anything.
- No new module, no code outside `build.mill` and the build test tree.

## Design references

- ADR-041 §2 (the rule table), §3 (enforcement is a build failure and every rule is proven by
  watching it fail), Amendment 3 (the precedent: A9 and A10 were added by the milestone that
  created the module shape they constrain).
- DEVPLAN §5.3.

## Public signatures to implement

The rule is data in the existing check, not a new abstraction:

```scala
/** A11 — a service may see another service's published surface and nothing else.
  *
  * `contract` is the wire shape both sides compile against; `client` is the shared consumer of
  * that wire shape (`services/cluster/client`, DEVPLAN §5.1). Everything else — `domain`,
  * `application`, `infrastructure`, `api`, `app` — is private to the service that owns it.
  *
  * Without this rule, a service could call another service's use case directly in the all-in-one
  * build and over HTTP in the distributed one, and the two shapes would diverge without either
  * being wrong at its own call site. That divergence is invisible in a unit test on either side,
  * which is precisely the class of defect the M0 and M1 reviews found twice.
  */
val A11: Rule
```

## Acceptance criteria

```
$ ./mill checkArchitecture
$ ./mill build-tests.test
```

Both green with A11 active, and the check's output names the rule count including A11.

Then, the ADR-041 §3 requirement — a check nobody has watched fail is a check nobody knows works.
The implementer performs this by hand and pastes the output into the Implementation Report:

```
# temporarily add `services.topic.application` -> `services.cluster.application` to build.mill
$ ./mill checkArchitecture
[A11] services.topic.application -> services.cluster.application
      A service may depend only on another service's `contract` and `client` modules.
      ... (the explanatory sentence)
# revert
```

## Tests required

`ArchitectureSuite` gains:

- `a11AllowsAnotherServicesContract` — `services.topic.infrastructure -> services.cluster.contract.jvm`.
- `a11AllowsAnotherServicesClient` — `services.topic.infrastructure -> services.cluster.client`.
- `a11ForbidsAnotherServicesApplication`.
- `a11ForbidsAnotherServicesInfrastructure`.
- `a11ForbidsAnotherServicesApi`.
- `a11DoesNotConstrainAServicesViewOfItself` — `services.topic.app -> services.topic.infrastructure`
  is A9's business and stays legal.
- `a11IsListedInTheRuleTableWithItsReason` — the message text is asserted, because a rule that
  fails with only an id teaches nobody anything.
- `theGatewayIsStillLimitedToContract` — A4 unchanged, asserted here so this commit cannot widen it
  by accident.
