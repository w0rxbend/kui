# TOP-030 — The topic detail screen: overview, partitions, configuration, panel slots

- **ID:** TOP-030
- **Title:** The topic detail screen: overview, partitions, configuration, panel slots
- **Milestone / Feature:** M2 / TP-003, TP-004, PA-001, KU-013
- **Owner role:** Frontend Architect
- **Context / module:** `frontend/ui-topics`
- **Size:** L
- **Dependencies / blocked by:** TOP-029, TOP-024

## Goal (user value)

Opening a topic shows what it is made of: an indicator strip, a partition table with leaders,
replicas and in-sync replicas, and a settings tab listing every configuration key — with an offline
partition visibly offline rather than silently zero.

## Scope

1. `TopicDetailPage` at `/ui/clusters/{clusterId}/topics/{topicName}` with two tabs, `Overview`
   and `Settings`, the tab in the URL.
2. The indicator strip: partitions, replication factor, under-replicated partitions, in-sync
   replicas, type (internal or not), size, segment count, cleanup policy, message count.
3. The partition table: partition id, replicas as chips (leader, out of sync), first offset, next
   offset, message count, size.
4. The settings tab: key, value, default value, with sensitive values masked and overridden keys
   emphasised; unit hints for `ms` and `bytes` keys.
5. The `FeaturePanel` slots for the four sections the gateway's overview reports as
   `NotConfigured` — rendered as nothing at all in M2, which is what KU-013's slot means.

## Non-goals

- **No Messages tab, no Produce.** M3. No tab is rendered disabled and no tab promises a milestone
  (DEVPLAN §10 D13).
- **No Consumers, ACLs or Connectors tab.** M4 and M7 register a panel; this task builds the slot
  they register into.
- **No Edit settings, no danger zone, no actions dropdown.** M5.
- No statistics or analysis tab. M5.

## Public Scala signatures to implement

```scala
package kui.ui.topics.detail

object TopicDetailPage {
  def apply(
      cluster: ClusterId,
      topic: String,
      tab: Signal[TopicTab],
      queries: TopicsQueries,
      onTab: TopicTab => Unit,
      zone: Signal[String]
  ): HtmlElement
}

/** The strip above the tabs. One pure function to the values it shows, so the threshold rules are
  * test rows.
  */
object TopicIndicators {
  final case class Indicator(label: String, value: String, tone: Tone)
  def of(detail: TopicDetailDto): List[Indicator]
}

/** Rendering a configuration value the way an operator reads it.
  *
  * `retention.ms = 604800000` is a number nobody parses at a glance, and the reference product
  * renders "7 days" beside it. The unit is inferred from the key's suffix (`.ms`, `.bytes`,
  * `.seconds`) and the hint is **hidden** for a negative value or a zero, because "-1 milliseconds"
  * is worse than the raw number.
  */
object ConfigValue {
  def hint(name: String, value: String): Option[String]
  /** A sensitive value is a fixed mask with an accessible name, never the value's own length —
    * which would leak how long the password is. */
  def masked: String
}
```

## Decisions this task takes (no ADR covers them)

1. **An absent section renders nothing, not a placeholder panel.** DEVPLAN §10 D10: four permanent
   "unavailable" panels on every topic page would train operators to ignore the colour that
   matters. The slot exists in the DOM as an empty container with a stable `data-testid`, so M4's
   registration is visible in a test the moment it lands.
2. **The masked value is a fixed-width mask.** Rendering one asterisk per character tells a reader
   how long the secret is.
3. **The partition table uses `VirtualizedTable`.** A topic with two thousand partitions is
   ordinary, and this is the second caller that justifies the component — the first being the topic
   list. It is also where TD-018's per-partition log-directory table will land.
4. **The message count on the strip and on a partition row obey the same refusal.** A topic whose
   count is unknown shows an em dash in both places; showing the sum of the partitions that *did*
   answer would be the exact wrongness `PORT-INVARIANTS.md` §1 warns about, reintroduced in the
   browser.

## Degraded behaviour

- **Topic section unavailable**: the heading and breadcrumbs stay, the body is an error region with
  a retry.
- **Topic section stale**: greyed, timestamped, everything still readable.
- **Config not permitted**: one tab explains itself; the overview is unaffected.
- **A partition with no leader**: "offline" in the leader cell, no count for that row, no count on
  the strip, and the strip's offline-partition indicator in the warning colour — four consistent
  statements of one fact.
