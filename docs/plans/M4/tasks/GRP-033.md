# GRP-033 — Lag polling and the trend sparkline, driven by the Degraded payload

- **ID:** GRP-033
- **Title:** Lag polling and the trend sparkline, driven by the Degraded payload
- **Milestone / Feature:** M4 / CG-006
- **Owner role:** Frontend Architect
- **Context / module:** `frontend/ui-consumers`
- **Size:** M
- **Dependencies / blocked by:** GRP-032

## Goal (user value)

Lag that moves on screen while an operator watches, and a small line beside each number that says
which way it is going — without re-fetching a page of rows every few seconds, and without hammering
a service that has already said it is struggling.

## Scope

1. `LagPoller`: an Airstream-driven loop that calls the delta endpoint with the last token, merges
   the changes into the rendered rows, and stops when the page is hidden or the component unmounts.
2. The interval: `nextPollMs` from the response, which is the snapshot interval normally and the
   capability's `suggestedPollIntervalMs` when the service is degraded (exit criterion 4).
3. `LagSparkline`: an inline SVG of the last N samples the browser has collected, with the trend
   arrow beside it.
4. The rules for what a trend means when samples are missing, which is most of the interesting part.

## Non-goals

- **No charting library.** `uplot` is in `DEPENDENCY_MATRIX.md` for M8's metrics graphs; a
  twenty-point sparkline is a `<polyline>` and pulling a library for it would put a facade, an npm
  pin and an import map entry in the bundle for one shape.
- **No server-side history.** GRP-016 keeps two snapshots; the samples are the browser's and die
  with the page. That is the honest scope of "trend" in M4.
- **No polling on the detail page's partition table.** The detail page recomputes live on demand;
  polling it would put a describe on a timer for one open tab.
- **No polling when the tab is hidden.** `document.visibilityState` gates the loop.

## Design references

- `research/kafbat/ui-analysis.md` "Consumer groups list", real-time section: `refetchInterval` from

## Public Scala signatures to implement

```scala
package kui.ui.consumers.lag

import com.raquo.laminar.api.L.*
import kui.consumer.contract.dto.{LagDeltaDto, LagUpdateDto}

enum LagTrend:
  case Up, Down, Flat, Unknown

object LagTrend:
  /** Two samples give a trend. Anything else does not.
    *
    *   - fewer than two samples ⇒ `Unknown`
    *   - either sample undefined ⇒ `Unknown` — not `Flat`, which is what a naive
    *     `getOrElse(0)` produces and which reads as "this group is stable" for a group that has
    *     never committed
    *   - a gap in the series (a `full` payload, or the poller was stopped) ⇒ the series is reset and
    *     the trend is `Unknown` until two fresh samples exist, because a trend across a gap is a
    *     comparison of two unrelated moments
    */
  def of(samples: List[Option[Long]]): LagTrend

object LagPoller:
  /** Owns one fiber-shaped `EventStream` timer. Mounted with the table, unmounted with it.
    *
    * Stops when: the component unmounts, the tab is hidden, the endpoint answers 503 (and resumes
    * on the capability stream, not on a timer), or the user navigates away. Every one of those is a
    * test. */
  def apply(
      cluster: String,
      groups: Signal[Set[String]],
      clients: kui.ui.consumers.ConsumerClients,
      into: Observer[LagDeltaDto]
  ): Modifier[HtmlElement]

object LagSparkline:
  /** An inline `<svg>` `<polyline>` over at most 20 samples, with the trend arrow beside it.
    * Renders nothing at all — not an empty box — with fewer than two defined samples. */
  def apply(samples: Signal[List[Option[Long]]]): HtmlElement
```

## Tests required

`LagPollerSuite` (MUnit + `domtestutils`, with a stubbed client and a controllable clock):

1. `pollsAtTheServerSuppliedInterval` — **exit criterion 4's browser half**: the response says
   9 000 ms and the poller waits 9 000 ms, not its own default.
2. `sendsTheTokenFromThePreviousResponse`.
3. `aFullPayloadResetsTheSeries`.
4. `onlyChangedRowsAreUpdated` — the other rows' DOM nodes are not re-rendered, asserted by identity.
5. `goneGroupsAreRemovedFromTheTable`.
6. `stopsWhenTheComponentUnmounts` — **the named cancellation test**: unmount, advance the clock,
   assert the stub received no further request.
7. `stopsWhenTheTabIsHidden` — and resumes on visible, with a fresh token request.
8. `stopsOnFiveOhThreeAndResumesOnTheCapabilityStream` — not on a timer, so a dead service is not
   polled every nine seconds by every open tab.
9. `doesNotPollWhenTheGroupSetIsEmpty`.
10. `navigatingAwayStopsThePoller`.
11. `twoTablesDoNotPollTwice` — one poller per page.
12. `aSlowResponseDoesNotOverlapRequests` — the next poll starts after the previous one finishes,
    plus the interval. A poller that overlaps turns a slow service into a slower one.

`LagSparklineSuite`:

1. `rendersNothingWithFewerThanTwoSamples`.
2. `rendersAPolylineWithTwentySamples`.
3. `dropsTheOldestSampleBeyondTwenty`.
4. `anUndefinedSampleBreaksTheLineRatherThanBeingZero` — a gap is drawn as a gap. Interpolating
   through an unknown is a picture of data that does not exist.
5. `trendIsUnknownWithAnUndefinedSample` — not `Flat`.
6. `trendIsUnknownAcrossAGap`.
7. `theArrowDirectionMatchesTheTrend`.
8. `theSparklineHasAnAccessibleLabel` — a decorative SVG with no label is invisible to a screen
   reader and the number beside it is what they get instead.

## Observability

None. The kernel's `ApiClient` already counts request outcomes; a per-poll metric in the browser
would be telemetry KUI does not collect.

## Degraded behavior

| Condition | Behaviour |
| --- | --- |
| Service degraded | The interval lengthens to `suggestedPollIntervalMs`; rows keep their last values; the capability banner shows the amber dot |
| Service unavailable | Polling stops; rows freeze greyed with their last timestamp; the sparkline shows a "paused" watermark (`research/kafbat/ui-analysis.md`'s own degraded-state proposal) and resumes on the capability stream |
| Tab hidden for an hour | No polling; on return, one `full` payload, the series reset, trends `Unknown` until two samples exist |
| A group's lag becomes undefined | Its sparkline breaks at that point and the trend goes `Unknown`; the number becomes an em dash |
