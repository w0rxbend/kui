# GRP-025 — Read endpoints: list, detail, lag delta, groups-for-topic

- **ID:** GRP-025
- **Title:** Read endpoints: list, detail, lag delta, groups-for-topic
- **Milestone / Feature:** M4 / CG-001, CG-002, CG-006, TP-015
- **Owner role:** Chief Architect
- **Context / module:** `services/consumer/contract`
- **Size:** M
- **Dependencies / blocked by:** GRP-024

## Goal (user value)

The four documents the Consumers screens read, declared once as Tapir endpoints so that the server
route, the browser client and the OpenAPI document are three renderings of one description and
cannot drift.

## Scope

1. `ConsumerEndpoints`: the four read endpoints, their paths, their query parameters, their error
   outputs and their descriptions.
2. The query-parameter codecs for `GroupState` (repeated), the sort field and direction, and the lag
   token.
3. `/internal/v1` variants for the two the gateway aggregates (detail and groups-for-topic), per
   ADR-043, because the gateway calls those and the browser calls the public ones.

## Non-goals

- **No mutations.** GRP-026.
- **No server logic.** GRP-027.
- **No gateway routes.** GRP-029.
- **No SSE.** DEVPLAN §4.

## Design references

- `research/kafbat/api-analysis.md` "Proposed KUI /api/v1 mapping" — the path shapes KUI committed
  to; `GET /consumer-groups/{groupId}` is named there as one of the aggregations.
- ADR-003, ADR-026 (paging parameters), ADR-034 (error outputs), ADR-040 (edge header policy),
  ADR-043 (`/internal/v1`).
- `services/cluster/contract/src/kui/cluster/contract/ClusterEndpoints.scala` — the house shape,
  including `KuiEndpoint.public` / `KuiEndpoint.internal` and the `SignedPrincipal` input.
- `research/kafbat/ui-analysis.md` "Consumer groups list" — the parameter names the reference uses,
  which KUI does **not** copy verbatim (`?sortBy`, `?STATE=`); KUI's are the ADR-026 ones.

## Public Scala signatures to implement

```scala
package kui.consumer.contract

object ConsumerEndpoints:

  val ClustersSegment: String = "clusters"
  val GroupsSegment: String = "consumer-groups"
  val ClusterIdParam: String = "clusterId"
  val GroupIdParam: String = "groupId"

  /** `GET /api/v1/clusters/{clusterId}/consumer-groups`
    *
    * `?state=` repeats (`state=STABLE&state=EMPTY`) rather than taking a comma list, because a
    * repeated parameter is what OpenAPI, Tapir and every HTTP client agree on, and the reference's
    * comma list has to be split by hand on both sides.
    */
  val list: Endpoint[SignedPrincipal, (ClusterId, GroupListParams), ErrorEnvelope, GroupPageDto, Any]

  /** `GET /api/v1/clusters/{clusterId}/consumer-groups/{groupId}` */
  val detail: Endpoint[SignedPrincipal, (ClusterId, GroupId), ErrorEnvelope, GroupDetailDto, Any]

  /** `GET /api/v1/clusters/{clusterId}/consumer-groups/lag`
    *
    * `?group=` repeats and may be empty (every group); `?since=` carries the opaque token. A GET
    * with a possibly long list of ids is deliberate: it is cacheable-by-nothing, idempotent, and
    * fits in a URL for the page sizes M4 allows (200 groups, ~40 characters each, under the 8 KB
    * every server and proxy accepts). If that ever stops being true it becomes a POST, and the
    * contract test that asserts the worst-case URL length is what will tell us.
    */
  val lag: Endpoint[SignedPrincipal, (ClusterId, Set[GroupId], Option[String]), ErrorEnvelope, LagDeltaDto, Any]

  /** `GET /internal/v1/clusters/{clusterId}/topics/{topic}/consumer-groups`
    *
    * Internal only: the browser reaches this through the gateway's topic-overview aggregation
    * (DEVPLAN §10 D13), never directly, so that `ui-topics` never learns this service's routes.
    */
  val forTopic: Endpoint[SignedPrincipal, (ClusterId, TopicName), ErrorEnvelope, TopicConsumersDto, Any]

  /** `GET /internal/v1/clusters/{clusterId}/consumer-groups/{groupId}` — the gateway's input to the
    * group-page aggregation. Same document as `detail`; a separate endpoint because ADR-043
    * separates the two surfaces and because the internal one may gain fields the public one must
    * not. */
  val detailInternal: Endpoint[SignedPrincipal, (ClusterId, GroupId), ErrorEnvelope, GroupDetailDto, Any]

  val all: List[AnyEndpoint]

final case class GroupListParams(
    states: Set[GroupState],
    q: Option[String],
    sort: GroupSortWire,          // "id" | "members" | "topics" | "lag" | "state"
    direction: SortDirection,     // "asc" | "desc"
    page: Int,
    pageSize: Int
)
```

Every endpoint declares its error outputs from `ErrorCode`'s statuses: 400 `KUI-VALIDATION`, 403
`KUI-FORBIDDEN`, 404 `KUI-CLUSTER-NOT-FOUND`, 503 `KUI-UPSTREAM-UNAVAILABLE`. `detail` deliberately
does **not** declare `KUI-GROUP-NOT-FOUND`: an unknown group renders as an empty dead group
(GRP-002's invariant), and declaring an error the endpoint cannot return would put a lie in the
OpenAPI document.

## Tests required

`ConsumerEndpointsSuite`, cross-compiled:

1. `everyEndpointHasANameASummaryAndATag` — the OpenAPI document is documentation, and an endpoint
   without a summary is a row in it that says nothing.
2. `pathsMatchTheDocumentedShapes` — asserted against literals, so a path change is a deliberate
   contract change.
3. `stateParameterRepeats` — `state=STABLE&state=EMPTY` decodes to a two-element set.
4. `anUnknownStateParameterIsAValidationError` — with the accepted values in the message, read from
   `GroupState.All`.
5. `sortAndDirectionDecodeFromTheirWireNames`.
6. `pageDefaultsAreOneAndTwentyFive`.
7. `pageSizeAboveTheMaximumIsAcceptedAndClamped` — the endpoint decodes it; `GroupQuery.normalise`
   clamps it (GRP-014). A 400 for asking for too much is unhelpful.
8. `theLagEndpointAcceptsAnEmptyGroupSet`.
9. `worstCaseLagUrlIsUnderEightKilobytes` — 200 group ids of 40 characters. The assertion that keeps
   the GET honest.
10. `internalEndpointsAreNotUnderApiV1` — a public path that reached an internal endpoint would let
    the browser call it directly, which DEVPLAN §10 D13 forbids.
11. `detailDoesNotDeclareGroupNotFound` — the invariant, asserted against the endpoint description.
12. `theOpenApiDocumentGenerates` — `tapir-openapi-docs` over `all`, asserting no duplicate
    `operationId` and no missing schema.

## Observability

None. Contract module. The `Operation` names the endpoints are traced under are the use cases'
constants (`kui.consumer.list`, `.detail`, `.lag`, `.forTopic`), and GRP-027 wires them.

## Degraded behavior

Declared, not implemented: each endpoint's success type carries the `stale` / `incomplete` fields of
GRP-024, and the error outputs above are the exhaustive set. GRP-027's suite asserts that the server
returns nothing outside it.
