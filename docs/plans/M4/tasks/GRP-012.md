# GRP-012 — Domain ports and the pure reset planner: `ResetSpec`, `ResetPlan`, clamping

- **ID:** GRP-012
- **Title:** Domain ports and the pure reset planner: `ResetSpec`, `ResetPlan`, clamping
- **Milestone / Feature:** M4 / CG-004
- **Owner role:** Domain Architect (Consumer Group Management context)
- **Context / module:** `services/consumer/domain`
- **Size:** L
- **Dependencies / blocked by:** GRP-011

## Goal (user value)

The safety of the milestone's one destructive operation, expressed as pure functions that can be
tested exhaustively without a broker. Every rule KIP-122 imposes and every rule the reference
products learned the hard way lives here: a timestamp with no matching record resolves to the *end*
of the partition and not the beginning; an offset an operator typed is clamped into the range the
partition actually holds and the clamp is *reported*, not applied silently; a partition with no
leader aborts the whole reset rather than being skipped.

## Scope

1. `ResetSpec`, the six modes as an ADT carrying their parameters.
2. `ResetPlan` and `PlannedPartition`: what will be written, what is there now, and every warning.
3. `ResetPlanner`: the pure function from a spec plus resolved offsets to a plan, or to a refusal.
4. The domain ports: `GroupAdminPort[F]`, `OffsetPort[F]`, `ClusterProfileSource[F]`, `AuditSink[F]`
   and `Clock`-shaped time, each declared in terms of the domain's own types.
5. `docs/domain/consumer.md` gains the "Resetting offsets" section.

## Non-goals

- **No effects in the planner.** `ResetPlanner.plan` takes already-resolved offsets and returns a
  value. Everything it needs to know about the cluster is an argument. That is what makes fourteen
  property tests cheap.
- **No token.** The `planToken` of DEVPLAN §10 D3 is minted in the application layer (GRP-019) with
  the cursor key, which the domain must not see.
- **No performing the reset.** GRP-019.
- **No `ToCurrent` or `FromFile`.** Kafka's own tool has them; no reference product ships them and
  the feature matrix does not name them.

## Design references

- DC-D6 (`research/kafka/admin-capabilities.md`) — the mode set, the precondition, timestamp misses
  ⇒ end offset, explicit offsets clamped to `[earliest, latest]` **with a warning**, leaderless ⇒
  fail, and Kouncil's missing clamp called "a foot-gun".
- `research/kafka/admin-capabilities.md` §3, row "Reset offsets" — `OffsetsResetService.java:12-127`
  is the behavioural source, including `failOnUnknownLeader=true` (`:93-122`).
- DEVPLAN §10 D3 (two-phase confirmation), D4 (the precondition, both halves, twice), D8
  (leaderless), D10 (`ShiftBy` and `ByDuration` ship in M4).
- ADR-041 A1 — these ports name domain types only; the adapter maps.

## Public Scala signatures to implement

```scala
package kui.consumer.domain

import java.time.Instant
import scala.concurrent.duration.FiniteDuration

import kui.kernel.{GroupId, Offset, TopicName, TopicPartition}
import kui.kernel.group.ResetTarget

/** What the operator asked for. One case per `ResetTarget`, carrying that mode's parameters.
  *
  * The scope — which partitions of which topic — is separate from the mode, because every mode
  * applies to any scope and pairing them would give twelve cases instead of six plus two.
  */
enum ResetSpec:
  case ToEarliest
  case ToLatest
  case ToTimestamp(at: Instant)
  case ToOffsets(offsets: Map[TopicPartition, Offset])
  case ShiftBy(records: Long)                 // may be negative
  case ByDuration(back: FiniteDuration)       // resolves to ToTimestamp(now - back)

  def target: ResetTarget

final case class ResetScope(topic: TopicName, partitions: Set[TopicPartition])

/** Everything the planner needs to know about the cluster, gathered by the caller.
  *
  * A record, not five arguments, because the caller must gather all of it in one snapshot pass and
  * a signature that lets three of the five come from different passes is a signature that invites
  * it (DEVPLAN §10 D7).
  */
final case class OffsetWindow(
    begin: Map[TopicPartition, Offset],
    end: Map[TopicPartition, Offset],
    committed: Map[TopicPartition, Offset],
    /** For `ToTimestamp`: the resolved offset per partition, `None` where no record is at or after
      * the timestamp. */
    atTimestamp: Map[TopicPartition, Option[Offset]],
    leaderless: Set[TopicPartition]
)

enum ResetWarning(val message: String):
  /** The operator's offset was outside `[begin, end]` and was moved to the nearest end. Reported,
    * never applied silently — Kouncil applies no clamp at all and Kafbat applies one without
    * saying so; an operator who typed 900 000 into a partition holding 400 must be told. */
  case Clamped(partition: TopicPartition, requested: Offset, applied: Offset)
      extends ResetWarning(...)
  /** No record at or after the requested time; KIP-122 says the end of the partition. Which means
    * "skip everything", and is the single most surprising rule in the feature. */
  case TimestampBeyondEnd(partition: TopicPartition, applied: Offset) extends ResetWarning(...)
  /** The partition is already at the offset the plan would write. */
  case NoChange(partition: TopicPartition) extends ResetWarning(...)
  /** The group has no committed offset here, so `ShiftBy` had nothing to shift from and used the
    * beginning. */
  case ShiftedFromBeginning(partition: TopicPartition) extends ResetWarning(...)

enum ResetRefusal(val message: String):
  case Leaderless(partitions: Set[TopicPartition]) extends ResetRefusal(...)
  case NoPartitionsInScope extends ResetRefusal(...)
  case UnknownPartition(partitions: Set[TopicPartition]) extends ResetRefusal(...)
  case NegativeResult(partition: TopicPartition) extends ResetRefusal(...)

final case class PlannedPartition(
    partition: TopicPartition,
    current: Option[Offset],
    proposed: Offset,
    /** `proposed - current`, `None` when there is no current. Rendered as "+412" / "−9 001". */
    delta: Option[Long]
)

final case class ResetPlan(
    group: GroupId,
    scope: ResetScope,
    spec: ResetSpec,
    partitions: List[PlannedPartition],
    warnings: List[ResetWarning],
    computedAt: Instant
):
  def isNoOp: Boolean = partitions.forall(p => p.current.contains(p.proposed))

object ResetPlanner:
  /** Pure. Every rule of KIP-122 and every rule the references learned, in one function.
    *
    * Refuses rather than partially plans: a reset that silently skipped a partition would leave a
    * group in a state nobody asked for, which is why `failOnUnknownLeader` is `true` in the
    * reference and why `Leaderless` is a refusal here rather than a warning.
    */
  def plan(
      group: GroupId,
      scope: ResetScope,
      spec: ResetSpec,
      window: OffsetWindow,
      now: Instant
  ): Either[ResetRefusal, ResetPlan]

// Ports.scala — declared in terms of domain types only (rule A1)
trait GroupAdminPort[F[_]]:
  def list(states: Set[GroupState]): F[Either[KuiError, GroupListingPage]]
  def describe(ids: List[GroupId]): F[Either[KuiError, Map[GroupId, ConsumerGroup]]]
  def exists(id: GroupId): F[Either[KuiError, Boolean]]     // by listing, never by describing (D5)
  def offsetWindow(group: GroupId, scope: ResetScope, at: Option[Instant]): F[Either[KuiError, OffsetWindow]]
  def applyOffsets(group: GroupId, offsets: Map[TopicPartition, Offset]): F[Either[KuiError, Unit]]
  def deleteOffsets(group: GroupId, partitions: Set[TopicPartition]): F[Either[KuiError, Unit]]
  def deleteGroup(id: GroupId): F[Either[KuiError, Unit]]

trait ClusterProfileSource[F[_]]:
  /** The cluster's connection settings and its `readOnly` flag, from the cluster service
    * (ADR-036/ADR-043). Never fails while a last-known profile is held. */
  def profileOf(cluster: ClusterId): F[Either[KuiError, ClusterProfileView]]
  def changes: fs2.Stream[F, ClusterId]

trait AuditSink[F[_]]:
  /** Never fails the operation it is recording. A sink that can fail a mutation is a sink that will
    * one day refuse a reset because a log was full. */
  def record(record: MutationRecord): F[Unit]
```

`GroupListingPage`, `ClusterProfileView` and `MutationRecord` are declared here as small records;
`MutationRecord`'s fields are fixed by GRP-018 and this task declares only the type name so the port
compiles. If that ordering is inconvenient, GRP-018 may land first — the dependency is declared the
other way only because the ports are needed by more tasks.

## Library coordinates

Unchanged from GRP-010, plus `fs2-core 3.13.0` on `services.consumer.domain` for the `changes`
stream. **This is the one dependency the domain gains**, and it is deliberate: a port that must
express "and then it changes" has no way to say so without a stream type, and `fs2.Stream` is
already `libs/kernel`-adjacent in every other context's ports (`ARCHITECTURE.md` §4.3). Rule A1
permits it — it names cats-core and `libs/kernel`; the build's `KuiPureModule` check is updated in
GRP-040 with fs2-core on the domain allow-list and a one-line justification in the rule table.

## Tests required

`ResetPlannerSuite` (MUnit + ScalaCheck):

1. `earliestPlansTheBeginOffsets`.
2. `latestPlansTheEndOffsets`.
3. `timestampPlansTheResolvedOffset`.
4. `timestampWithNoMatchPlansTheEndOffset` — **the KIP-122 rule**, with `TimestampBeyondEnd` in the
   warnings. The most surprising rule in the feature and the one an operator must be told about.
5. `explicitOffsetsAreClampedIntoRange` — a property over arbitrary offsets: the proposed offset is
   always within `[begin, end]`.
6. `everyClampIsReported` — a property: the count of `Clamped` warnings equals the count of
   partitions whose requested offset was outside the range. A silent clamp fails this test.
7. `shiftByMovesFromTheCommittedOffset`.
8. `shiftByClampsAtBothEnds` — a property with arbitrary large positive and negative shifts.
9. `shiftByWithNoCommitStartsFromTheBeginning` — with `ShiftedFromBeginning` warned.
10. `byDurationIsTimestampNowMinusD` — asserted by equality with the `ToTimestamp` plan for the same
    instant, so the two cannot drift.
11. `aLeaderlessPartitionRefusesTheWholePlan` — **the D8 rule**. Not a warning, not a skip.
12. `anEmptyScopeIsARefusal` — a wizard that submitted nothing does not silently succeed.
13. `apartitionOutsideTheWindowIsARefusal` — the topic was deleted between the form and the plan.
14. `noProposedOffsetIsEverNegative` — a property over every mode.
15. `deltaIsNoneWithoutACurrentOffset`.
16. `noChangeIsWarnedNotRefused` — resetting to where it already is succeeds and says so.
17. `isNoOpIsTrueWhenNothingMoves` — the wizard uses this to say "this would change nothing".
18. `planIsDeterministic` — the same inputs give an equal plan, including warning order. The plan is
    HMAC'd (GRP-019) and a non-deterministic ordering would break the token.

## Observability

None. Pure.

## Degraded behavior

| Condition | Behaviour |
| --- | --- |
| Any partition in scope is leaderless | The whole plan is refused, naming the partitions. The UI shows which broker is down and says the reset cannot be planned until it is back |
| The group has no commits at all | `ToEarliest` / `ToLatest` / `ToTimestamp` plan normally; `ShiftBy` warns and shifts from the beginning |
| The topic was deleted between the form and the plan | `UnknownPartition` refusal naming what is missing |
| The plan is a no-op | Succeeds, `isNoOp = true`; the wizard's confirm button says "This would not change anything" and stays enabled, because performing a no-op is harmless and refusing it is confusing |
