# GRP-016 — `LagPollUseCase`: the incremental delta and its server-issued token

- **ID:** GRP-016
- **Title:** `LagPollUseCase`: the incremental delta and its server-issued token
- **Milestone / Feature:** M4 / CG-006
- **Owner role:** Domain Architect (Consumer Group Management context)
- **Context / module:** `services/consumer/application`
- **Size:** M
- **Dependencies / blocked by:** GRP-013

## Goal (user value)

Lag that keeps moving on screen without re-fetching a page of four thousand rows every few seconds.
The browser asks "what changed since this token", and gets back only the groups whose lag actually
moved, plus a new token. On an idle cluster the answer is empty and costs nothing.

## Scope

1. `LagPollUseCase[F]`: `poll(cluster, groups, since)`.
2. `LagToken`: an opaque, server-issued value carrying the snapshot version it was cut from.
3. The delta rule: a group appears in the response when its `totalLag`, its `pace`, its state or its
   member count differs from the snapshot the token names.
4. The poll-interval hint: the response carries the server's own view of how often it is worth
   asking, which is the snapshot interval and, when the service is `Degraded`, the
   `suggestedPollIntervalMs` from the capability reason (KU-003).

## Non-goals

- **No SSE.** DEVPLAN §4: this is a polled delta, as the reference product's is, and ADR-035's
  envelope is for the streams that genuinely stream.
- **No history.** The server keeps two snapshot versions at most; the sparkline's samples are the
  browser's (GRP-033).
- **No per-partition lag in the delta.** The list needs a total; the detail page computes live. An
  `includePartitions` flag would put the detail page's cost on the list page's poll.
- **No client timestamps anywhere.** DEVPLAN §10 D9.

## Design references

- `research/kafbat/ui-analysis.md` "Consumer groups list", real-time section: `useGetConsumerGroupsLag`
  sends `lastUpdate` from the previous response, polls at `pollingIntervalSec`, computes trends only
  when polling is on, and renders `N/A` for a null lag. KUI copies the shape and replaces the client
  timestamp with a server token.
- DEVPLAN §10 D9 — why, and what an unrecognised token does.
- KU-003 / ADR-039 — the structured degraded reason with `suggestedPollIntervalMs`, and
  `services/gateway/application/.../capability/CapabilityFold.scala`, which already computes it.
- DEVPLAN §2.3 and §2.4 — the two exit criteria this task carries.

## Public Scala signatures to implement

```scala
package kui.consumer.application

import kui.kernel.{ClusterId, GroupId}
import kui.kernel.group.GroupState

/** Opaque to the client, meaningful to the server.
  *
  * Encoded as `<clusterId>:<snapshotVersion>` and base64url'd — not signed, because it carries no
  * authority and forging one can at worst make the server send a full payload. That is deliberate:
  * a token that needed the cursor key would need key distribution for a polling hint.
  */
opaque type LagToken = String

object LagToken:
  def of(cluster: ClusterId, version: Long): LagToken
  def parse(raw: String): Option[(ClusterId, Long)]
  extension (t: LagToken) def value: String

final case class LagUpdate(
    groupId: GroupId,
    totalLag: Option[Long],
    pace: Option[Double],
    state: GroupState,
    memberCount: Int
)

final case class LagPollView(
    changed: List[LagUpdate],
    /** Groups the caller asked about that are no longer on the cluster. The row is removed rather
      * than frozen at its last value, which is what the reference does and why a deleted group
      * lingers on its screen. */
    gone: List[GroupId],
    token: LagToken,
    /** How long the client should wait before asking again. The snapshot interval normally; the
      * capability's `suggestedPollIntervalMs` when the service is degraded (KU-003). */
    nextPollMs: Long,
    /** True when the token was unrecognised and everything was sent. The client uses it to reset its
      * trend history rather than computing a trend across a gap. */
    full: Boolean
)

trait LagPollUseCase[F[_]]:
  /** `groups` empty means "every group in the snapshot". `since` absent or unrecognised means a full
    * payload with `full = true` — never an error, because a client that has been asleep must be able
    * to resynchronise without special-casing an error code. */
  def poll(
      cluster: ClusterId,
      groups: Set[GroupId],
      since: Option[LagToken]
  ): F[Either[KuiError, LagPollView]]

object LagPollUseCase:
  val Operation: String = "kui.consumer.lag"
  def make[F[_]: Temporal](
      snapshots: GroupSnapshots[F],
      degradedHint: F[Option[Long]]     // suggestedPollIntervalMs, when the service is degraded
  ): LagPollUseCase[F]

  /** Pure: the delta between two snapshots, restricted to the requested groups. Exported so the
    * rule is asserted directly. */
  def diff(previous: Option[GroupSnapshot], current: GroupSnapshot, groups: Set[GroupId]): (List[LagUpdate], List[GroupId])
```

The server keeps the **previous** snapshot alongside the current one — one extra reference, bounded
by construction — so that a token one version old can be answered as a delta. A token more than one
version old is answered in full: keeping a ring of versions to serve a client that has been away for
ten minutes is a cache with a staleness contract nobody asked for.

**Exit criterion 3, demonstrated:** the Implementation Report records the two-call sequence — poll,

empty and the token is unchanged.

## Tests required

`LagPollUseCaseSuite` (MUnit + `munit-cats-effect` + `TestControl`):

1. `aFirstPollWithNoTokenIsFull` — every group, `full = true`.
2. `asecondPollWithNoChangeIsEmpty` — **exit criterion 3**. `changed.isEmpty`, and the token equals
   the one returned before.
3. `aGroupThatCommittedAppears` — and only that group.
4. `aGroupThatChangedStateAppears` — a rebalance is a change worth pushing even when the lag did not
   move.
5. `aGroupThatLostAMemberAppears`.
6. `aDeletedGroupIsInGone`.
7. `anUnrecognisedTokenIsAFullPayloadNotAnError`.
8. `aTokenFromAnotherClusterIsAFullPayload` — and does not leak that cluster's groups.
9. `aTokenMoreThanOneVersionOldIsFull`.
10. `nextPollIsTheSnapshotIntervalWhenHealthy`.
11. `nextPollFollowsTheDegradedHint` — **exit criterion 4's server half**.
12. `theRequestedGroupSetNarrowsTheResult` — a client watching page 1 is not sent page 40's updates.

## Degraded behavior

| Condition | Behaviour |
| --- | --- |
| Snapshot stale | The delta is computed anyway and `nextPollMs` lengthens; the client keeps its last values and greys them (ADR-032) |
| Snapshot never taken | `Left(Unavailable)`; the client stops polling and shows the fallback, then retries on the capability stream rather than on a timer |
| Service degraded | `nextPollMs` is the capability's `suggestedPollIntervalMs`; a browser that ignored it would be the load that keeps the service degraded |
| A group is `Forbidden` | Absent from `changed` and absent from `gone`; its row keeps whatever the list gave it, which is a `Forbidden` section |
