# GRP-009 — The group port's live suite against a seeded Testcontainers cluster

- **ID:** GRP-009
- **Title:** The group port's live suite against a seeded Testcontainers cluster
- **Milestone / Feature:** M4 / CG-001 … CG-005
- **Owner role:** QA Engineer with the Principal Scala Engineer
- **Context / module:** `libs/kafka`
- **Size:** L
- **Dependencies / blocked by:** GRP-007, GRP-008, GRP-036

## Goal (user value)

One suite that runs every method of `GroupAdmin` and `OffsetLookup` against a real broker with real
consumer groups on it, so that the twenty behaviours `research/kafka/admin-capabilities.md` §3
records as gotchas are behaviours this code has actually been observed to have, rather than
behaviours it was written to have.

## Scope

1. `GroupAdminContract`, a shared trait of assertions parameterised over a `GroupAdmin[F]` instance
   and a fixture, so that GRP-021's adapter suite runs the *same* assertions against the service's
   adapter. A fake that passes a contract its real implementation does not is the failure this
   shape prevents.
2. `GroupAdminLiveSuite`, running the contract against the PLAINTEXT container.
3. The classic / KIP-848 pair: two groups on the same cluster, one with
   `group.protocol=classic`, one with `group.protocol=consumer`, both asserted (DEVPLAN risk R-10).
4. A rebalance scenario: a second consumer joins, the suite polls until the group reports
   `PreparingRebalance` or a member's target differs from its assignment, and asserts the port
   reports it.

## Non-goals

- **No SASL or SSL matrix.** M1's three-mode parity suite already proves `AdminClientPool` against
  all three, and the group port uses that pool unchanged. Re-running the matrix here would be an
  hour of CI proving M1's property again.
- **No service, no HTTP.** This suite is `libs/kafka` only.
- **No sleeps.** M1's integration found three flaky suites, all asserting on sleeps rather than on
  conditions. Every wait in this suite is `eventually`-shaped: poll for the condition, with a
  deadline and a message naming what never happened.

## Design references

- `research/kafka/admin-capabilities.md` §3 in full — every row is at least one test here.
- `STATUS.md`, "M1 integration": defect 6 (three flaky suites) and defect 5 (a container suite in a

- M1's `ClusterAdminContract` / `ClusterAdminLiveSuite` pair (`c35d413`) — the shape to copy.

## Public Scala signatures to implement

```scala
package kui.kafka.admin

/** The assertions any `GroupAdmin` must satisfy, whoever implements it.
  *
  * Extended by `GroupAdminLiveSuite` here and by `KafkaGroupAdminAdapterSuite` in
  * `services/consumer/infrastructure` (GRP-021). One set of assertions, two implementations, no
  * chance of a fake that is kinder than the real thing.
  */
trait GroupAdminContract extends munit.CatsEffectSuite:
  def admin: IO[GroupAdmin[IO]]
  def offsets: IO[OffsetLookup[IO]]
  def fixture: IO[ConsumerGroupFixture.Seeded]

  /** Registers every assertion. Call once from the concrete suite's body. */
  def groupAdminContractTests(): Unit
```

## Tests required

`GroupAdminContract`, 24 assertions, grouped:

*Listing* — 1 `listsEverySeededGroup`; 2 `stateFilterNarrows`; 3 `unknownStateSurvivesFiltering`;
4 `shareGroupsAreExcluded`.

*Describing* — 5 `stableGroupHasItsMemberWithHostAndClientId`; 6 `emptyGroupHasNoMembers`;
7 `unknownGroupIsDeadWithNoMembers` (**the invariant, live**); 8 `classicGroupReportsAssignment`;
9 `consumerProtocolGroupReportsAssignment`; 10 `targetAssignmentDiffersDuringRebalance`;
11 `simpleGroupHasNoAssignor`.

*Offsets* — 12 `committedOffsetsMatchWhatWasConsumed`; 13 `uncommittedPartitionIsAbsent`;
14 `endOffsetsMatchWhatWasProduced`; 15 `beginningOffsetsAreTheLogStart`;
16 `offsetsForTimesResolvesAKnownTimestamp`; 17 `offsetsForTimesIsNoneBeyondTheLastRecord`.

*Mutations* — 18 `resetToEarliestOnAnEmptyGroup`; 19 `resetOnAnActiveGroupIsRefusedAndChangesNothing`;
20 `deleteOffsetsForOneTopicLeavesTheOther`; 21 `deleteAnEmptyGroup`;
22 `deleteAnActiveGroupIsRefused`.

*Shape* — 23 `theProbeReportsEveryFeaturePresentOnThisBroker`;
24 `everyAssertionAboveRanAgainstOneSharedContainer` — a guard that the suite did not silently start
a container per test, which is how a 30 s suite becomes a 12-minute one.

## Observability

None emitted. The suite asserts on the metrics the port emits: `GroupAdminContract` includes a check
that `kui.kafka.group.fabricated_dead` incremented during assertion 7, using the otel4s testkit
already in `libs/testkit`. A metric nobody asserts on is a metric that silently stops being emitted.

## Degraded behavior

Not applicable — this is a test suite. Its own degraded behaviour is that a container that cannot
start fails the suite with the container's log tail in the message, never with a bare timeout.

## Cancellation and shutdown

The container is a `ResourceSuiteLocalFixture`; the suite asserts in an `afterAll` that no
`AdminClient` thread survives it, because a leaked admin client in a test run is the same leak in
production wearing a different hat.
