# GRP-026 — Mutation endpoints: plan, apply, delete group, delete offsets

- **ID:** GRP-026
- **Title:** Mutation endpoints: plan, apply, delete group, delete offsets
- **Milestone / Feature:** M4 / CG-003, CG-004, CG-005
- **Owner role:** Chief Architect
- **Context / module:** `services/consumer/contract`
- **Size:** L
- **Dependencies / blocked by:** GRP-025

## Goal (user value)

The wire shape of the first destructive operations in KUI, designed so that the destructive part is
the *second* request and the first one only tells the operator what would happen. And marked, in the
description every generated client and every generated document carries, as mutations — so that M5's
read-only enumeration finds them already classified rather than having to guess.

## Scope

1. Four endpoints: plan a reset, apply a plan, delete a group, delete a group's offsets for a topic.
2. The `Mutation` marker: a Tapir attribute plus a description convention, and the helper
   `KuiEndpoint.mutation` that sets both, so a mutating endpoint declared without it is visible.
3. The `403`/`405`/`409` error outputs these four can return and the read endpoints cannot.
4. The CSRF header requirement (ADR-019) declared on all four, even though authentication is
   disabled in M4 — because a header that is required from the day the endpoint exists never has to
   be added to a client that already shipped.

## Non-goals

- **No raw-spec apply.** DEVPLAN §10 D3: `apply` takes a token. There is no second path, not for
  tests and not for the MCP server in M8.
- **No bulk endpoints.** One group per request (GRP-020).
- **No server logic.** GRP-027.
- **No RBAC declarations.** M6 adds the required permission to each; M4 leaves the hook where
  `ActionPermissionWrapper` will read it and nothing else.

## Design references

- DEVPLAN §10 D2 (the marker and why now), D3 (two phases, the token), D11 (deletes ship too).
- `docs/ROADMAP.md` M5's read-only exit criterion — the enumeration test this marker feeds.
- ADR-019 — the CSRF header on every cookie-authenticated mutation.
- ADR-034 — `ErrorCode.ReadOnly` is 405, `InvalidState` 409, `GroupNotEmpty` 409, `GroupNotFound` 404.
- `research/kafbat/ui-analysis.md` "Reset offsets" — the reference's single-request form, and why
  KUI's is two.

## Public Scala signatures to implement

```scala
// in libs/contracts-core
object KuiEndpoint:
  /** The marker every mutating endpoint carries.
    *
    * It is an attribute rather than a naming convention because M5's enumeration test must be able
    * to *read* it: `endpoint.attribute(KuiEndpoint.MutationKey)` is `Some(_)` for exactly the
    * endpoints that change something. A convention nothing can read is the "documented rule that
    * nothing enforces" the M0 review warned about.
    */
  val MutationKey: AttributeKey[MutationMarker]
  final case class MutationMarker(operation: String, destructive: Boolean)

  /** Public endpoint, marked as a mutation, with the CSRF header input already attached. */
  def mutation(operation: String, destructive: Boolean): PartialServerEndpointBuilder
```

```scala
package kui.consumer.contract

object ConsumerMutationEndpoints:

  val OffsetsSegment: String = "offsets"
  val PlanSegment: String = "plan"

  /** `POST /api/v1/clusters/{clusterId}/consumer-groups/{groupId}/offsets/plan`
    *
    * **Not a mutation.** It reads live offsets and returns what would be written. Marked with
    * `destructive = false` and no read-only refusal of its own — except that it *does* refuse on a
    * read-only cluster, so the wizard never renders a plan the operator cannot apply. That
    * asymmetry is deliberate and the description says so.
    */
  val planReset: Endpoint[SignedPrincipal, (ClusterId, GroupId, ResetPlanRequest), ErrorEnvelope, ResetPlanDto, Any]

  /** `POST /api/v1/clusters/{clusterId}/consumer-groups/{groupId}/offsets`
    *
    * Applies exactly the plan the token names. Returns the plan that was applied, so the client can
    * show what happened without asking again. Marked `destructive = true`.
    */
  val applyReset: Endpoint[SignedPrincipal, (ClusterId, GroupId, ResetApplyRequest), ErrorEnvelope, ResetPlanDto, Any]

  /** `DELETE /api/v1/clusters/{clusterId}/consumer-groups/{groupId}` */
  val deleteGroup: Endpoint[SignedPrincipal, (ClusterId, GroupId), ErrorEnvelope, Unit, Any]

  /** `DELETE /api/v1/clusters/{clusterId}/consumer-groups/{groupId}/offsets?topic=<name>`
    *
    * The topic is a query parameter rather than a path segment because the resource being deleted is
    * "this group's offsets", narrowed by topic — and a path that read
    * `/consumer-groups/{g}/topics/{t}/offsets` would suggest a resource that does not exist.
    */
  val deleteOffsets: Endpoint[SignedPrincipal, (ClusterId, GroupId, TopicName), ErrorEnvelope, DeletedOffsetsDto, Any]

  val all: List[AnyEndpoint]
```

Error outputs, per endpoint, exhaustively:

| Endpoint | 400 | 403 | 404 | 405 | 409 | 503 |
| --- | --- | --- | --- | --- | --- | --- |
| `planReset` | `KUI-VALIDATION` | `KUI-FORBIDDEN` | `KUI-CLUSTER-NOT-FOUND`, `KUI-GROUP-NOT-FOUND` | `KUI-READ-ONLY` | `KUI-INVALID-STATE` | `KUI-UPSTREAM-UNAVAILABLE` |
| `applyReset` | `KUI-VALIDATION` (bad or expired token) | `KUI-FORBIDDEN` | both | `KUI-READ-ONLY` | `KUI-INVALID-STATE`, `KUI-GROUP-NOT-EMPTY` | `KUI-UPSTREAM-UNAVAILABLE` |
| `deleteGroup` | — | `KUI-FORBIDDEN` | both | `KUI-READ-ONLY` | `KUI-INVALID-STATE`, `KUI-GROUP-NOT-EMPTY` | `KUI-UPSTREAM-UNAVAILABLE` |
| `deleteOffsets` | `KUI-VALIDATION` | `KUI-FORBIDDEN` | both, plus `KUI-TOPIC-NOT-FOUND` | `KUI-READ-ONLY` | `KUI-INVALID-STATE` | `KUI-UPSTREAM-UNAVAILABLE` |

These four rows are the whole error surface of the milestone's destructive half, and GRP-027's suite
asserts the server returns nothing outside them.

## Tests required

`ConsumerMutationEndpointsSuite`, cross-compiled:

1. `everyMutatingEndpointCarriesTheMarker` — **the M5 hook**: `all.filter(isMutating).size == 3` and
   each names its operation. `planReset` is in `all` and is *not* in that set.
2. `theMarkerOperationMatchesTheApplicationLayer` — the three strings equal
   `MutationKind.values.map(_.operation)`. Two enums in two modules with the same names is exactly
   the drift rule A11 exists for, and this is the assertion that catches it across a layer boundary
   the rule cannot see.
3. `everyMutatingEndpointRequiresTheCsrfHeader`.
4. `everyMutatingEndpointDeclaresReadOnly` — a 405 output on all three.
5. `applyAcceptsOnlyAToken` — the request type has one field; asserted by decoding a body that also
   carries a spec and finding the spec ignored, so a client cannot smuggle one.
6. `planRequestRejectsAModeWithoutItsParameter` — four cases: `TIMESTAMP` without a timestamp,
   `OFFSET` without offsets, `SHIFT_BY` without a count, `DURATION` without a duration.
7. `planRequestRejectsAnOffsetMapWithAForeignPartition` — schema-level where it can be, server-level
   where it cannot.
8. `errorOutputsAreExactlyTheDocumentedTable` — per endpoint, asserted against the table above.
9. `deleteOffsetsTakesTheTopicAsAQueryParameter`.
10. `noMutationIsAGet` — a property over `all`: nothing that changes state is reachable by `GET`,
    which is what stops a link, a prefetch or a crawler from resetting a consumer group.
11. `theOpenApiDocumentMarksThemAsMutations` — the generated document carries the marker in its
    description, so an operator reading the API docs can see which calls change something.

## Degraded behavior

Declared: the 405 and 503 rows above are how a read-only cluster and an unreachable one reach the
browser. GRP-035 renders both — a read-only cluster hides the actions entirely, and an unreachable
one disables them with the reason.
