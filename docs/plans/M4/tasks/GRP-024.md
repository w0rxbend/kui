# GRP-024 — Consumer contract DTOs, redaction and golden files

- **ID:** GRP-024
- **Title:** Consumer contract DTOs, redaction and golden files
- **Milestone / Feature:** M4 / CG-001 … CG-006, TP-015
- **Owner role:** Chief Architect
- **Context / module:** `services/consumer/contract` (cross-compiled), `libs/contracts-core`
- **Size:** M
- **Dependencies / blocked by:** GRP-010

## Goal (user value)

One declaration of every document that crosses the process boundary, compiled by the server that
emits it and by the browser that reads it. M1's integration found the alternative: a browser
decoding `{"items": …}` from a server that sends `{"clusters": …}`, whose decoder defaulted the
missing field to `Nil`, so every response decoded *successfully* into zero rows under a "last
updated just now" timestamp. That defect passed every unit test on both sides.

## Scope

1. The Mill module `services.consumer.contract`, cross-compiled (`jvm` and `js`), and its test
   modules.
2. The DTOs for every M4 document: group summary and page, group detail with topics and partitions,
   the lag delta, the topic-consumers rows, the reset plan, and the three mutation requests.
3. Explicit Circe codecs and Tapir schemas (ADR-007: no automatic derivation), with the vocabulary
   codecs derived from `kui.kernel.group`'s `wire`/`from` — **not** re-spelled here.
4. A **golden file per document**, committed, asserted from both the JVM and the JS test module.
5. The redaction assertion: no DTO in this module has a field that can carry a credential, proved by
   a test rather than by inspection.

## Non-goals

- **No endpoints.** GRP-025 and GRP-026 declare them; this task declares what they carry.
- **No server logic, no domain types.** Rule A2 forbids this module seeing `domain` or
  `application`; the mapping is `api`'s (ADR-033, Chimney).
- **No state names spelled here.** Rule A11: `GroupState` comes from `libs/kernel` and its codec is
  `Codec.from(GroupState.from, _.wire)`. A literal `"STABLE"` in this module fails the build test.

- ADR-003 (Tapir, cross-compiled contract), ADR-007 (explicit codecs), ADR-026 (the `Page` shape),

## Public Scala signatures to implement

```scala
package kui.consumer.contract.dto

import kui.kernel.group.{GroupProtocol, GroupState, LagAnomaly, ResetTarget}

final case class GroupSummaryDto(
    groupId: String,
    state: GroupState,
    protocol: GroupProtocol,
    isSimple: Boolean,
    members: Int,
    topics: Int,
    partitions: Int,
    coordinatorId: Option[Int],
    /** `null` in JSON when undefined. **Never 0.** The browser renders `—`; a `0` here would be a
      * lie the browser has no way to detect (DEVPLAN §10 D6). */
    totalLag: Option[Long],
    pace: Option[Double],
    /** How many partitions contributed nothing to `totalLag`, so the UI can say "of 12, 3 have no
      * committed offset" rather than showing a number that means less than it looks like. */
    excludedPartitions: Int,
    /** Present only when something could not be fetched; `null` otherwise. */
    incomplete: Option[IncompleteDto]
)

final case class IncompleteDto(membersKnown: Boolean, offsetsKnown: Boolean, endOffsetsKnown: Boolean, note: String)

final case class PartitionDto(
    partition: Int,
    committed: Option[Long],
    begin: Option[Long],
    end: Option[Long],
    lag: Option[Long],
    anomalies: List[LagAnomaly],
    memberId: Option[String],
    host: Option[String]
)

final case class TopicSubscriptionDto(topic: String, lag: Option[Long], excludedPartitions: Int, partitions: List[PartitionDto])

final case class MemberDto(memberId: String, groupInstanceId: Option[String], clientId: String, host: String, partitions: List[String], rebalancing: Boolean)

final case class GroupDetailDto(
    groupId: String,
    state: GroupState,
    protocol: GroupProtocol,
    isSimple: Boolean,
    partitionAssignor: String,
    coordinatorId: Option[Int],
    members: List[MemberDto],
    topics: List[TopicSubscriptionDto],
    totalLag: Option[Long],
    excludedPartitions: Int,
    /** `"CURRENT" | "LAST_SEEN" | "UNKNOWN"` plus the timestamp for the middle one — the DC-H10
      * stale badge, on the wire. */
    assignments: AssignmentFreshnessDto,
    observedAt: java.time.Instant,
    stale: Option[StaleDto]
)

final case class LagUpdateDto(groupId: String, totalLag: Option[Long], pace: Option[Double], state: GroupState, members: Int)
final case class LagDeltaDto(changed: List[LagUpdateDto], gone: List[String], token: String, nextPollMs: Long, full: Boolean)

final case class TopicConsumerRowDto(group: GroupSummaryDto, topicLag: Option[Long], partitions: Int, dormant: Boolean)
final case class TopicConsumersDto(rows: List[TopicConsumerRowDto])

final case class PlannedPartitionDto(partition: Int, current: Option[Long], proposed: Long, delta: Option[Long])
final case class ResetWarningDto(kind: String, partition: Option[Int], message: String)
final case class ResetPlanDto(
    groupId: String,
    topic: String,
    target: ResetTarget,
    partitions: List[PlannedPartitionDto],
    warnings: List[ResetWarningDto],
    noOp: Boolean,
    token: String,
    expiresAt: java.time.Instant
)

/** The plan request. The apply request carries only the token (GRP-026), which is why this type and
  * `ResetApplyRequest` are separate rather than one optional-field type. */
final case class ResetPlanRequest(
    topic: String,
    partitions: List[Int],          // empty = every partition of the topic the group holds
    target: ResetTarget,
    timestamp: Option[java.time.Instant],
    offsets: Option[Map[String, Long]],
    shiftBy: Option[Long],
    durationMs: Option[Long]
)

final case class ResetApplyRequest(token: String)
```

Codecs live in `ConsumerCodecs` and are explicit. The vocabulary codecs are one line each:

```scala
given Codec[String, GroupState, TextPlain] = Codec.string.mapDecode(GroupState.from(_).toDecodeResult)(_.wire)
given io.circe.Codec[GroupState] = io.circe.Codec.from(
  Decoder.decodeString.emap(GroupState.from(_).left.map(_.message)),
  Encoder.encodeString.contramap(_.wire)
)
```

## Acceptance criteria

```
$ ./mill services.consumer.contract.jvm.test
Test run kui.consumer.contract.ConsumerContractSuite finished: 0 failed, 0 ignored, 21 total
SUCCESS

$ ./mill services.consumer.contract.js.test        # separate invocation, Node on PATH
Test run kui.consumer.contract.ConsumerContractSuite finished: 0 failed, 0 ignored, 21 total
SUCCESS

$ grep -rn '"STABLE"\|"EMPTY"\|"EARLIEST"\|"NO_COMMIT"' services/consumer/contract/src
# (no output — rule A11)
```

The same suite, the same count, on both platforms. That equality is the point: a document the JVM
encodes and the JS cannot decode is exactly M1's defect 2, and running the identical assertions on
both platforms is what makes it impossible.

## Tests required

`ConsumerContractSuite`, cross-compiled:

1–9. `<document>MatchesItsGoldenFile` — one per document (summary page, detail, lag delta, topic
consumers, reset plan, plan request, apply request, error envelope, incomplete section). Byte for
byte, including field order.
10. `everyGoldenFileDecodes` — the reverse direction, so a golden file that is not actually valid
    cannot sit there passing an encode test.
11. `absentLagEncodesAsNullNotZero` — a property over arbitrary summaries. **The D6 rule on the
    wire.**
12. `anAbsentOptionalFieldIsNullNotOmitted` — decided once, here: KUI's documents carry explicit
    nulls, because a browser distinguishing "absent" from "null" is a class of bug nobody needs.
13. `roundTripsForEveryDto` — a ScalaCheck property with generators for each.
14. `unknownFieldsAreIgnored` — additive compatibility (`ARCHITECTURE.md` §5).
15. `aMissingRequiredFieldIsADecodeFailureNotADefault` — **M1's defect 2, as a test**: decoding
    `{}` into a page must fail, not yield an empty list.
16. `vocabularyCodecsUseTheKernelWireStrings`.
17. `anUnknownStateStringIsADecodeFailure`.
18. `noDtoHasASecretField` — a reflective walk over every case class in the package asserting no
    field type is `Secret[_]` and no field name matches `(?i)password|secret|token|jaas|credential`,
    with `ResetPlanDto.token` and `ResetApplyRequest.token` on an explicit allow-list that names why
    (a plan HMAC is not a credential and carries no authority beyond the plan).
19. `instantsAreIso8601Utc` — one rendering, so the browser's formatter has one input shape. M1's
    integration found two screens disagreeing about a timezone offset; one wire format is where that
    stops.
20. `theResetPlanRequestRejectsAModeWithoutItsParameter` — `TIMESTAMP` with no timestamp is a decode
    failure, not a default of `now`.
21. `pageCountIsNotOnTheWire` — `Page` carries `totalItems`, and the client computes pages. One
    number, one source, and the reference product's page-count bug has nowhere to live.

## Observability

None. Contract module.

## Degraded behavior

Encoded, not implemented: `Section` variants and the `incomplete` / `stale` fields are how every
partial answer in M4 reaches the browser. The table of which endpoint can return which is in
GRP-025 and GRP-027.
