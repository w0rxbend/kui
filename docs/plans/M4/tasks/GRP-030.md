# GRP-030 — `ui-consumers`: the module, the typed clients, the route and the shell destination

- **ID:** GRP-030
- **Title:** `ui-consumers`: the module, the typed clients, the route and the shell destination
- **Milestone / Feature:** M4 / CG-001
- **Owner role:** Frontend Architect
- **Context / module:** `frontend/ui-consumers`, `frontend/ui-shell`
- **Size:** M
- **Dependencies / blocked by:** GRP-024, GRP-025

## Goal (user value)

A Consumers entry in the sidebar that goes somewhere, and a feature module the shell loads only when
a cluster actually has the capability. Nothing on screen yet beyond a page shell — but the seam this
task builds is the one M1's integration broke, so it is built the way that makes breaking it a test
failure.

## Scope

1. The Mill module `frontend.uiConsumers`, its test module, and its registration as a lazy feature
   module (ADR-012 Option B, `js.dynamicImport` keyed by `FeatureId`).
2. The typed clients, **derived from `services/consumer/contract`'s endpoints** with
   `tapir-sttp-client4` — not hand-written, and not a second declaration of any path or field name.
3. The routes: `/clusters/:clusterId/consumer-groups`, `/consumer-groups/:groupId`,
   `/consumer-groups/:groupId/reset-offsets`, and their `history.state` codecs.
4. The shell's Consumers destination, its `FeatureId`, its capability binding and its icon.
5. `ConsumersFeature`: the module's entry point, its route table and its fallback panel.

## Non-goals

- **No screens.** GRP-031 onwards. This task ships page skeletons with headings, breadcrumbs and
  loading states, because a route must go somewhere real on the day it is drawn.
- **No hand-written DTOs.** Anything the browser decodes comes from the contract module. **A
  `case class` in this module with the same fields as a DTO is the defect M1 shipped**, and rule A11's
  build test plus this module's own suite both look for it.
- **No design token changes.** `ui-kernel`'s tokens are what they are; this feature uses them.

## Design references

- `STATUS.md` M1 integration, defect 2 — the browser declaring `ClustersResponse` while the gateway
  sent `ClusterOverviewDto`, decoding successfully into zero rows. The client in this task is derived
  from the endpoint, and GRP-037's seam suite decodes recorded server bytes.
- ADR-012 (module split, `js.dynamicImport`), ADR-011 (Laminar 17.2.1, Waypoint 9.0.0), ADR-024
  (CSS bands), ADR-032 (`FeatureState` and how each renders).
- `research/kafbat/ui-analysis.md` — the routes (`/consumer-groups`, `/:consumerGroupID`,
  `/:consumerGroupID/reset-offsets`) and the sidebar entry's position ("Brokers", "Topics",

## Public Scala signatures to implement

```scala
package kui.ui.consumers

import com.raquo.laminar.api.L.*
import kui.ui.kernel.feature.{Feature, FeatureId}

object ConsumersFeature extends Feature:
  val id: FeatureId = FeatureId("consumers")
  def routes: List[kui.ui.kernel.router.PageRoute]
  /** Rendered when the capability is `Unavailable`: the reason, the `since`, a retry, and — the
    * part that matters — a list of what still works, so a user who came here from a topic page
    * knows the topic page is fine (ADR-032). */
  def fallback(state: kui.ui.kernel.nav.FeatureState): HtmlElement

object ConsumersRoutes:
  case class GroupListPage(clusterId: String, query: GroupListQuery)
  case class GroupDetailPage(clusterId: String, groupId: String)
  case class ResetOffsetsPage(clusterId: String, groupId: String)

  /** The query lives in the URL, not in a `Var`: a filtered, sorted, paged list is a thing an
    * operator sends to a colleague in a message, and a list whose state is in memory cannot be. */
  case class GroupListQuery(states: Set[String], q: Option[String], sort: String, desc: Boolean, page: Int)

object ConsumerClients:
  /** Every method is `SttpClientInterpreter.toClient(endpoint)`. There is no hand-written request
    * and no hand-written response type anywhere in this module. */
  def make(base: kui.ui.kernel.http.ApiClient): ConsumerClients
```

## Tests required

`ConsumersRoutesSuite`:

1. `theListRouteRoundTripsThroughItsUrl`.
2. `theQueryIsInTheUrl` — states, search, sort, page; a URL pasted into another browser shows the
   same list.
3. `anUnknownStateInTheUrlIsIgnoredNotFatal` — a stale bookmark must not blank the page.
4. `theDetailRouteEncodesTheGroupId` — including a group id containing `/` and `%`, which Kafka
   permits and every naive path builder breaks on.
5. `theResetRouteIsUnderTheDetailRoute`.
6. `theFeatureIdIsConsumers`.
7. `theFallbackRendersTheReasonAndSince`.
8. `theFallbackListsWhatStillWorks`.
9. `routesAreRegisteredExactlyOnce` — a duplicate route silently shadows, and Waypoint will not say.

`ConsumerClientsSuite`:

1–4. Each client method builds the request the endpoint describes — method, path, query — asserted
against the endpoint, not against a literal.
5. `noClientMethodDeclaresItsOwnResponseType` — a reflective assertion that every method's response
type comes from `kui.consumer.contract.dto`. **M1's defect 2, as a test.**

## Observability

Browser-side: the kernel's `ApiClient` already records request outcomes and reports them to the
capability banner. This module adds nothing and the Implementation Report says so.

## Degraded behavior

| Condition | Behaviour |
| --- | --- |
| Capability `NotConfigured` | The sidebar entry is hidden and the module is **never downloaded** — asserted in GRP-038 with a Playwright network assertion (risk R-9) |
| Capability `Unavailable` | The entry is dimmed and clickable; clicking it renders `ConsumersFeature.fallback` with the reason, the `since`, a retry and what still works |
| Capability `Degraded` | The entry shows an amber dot; screens render and the lag poller uses the suggested interval |
| Module fails to load | The shell's own dynamic-import error path, which M0 built and tested; this module adds nothing to it |
