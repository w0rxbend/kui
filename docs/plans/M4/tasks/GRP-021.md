# GRP-021 — `services/consumer/infrastructure`: the module and the `GroupAdmin` adapter

- **ID:** GRP-021
- **Title:** `services/consumer/infrastructure`: the module and the `GroupAdmin` adapter
- **Milestone / Feature:** M4 / CG-001 … CG-005
- **Owner role:** Domain Architect (Consumer Group Management context)
- **Context / module:** `services/consumer/infrastructure`
- **Size:** L
- **Dependencies / blocked by:** GRP-012, GRP-007

## Goal (user value)

The one module in the consumer service that is allowed to know Kafka exists. It turns
`libs/kafka`'s `GroupAdmin` into the domain's `GroupAdminPort`, holds the per-cluster admin client
lifecycle, and is proved — by running the *same* contract the application's fakes are checked
against — to behave the way those fakes claim.

## Scope

1. The Mill module `services.consumer.infrastructure` and its test module.
2. `KafkaGroupAdminPort`: the adapter, mapping `libs/kafka` result types onto domain types, field
   for field, by exhaustive match.
3. `GroupCapabilities` mapping: `libs/kafka`'s three-set `GroupFeatures` onto the domain twin,
   **preserving all three sets and `probedAt`**.
4. The per-cluster client lifecycle: one `AdminClientPool` entry per cluster, rebuilt when the
   profile version moves, released when the cluster disappears.
5. `KafkaGroupAdminAdapterSuite`, which runs `GroupAdminContract` (GRP-009) against this adapter.

## Non-goals

- **No use cases.** Rule A9: `application` may not see this module, and this module implements ports,
  not policy.
- **No HTTP.** GRP-022 is the profile client; it lives in this module but is a separate task and a
  separate file.
- **No second lookup of leaderless partitions.** `OffsetLookup` (GRP-006) does it at the port.
- **No caching.** The snapshot is the application's.

## Design references

- ADR-041 A9, A10 — this is the only module in the tree with `libs/kafka` on its classpath, and
  `app` is the only module allowed to see it.
- ADR-033 — Chimney is for `application → contract`; this boundary is hand-written, because a mapping
  that must be exhaustive over an enum is exactly the mapping a macro would silently widen.
- M1's `services/cluster/infrastructure` — the shape, including how the pool is keyed and how a
  profile change invalidates a client.
- M1 gate review F-05 — the three-set collapse, which this adapter is the second place that could
  reintroduce.
- DEVPLAN §6.2 (module map), §8 (the adapter-contract suite row).

## Public Scala signatures to implement

```scala
package kui.consumer.infrastructure

import kui.consumer.domain.*
import kui.kafka.admin.{GroupAdmin, GroupFeatures, OffsetLookup}
import kui.kernel.{ClusterId, GroupId}
import kui.kernel.cluster.ClusterConnection

object KafkaGroupAdminPort:
  /** One port instance per cluster, holding the connection it was built for. Rebuilt — not
    * mutated — when the profile version moves, so an in-flight call always finishes against the
    * client it started with. */
  def make[F[_]: Async](
      cluster: ClusterId,
      connection: ClusterConnection,
      admin: GroupAdmin[F],
      offsets: OffsetLookup[F],
      logger: StructuredLogger[F]
  ): GroupAdminPort[F]

object GroupMappings:
  /** Exhaustive by construction: a `match` over `GroupFeature` with no default case, so a feature
    * added in `libs/kafka` fails this file's compile rather than silently landing in no set.
    *
    * **All three sets survive.** M1's gate review (F-05) found a caller collapsing exactly this
    * shape to a `Set`, which turns "the probe timed out" into "the cluster cannot do that" and
    * caches the lie for an hour. */
  def toDomain(f: GroupFeatures): GroupCapabilities

  def toDomainGroup(d: kui.kafka.admin.GroupDescription, offsets: List[kui.kafka.admin.CommittedOffset], ends: Map[TopicPartition, Offset], at: Instant): ConsumerGroup

/** The per-cluster registry the application's `ClusterId => GroupAdminPort[F]` function reads. */
trait GroupAdminRegistry[F[_]]:
  def portFor(cluster: ClusterId): F[Option[GroupAdminPort[F]]]

object GroupAdminRegistry:
  def resource[F[_]: Async](
      profiles: ClusterProfileSource[F],
      admin: GroupAdmin[F],
      offsets: OffsetLookup[F],
      logger: StructuredLogger[F]
  ): Resource[F, GroupAdminRegistry[F]]
```

## Tests required

`GroupMappingsSuite` (MUnit + ScalaCheck):

1. `theThreeCapabilitySetsSurviveTheMapping` — **the F-05 assertion**, on this side of the boundary.
   A property: `toDomain(f)` preserves `present`, `absent`, `unknown` and `probedAt` exactly.
2. `theCapabilityMappingIsExhaustive` — every `GroupFeature` lands in exactly one set.
3. `memberMappingPreservesHostAndClientId`.
4. `targetAssignmentSurvives`.
5. `anAbsentCoordinatorStaysAbsent`.
6. `authorizedOperationsNoneStaysNone` — not `Some(Set.empty)`.
7. `absentCommitsStayAbsent` — a partition with no commit does not appear with a zero. **The same
   assertion as GRP-005's, on the other side of the mapping**, because that is where a `getOrElse`
   is most tempting.
8. `leaderlessPartitionsBecomeExcludedPartitions` — with the reason preserved.
9. `completenessReflectsWhatWasActuallyFetched`.
10. `noKafkaTypeEscapesTheMapping` — a compile-time assertion via `compileErrors` that
    `ConsumerGroup` has no field of a `org.apache.kafka` type.

`KafkaGroupAdminAdapterSuite` extends `GroupAdminContract` against a live container and adds:

11. `theClientIsRebuiltWhenTheProfileVersionMoves`.
12. `anInFlightCallFinishesAgainstItsOwnClient`.
13. `aClusterRemovedFromTheProfileSourceHasItsClientReleased` — the leak test.
14. `cancellationReleasesTheClient`.

## Observability

The adapter emits nothing of its own: `libs/kafka` already emits `kui.kafka.admin.duration` and the
group counters, tagged with `cluster.id`. Adding a second timer here would double-count. The
Implementation Report states that as a decision, because "the adapter has no metrics" reads like an
omission unless it is said out loud.

One exception:

| Signal | Name | Attributes |
| --- | --- | --- |
| Gauge | `kui.consumer.admin.clients` | `cluster.id` — how many admin clients this service holds; the number that makes a leak visible |

## Degraded behavior

| Condition | Behaviour |
| --- | --- |
| Profile unavailable for a cluster | `portFor` returns `None`; the use cases answer `Unavailable` with the profile source's reason rather than constructing a client with no credentials |
| Profile version moves mid-call | The in-flight call completes on the old client; the next call uses the new one |
| Cluster removed | The client is released within one profile-change event; the gauge drops |

## Cancellation and shutdown

`GroupAdminRegistry.resource` releases every client it holds, in order, and cancels its
profile-change subscriber first so that a release cannot race a rebuild. Test 13 and test 14 are the
named cancellation tests DEVPLAN §11.10 requires for this task.
