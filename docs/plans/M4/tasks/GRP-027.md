# GRP-027 — Consumer `api`: server logic, error envelope, `Section` staleness

- **ID:** GRP-027
- **Title:** Consumer `api`: server logic, error envelope, `Section` staleness
- **Milestone / Feature:** M4 / CG-001 … CG-006, TP-015
- **Owner role:** Chief Architect
- **Context / module:** `services/consumer/api`
- **Size:** L
- **Dependencies / blocked by:** GRP-026, GRP-020, GRP-017

## Goal (user value)

The service answers. Every endpoint of GRP-025 and GRP-026 is served, every application-layer value
is mapped to its DTO, every `KuiError` becomes the one envelope shape the browser already knows, and
every stale answer says it is stale instead of pretending to be fresh.

## Scope

1. The Mill module `services.consumer.api` and its test module.
2. `ConsumerRoutes`, `ConsumerMutationRoutes`: server logic for all nine endpoints.
3. The mapping layer: application types → DTOs, with Chimney (ADR-033) where the shapes match and by
   hand where they do not, and the freshness → `stale` field mapping.
4. The error mapping: `KuiError` → `ErrorEnvelope` with `ErrorEnvelope.statusOf`, and the assertion
   that nothing outside GRP-026's table is ever returned.
5. The health and capability endpoints every service carries, reporting the consumer service's own
   state including the profile source's health (GRP-022).
6. OpenAPI generation and its committed snapshot.

## Non-goals

- **No use-case logic.** If a rule can be tested without a socket it belongs in `application`. The
  review question for every line of this module is "could this be a use-case test instead".
- **No gateway routes.** GRP-029.
- **No wiring.** GRP-028.
- **No domain or infrastructure imports.** Rules A3 and A9: this module sees `application` and
  `contract`, not `domain` internals and never `infrastructure`.

## Design references

- ADR-034 — the error envelope, `statusOf`, and the rule that a `KuiError` carries display text free
  of hosts, bodies and credentials.
- `ARCHITECTURE.md` §6 — `Section` and which responses are partial.
- ADR-033 — Chimney for `application → contract`.
- `services/cluster/api` — the house shape: `KuiEndpoint` interpretation, the `Section` mapping, the
  contract suite using the Tapir stub interpreter.
- ADR-032 — what `Stale` means on the wire and how the browser renders it.
- DEVPLAN §8's contract and seam suite rows.

## Tests required

`ConsumerRoutesSuite` (Tapir stub interpreter, no socket, with the application fakes from
`services.consumer.application.test`):

1–4. Each read endpoint's happy path, asserted against the golden document from GRP-024. **Not
against a hand-written expectation**: the same file the contract suite uses, so the server and the
client are tested against one artefact (M1's defect 2).
5. `staleFreshnessBecomesTheStaleField` — with `fetchedAt` and the reason.
6. `unavailableFreshnessBecomesFiveOhThree`.
7. `anUnknownClusterIsFourOhFour`.
8. `anUnknownGroupIsAnEmptyDeadGroupNotFourOhFour` — the invariant, at the HTTP layer.
9. `queryParametersReachTheUseCase` — every field of `GroupListParams`, asserted on the fake.
10. `noSecretAppearsInAnyResponseBody` — every endpoint exercised against a profile whose every
    secret is a distinctive token; the token appears in no body. **Nine assertions in one test**,
    because a leak in the ninth endpoint is as bad as one in the first.
11. `theLagTokenRoundTrips` — the token the server returns is accepted by the server.
12. `incompleteCoordinatorsReachTheDocument`.
13. `theForTopicEndpointIsReachableOnlyOnInternalV1`.
14–18. The five degraded rows of the table below, each asserted as a response.

`ConsumerMutationRoutesSuite`:

1. `planReturnsThePlanAndAToken`.
2. `applyWithTheTokenSucceeds`.
3. `applyWithoutATokenIsFourHundred`.
4. `readOnlyIsFourOhFiveOnAllThreeMutations`.
5. `anActiveGroupIsFourOhNine`.
6. `aMissingCsrfHeaderIsRejected` — declared now, enforced now, so M6 does not have to retrofit it
   into a shipped client.
7. `deleteGroupReturnsTwoOhFour`.
8. `deleteOffsetsReturnsWhatItDeleted`.
9. `everyErrorIsInTheDocumentedTable` — **a property**: drive each endpoint through every `KuiError`
   the fakes can produce and assert the `(status, code)` pair is in GRP-026's table. An error shape
   that is not in the OpenAPI document is one the browser has no branch for.
10. `noMutationSucceedsOnAGetRequest`.
11–16. The mutation half of the degraded table.

`ConsumerErrorMappingSuite`: totality over `KuiError` (a property); no mapping produces a 500 for a
condition the operator caused; the message never contains a host, a body or a credential (a property
over errors constructed from a distinctive-token profile).

## Degraded behavior

| Condition | Response |
| --- | --- |
| Snapshot stale | 200 with `stale: {fetchedAt, reason}`; the browser greys the rows and shows the timestamp |
| Snapshot never taken | 503 `KUI-UPSTREAM-UNAVAILABLE` with the reason; the feature's fallback panel |
| Profile source stale | 200 for reads; 503 for mutations (GRP-018), with a message saying the cluster's settings could not be confirmed |
| One coordinator down | 200, `incompleteCoordinators` non-empty; the list banner |
| Group forbidden | 200 with the row's sections marked forbidden — not a 403 for the whole list, because one group KUI may not describe must not hide four thousand it may |
| Cluster read-only | 405 on the three mutations; the reads are unaffected |
