# GRP-001 — `libs/kernel`: the shared consumer-group wire vocabulary and two error codes

- **ID:** GRP-001
- **Title:** `libs/kernel`: the shared consumer-group wire vocabulary and two error codes
- **Milestone / Feature:** M4 / CG-001, CG-002, CG-004, KU-013
- **Owner role:** Principal Scala Engineer
- **Context / module:** `libs/kernel` (cross-compiled)
- **Size:** M
- **Dependencies / blocked by:** —

## Goal (user value)

Nothing an operator sees. What this buys is that the word `STABLE` is spelled once in KUI. The M0
review found that a string typed twice in two files drifts, and M1's integration found the same
class of defect twice — a config section parsed and discarded, and a browser decoding a document
nobody sends. Six consumer-group state names, six reset-mode names and three lag-anomaly names each
appear in a Kafka enum, a domain type, a JSON field, a query parameter and a CSS class. This task
makes all five of those read from one declaration that the compiler checks.

## Scope

1. A new pure package `kui.kernel.group` in `libs/kernel`, cross-compiled to JVM and Scala.js:
   `GroupState`, `GroupProtocol`, `ResetTarget`, `LagAnomaly`.
2. Each is an `enum` carrying a `wire: String`, with `from(wire): Either[ValidationError, A]` and a
   `given CanEqual`. The `wire` value is the JSON string, the query-parameter value and the CSS
   modifier suffix — one string, three uses.
3. Two new `ErrorCode` cases: `GroupNotFound` and `GroupNotEmpty` (DEVPLAN §10 D5).
4. The `docs/api/error-codes.md` regeneration that `./mill docs.errorCodes` performs, committed.

## Non-goals

- **No domain types.** `ConsumerGroup`, `PartitionLag`, `ResetSpec` and `ResetPlan` are
  `services/consumer/domain` (GRP-010, GRP-012). This package holds *vocabulary* — the closed sets
  of names that cross the wire — and nothing with behaviour.
- **No Kafka types and no mapping to them.** `libs/kernel` must not see `org.apache.kafka`
  (rule A10). The mapping from `org.apache.kafka.common.ConsumerGroupState` lives in `libs/kafka`
  (GRP-003).
- **No Tapir codec and no Circe codec here.** `libs/kernel` carries neither dependency. The codecs
  are derived from `wire`/`from` in `libs/contracts-core` (GRP-024).
- **No share-group state.** KIP-932 share groups are out of scope (DEVPLAN §4).

## Design references

- DEVPLAN §10 D1 (where the vocabulary lives) and §6.3 (rule A11, which enforces it).
- `research/kafbat/ui-analysis.md` "Consumer groups" — the six state names and their operator-facing
  tooltips, which are the source for the `description` field.
- `research/kafka/admin-capabilities.md` §3 — `ConsumerGroupState`, `state()` being `Optional`
  (hence `Unknown` is a real member and not an error), and the reset modes of DC-D6.
- ADR-034 — `ErrorCode` carries `wire`, `httpStatus`, `retryable` and `description` on one enum so
  the generated document cannot fall behind.
- `libs/kernel/src/kui/kernel/ids.scala` — the house style for a value type: smart constructor,
  `unsafe`, `Ordering`, `CanEqual`.

## Public Scala signatures to implement

```scala
package kui.kernel.group

import kui.kernel.ValidationError

/** The lifecycle state a broker reports for a consumer group.
  *
  * `Unknown` is a member rather than an error: `ConsumerGroupListing.state()` is an `Optional` and
  * a broker older than 2.6, or one that could not be reached, simply does not say
  * (`research/kafka/admin-capabilities.md` §3). Rendering that as `DEAD` would be a lie about a
  * group that may be perfectly healthy.
  *
  * `description` is the operator-facing sentence the UI shows in the state chip's tooltip. It is a
  * constructor parameter for the same reason `ErrorCode.description` is: a new state cannot be
  * added without one.
  */
enum GroupState(val wire: String, val description: String):
  case Stable extends GroupState("STABLE", "Consumers are consuming and have assigned partitions.")
  case Empty extends GroupState("EMPTY", "The group exists but has no members.")
  case Dead extends GroupState("DEAD", "The group has no members and no committed offsets, or it is being removed.")
  case PreparingRebalance extends GroupState("PREPARING_REBALANCE", "Something changed and the partitions are about to be reassigned.")
  case CompletingRebalance extends GroupState("COMPLETING_REBALANCE", "Partition reassignment is in progress.")
  case Unknown extends GroupState("UNKNOWN", "The broker did not report a state for this group.")

object GroupState:
  val All: List[GroupState] = values.toList
  def from(wire: String): Either[ValidationError, GroupState]
  /** True when an offset operation is allowed. DEVPLAN §10 D4: state alone is not sufficient — the
    * member list is checked too — but a state outside this set is an immediate refusal. */
  def permitsOffsetChange(state: GroupState): Boolean   // Empty | Dead
  given Ordering[GroupState]
  given CanEqual[GroupState, GroupState] = CanEqual.derived

/** Which group protocol a member speaks. Classic members report their assignment through
  * `assignment()`; KIP-848 consumer-protocol members report it through `targetAssignment()`, and a
  * port that reads only one shows an empty member list for the other (DEVPLAN risk R-10). */
enum GroupProtocol(val wire: String):
  case Classic extends GroupProtocol("CLASSIC")
  case Consumer extends GroupProtocol("CONSUMER")
  case Unknown extends GroupProtocol("UNKNOWN")

object GroupProtocol:
  def from(wire: String): Either[ValidationError, GroupProtocol]
  given CanEqual[GroupProtocol, GroupProtocol] = CanEqual.derived

/** The *name* of a reset mode, as it appears in a request and on a radio button.
  *
  * The parameterised mode — the timestamp, the offset map, the shift — is `ResetSpec` in the
  * consumer domain (GRP-012). This enum is only the closed set of names, because that set is what
  * the browser, the contract and the planner must agree on. Splitting them this way is what lets
  * `libs/kernel` stay free of `Instant`-carrying request shapes and lets the wizard render its six
  * radios from `ResetTarget.values` rather than from a hand-written list.
  */
enum ResetTarget(val wire: String, val label: String):
  case Earliest extends ResetTarget("EARLIEST", "The beginning of each partition")
  case Latest extends ResetTarget("LATEST", "The end of each partition")
  case Timestamp extends ResetTarget("TIMESTAMP", "The first record at or after a point in time")
  case Offset extends ResetTarget("OFFSET", "An offset you give, per partition")
  case ShiftBy extends ResetTarget("SHIFT_BY", "A number of records forward or back from where it is now")
  case Duration extends ResetTarget("DURATION", "A period of time back from now")

object ResetTarget:
  def from(wire: String): Either[ValidationError, ResetTarget]
  given CanEqual[ResetTarget, ResetTarget] = CanEqual.derived

/** Why a partition's lag is not a plain number (DEVPLAN §10 D6). */
enum LagAnomaly(val wire: String, val description: String):
  case NoCommit extends LagAnomaly("NO_COMMIT", "This group has never committed an offset for this partition.")
  case CommittedBeyondEnd extends LagAnomaly("COMMITTED_BEYOND_END", "The committed offset is past the end of the log; the lag cannot be computed.")
  case CommittedBeforeStart extends LagAnomaly("COMMITTED_BEFORE_START", "The committed offset is older than the earliest record still retained; the consumer will resume from the earliest one.")
  case NoLeader extends LagAnomaly("NO_LEADER", "This partition has no leader, so its end offset could not be read.")

object LagAnomaly:
  def from(wire: String): Either[ValidationError, LagAnomaly]
  given CanEqual[LagAnomaly, LagAnomaly] = CanEqual.derived
```

And in `ErrorCode`:

```scala
  case GroupNotFound
      extends ErrorCode(
        "KUI-GROUP-NOT-FOUND",
        404,
        false,
        "No consumer group with this id exists on this cluster."
      )

  case GroupNotEmpty
      extends ErrorCode(
        "KUI-GROUP-NOT-EMPTY",
        409,
        false,
        "The consumer group still has members, so its offsets cannot be changed or deleted."
      )
```

`GroupNotEmpty` is distinct from `InvalidState` because it is the one refusal an operator can act
on directly — stop the consumers — and a message that says so is worth a code the UI can switch on.

## Tests required

`GroupVocabularySuite` (MUnit + ScalaCheck, one file, cross-compiled so it runs on both platforms):

1. `everyGroupStateRoundTripsThroughItsWire` — `from(s.wire) == Right(s)` for all six.
2. `theWireSetIsExactlyTheDocumentedSet` — the sorted set of wire strings equals the literal list
   from `research/kafbat/ui-analysis.md`. Asserted against a literal so that renaming a case is a
   test failure and therefore a deliberate contract change.
3. `anUnknownWireIsAValidationErrorNamingTheField` — not an exception, not `Unknown`.
4. `everyGroupStateHasANonEmptyDescription` — the tooltip cannot be forgotten.
5. `permitsOffsetChangeIsExactlyEmptyAndDead`.
6–8. The same round-trip / exact-set / unknown-wire triple for `ResetTarget`.
9–11. The same triple for `LagAnomaly`.
12. `groupProtocolRoundTrips`.
13. `groupNotFoundAndGroupNotEmptyHaveTheDocumentedStatuses` — 404 and 409, both `retryable = false`.
14. `noTwoErrorCodesShareAWireString` — a property over `ErrorCode.values`, cheap and permanent.

## Observability

None. This module emits no signals; it is data.

## Degraded behavior

| Condition | Behaviour |
| --- | --- |
| A broker reports a state name this enum does not have | The mapping in `libs/kafka` (GRP-003) yields `GroupState.Unknown` and counts it on `kui.kafka.group.unknown_state`. This enum is not extended speculatively |
| A request carries an unknown `state=` filter value | `from` returns `ValidationError`; the endpoint answers `KUI-VALIDATION` naming the parameter and listing the accepted values, which it reads from `GroupState.All` rather than from a literal |
